## TL;DR

<strong>一句话：大家默认"让视觉 agent 多用工具（zoom-in 裁剪）就会更强"，这篇在更难的空间推理任务上把这件事拆开了——vanilla RL 微调会让工具使用率从 20% 塌到 2%，而准确率还在涨；把工具彻底禁掉成绩反而掉 1.1 分；用奖励逼它每题都用工具，使用率冲到 100% 但准确率只涨 0.7 分。真正的原因是 rollout 多样性：两种训练都把推理练成了模板、把裁剪框挤在同一块地方。加一个自适应熵正则后成绩从 59.2 涨到 62.9，而工具使用率照样自己掉到 3%——所以工具的价值在训练期，不在推理期。</strong>

- <strong>最刺眼的一组数（Table 2）</strong>：同一个起点（工具使用率 \~20%），四种走法

| 方法 | 允许用工具 | 3DSRBench 准确率 | 工具使用率（起→末） |
|-|-|-|-|
| vanilla RFT | 是 | 59.2 | \~20% → <strong>≈2%</strong> |
| 完全禁工具 | 否 | <strong>58.1</strong>（掉 1.1） | 0 → 0 |
| 奖励鼓励用工具 | 是 | 59.9（只 +0.7） | \~20% → <strong>100%</strong> |
| <strong>自适应熵正则</strong> | 是 | <strong>62.9</strong> | \~20% → <strong>≈3%</strong> |
| 禁工具 + 熵正则 | 否 | 57.8（没救） | 0 → 0 |

- <strong>论文自己命名的三个现象</strong>：<strong>Tool-Use Collapse</strong>（工具塌掉但准确率涨）、<strong>Tool Explosion</strong>（奖励逼出 100% 使用率但收益微薄）、<strong>Tools as Scaffolding</strong>（工具只在训练期当脚手架）
- <strong>诊断两手抓</strong>：<strong>文本侧</strong>——distinct n-gram 比例（n=3/4/5/6）在 vanilla 与 tool-encourage 下都单调下降，推理越来越模板化；<strong>视觉侧</strong>——同一题采 50 条 rollout，裁剪框的平均 pairwise IoU 在两种训练下都 &gt;0.55（框挤成一团），而熵正则降到 <strong>0.494</strong>
- <strong>关键消融（§3.5）</strong>：<strong>禁工具 + 熵正则 = 57.8</strong>，不比禁工具的 58.1 高 → <strong>熵正则的收益依赖"训练时能用工具"，不是纯熵的功劳</strong>
- <strong>唯一"两榜都涨"的方法（Table 3）</strong>：专用榜 3DSRBench <strong>62.9</strong>（vanilla 59.2、预训练 Mini-o3 54.5、专家 SpatialReasoner 60.3）；通用榜 CV-Bench-3D <strong>78.8</strong>（vanilla 76.7、tool-encourage 74.5 都掉到预训练的 77.6 以下）
- <strong>跨模型/跨任务（Table 4）</strong>：换 OpenThinkIMG + 异构工具集（OCR/检测/分割/点定位/画轴）做医学 VQA，vanilla 46.34 → tool-encouraged 47.23 → <strong>熵正则 48.78</strong>，趋势复现
- <strong>方法本体极简</strong>：GRPO/DAPO 加一项 <strong>λ\_t·E\[H̄(τ)\]</strong>，系数用比例反馈自适应：<strong>λ\_t = Kp·\[H\_target − H\_t\]\_+，H\_target = 0.9，Kp = 0.03</strong>。熵低于目标才加压，否则为 0
- <strong>⚠️ 论文自述的两处限制都只是"训练工程"</strong>：① 超过 100 步后出现震荡、验证集不再稳定提升；② DAPO 动态采样若一步内重采样超 10 次，wall-clock 成本急剧上升，只能终止。<strong>没有独立 Limitations 章节</strong>，也没讨论"工具什么时候应该保留"这类方法边界
- <strong>主题轮换</strong>：今日起按<strong>每周单领域</strong>新规则运行；本周 <strong>① 多模态推理 / 感知</strong>（think-with-image / 视觉接地 / 细粒度 VQA / 文档图表），上一周（旧规则末尾）是世界模型

## 一、先看例子（大白话：放大镜该不该收走？）

> 💡 <strong>铺垫</strong>：现在有一类"会看图的 agent"，它可以在推理过程中<strong>调一个裁剪工具</strong>——先把注意力放到某个区域，把那一小块放大再看。
>
> <strong>大家的默认想法是：会调工具 = 更强；用得越多 = 越强。</strong>这篇说：<strong>两件事都不对。</strong>

> <strong>想象你教一个人用放大镜看地图找路：</strong>
>
> <strong>① 一开始他每题都要用放大镜</strong>（约 20% 的题）。练着练着，他不用了——<strong>成绩还在涨</strong>。
>
> <strong>② 你据此判断"放大镜没用"，干脆把放大镜收走</strong>——成绩<strong>反而掉了一点</strong>（58.1 vs 59.2）。
>
> <strong>③ 于是你改主意，规定他每题必须用放大镜</strong>——他每题都用，<strong>但成绩几乎没动</strong>（59.9）。
>
> <strong>④ 真正的办法：别管他用不用放大镜，只管让他别老盯同一个地方</strong>——成绩跳到 <strong>62.9</strong>，<strong>而放大镜照样自己退场了</strong>（3%）。
>
> <strong>结论：放大镜的价值在他"练的那段时间"，不在"考的时候还拿不拿着"。</strong>

![论文 Figure 1：三列对比同一道题（那个男人朝向的是更衣室还是婴儿车）。上半是训练早期，三列都还在到处看；下半是训练后期——vanilla 与工具奖励两列都塌成直接作答、答案都错（红叉），只有多样性鼓励那列还在主动去看婴儿车，答对（绿勾）](/images/paper-reading/2026-10-20-dof/2026-10-20-d60-1.webp)

<strong>论文把这三步各自命名了：</strong><strong>Tool-Use Collapse</strong>（塌掉但变强）、<strong>Tool Explosion</strong>（逼到 100% 但没用）、<strong>Tools as Scaffolding</strong>（脚手架）。

## 二、动机：工具研究都停在"视觉搜索"上

- <strong>现状</strong>：visual chain-of-thought 里调外部视觉工具（zoom-in 裁剪、grounding、分割、点选）已经成了标配，V\* 这类高分辨率基准上确实关键
- <strong>但以往研究几乎都在"视觉搜索"任务上做</strong>——<strong>目标小、找出来就完事</strong>，这时候裁剪当然有用，因为任务本身就是"定位"
- <strong>这篇换到更难的视觉推理</strong>： 
  - <strong>3D 空间推理</strong>（主战场）——要从 2D 图推断相对高度、深度次序、朝向，<strong>光靠 2D 坐标推不出来</strong>
  - <strong>医学 VQA</strong>（验证）——看片找病灶，也不只是"找得到"就够
- <strong>为什么这个区间关键</strong>：这类任务里"该不该裁"是<strong>模糊</strong>的——有的题不裁也能答，有的题非裁不可。<strong>只有混合效用的环境，才能研究"选择性使用工具"</strong>
- <strong>而他们发现：朴素 RL 在这个区间会翻车</strong>——翻车方式还挺意外

## 三、方法：三个现象 + 一个控制器

### 3.1 现象一：工具塌掉，但准确率在涨

![论文 Figure 2：(a) 三条曲线分别是 vanilla RFT（蓝）、加工具奖励（红）、加熵正则（绿）的工具使用率随训练步数变化——红的冲到 1.0（每题都用），蓝和绿都掉到接近 0；(b) 对应的 3DSRBench 准确率，绿线在后期明显拉开，蓝红两条几乎贴在 0.58 到 0.60 之间](/images/paper-reading/2026-10-20-dof/2026-10-20-d60-2.webp)

- 从<strong>已经会用工具的 Mini-o3</strong> 出发做 vanilla RFT，<strong>准确率一路涨到 59.2%</strong>，<strong>工具使用率却单调掉到 ≈2%</strong>
- <strong>早期还有个 \~20% 的平台期</strong>，然后塌得更快
- <strong>排除了长度偏置</strong>：换成 DAPO 的 token-level policy loss 之后<strong>照样塌</strong>；换到更大的 SAT（6k）数据<strong>照样塌</strong>

### 3.2 现象二：禁工具反而更差 —— 这是"脚手架"唯一的直接证据

- 训练和评测<strong>全程禁止</strong>模型输出 <strong>&lt;grounding&gt;</strong> 标签、也不执行任何裁剪
- 结果：<strong>58.1%</strong>，比 vanilla 的 59.2% <strong>低 1.1 分</strong>
- → <strong>一个悖论</strong>：vanilla 最终自己也不用工具了，但它<strong>比从不用工具的那个更强</strong>
- 作者的解读：那 \~20% 的早期工具经验<strong>不是白费的</strong>，它提供了更丰富的探索历史和学习信号，<strong>迁移到了最终那个"不用工具"的策略上</strong>

### 3.3 现象三：把工具逼到 100%，几乎没用

- 加了 DeepEyes 的 tool bonus（答对且用了工具才给加分）
- <strong>使用率 20% → 100%</strong>，但准确率只到 <strong>59.9%</strong>（+0.7）
- 换 PixelReasoner 的 curiosity reward，趋势一样（附录 B.2）
- <strong>于是问题变成：到底什么变了？</strong>——不是"用不用工具"，而是<strong>"探索有多宽"</strong>

### 3.4 诊断：两个轴上的多样性都在塌

![论文 Figure 3：文本探索多样性。四个子图分别是 distinct n-gram 比例（n 取 3、4、5、6）随训练步数的变化。vanilla（蓝）和工具奖励（红）都单调下降、互相贴合，说明推理越来越模板化；加熵正则（绿）基本维持在更高水平](/images/paper-reading/2026-10-20-dof/2026-10-20-d60-3.webp)

![论文 Figure 4：视觉探索。同一道题（问那个男人朝向的是更衣室还是婴儿车），把 50 条 rollout 产生的裁剪框叠成热力图。左（vanilla RFT）的框全压在人的上半身附近，平均框间 IoU 0.536；右（熵正则）的框铺到了婴儿车上，IoU 降到 0.356 —— 覆盖了题目真正问的物体](/images/paper-reading/2026-10-20-dof/2026-10-20-d60-4.webp)

- <strong>文本侧</strong>：只看 <strong>&lt;grounding&gt;</strong> <strong>之前</strong>那段 think span 的 n-gram 多样性。vanilla 和 tool-encourage <strong>都单调下降</strong> → 推理成了模板
- <strong>一个很实用的观察</strong>：他们做了熵探针，发现<strong>不确定性并不体现在裁剪框坐标上，而是更早体现在框之前的文字推理里</strong> → 所以要测"框之前的 think span"，不是测框
- <strong>视觉侧</strong>（取 step 40，每题采 50 条 rollout）： 
  - <strong>框的位置多样性</strong>：平均 pairwise IoU —— vanilla <strong>0.554</strong>、tool-encourage <strong>0.557</strong>、熵正则 <strong>0.494</strong>（越低越分散）
  - <strong>框的语义相关性</strong>：CLIP 分数 0.184 / 0.187 / 0.184 —— <strong>差不多</strong>
  - → <strong>工具调用多了三倍，但框还是挤在同一块地方，也没更贴题</strong>

### 3.5 方法：一个自适应熵控制器

<strong>本体就一行：</strong>

> <strong>J\_ent(θ) = J\_GRPO(θ) + λ\_t · E\[H̄(τ)\]</strong>
>
> 其中 H̄(τ) 是整条 rollout 上 token 级熵的均值。

<strong>关键是 λ 不能固定</strong>——他们试过，固定系数很脆：小了没效果，大了会生成混语言输出、重复 token 死循环。所以用<strong>比例反馈</strong>：

> <strong>λ\_t = Kp · \[H\_target − H\_t\]\_+</strong>，<strong>H\_target = 0.9</strong>，<strong>Kp = 0.03</strong>

- <strong>\[·\]\_+ = max(·, 0)</strong>：<strong>只在当前熵低于目标时才加压，高于目标就是 0</strong>——不会把已经够多样的训练再往上推
- 结果：<strong>62.9%</strong>，工具使用率照样掉到 <strong>3%</strong>

<strong>这个设计挺讲究的一点</strong>：它<strong>不奖励工具、也不惩罚工具</strong>，只奖励"别太确定"。工具使用率是<strong>自然演化</strong>出来的，不是被优化的目标。

## 四、实验

### 4.1 主结果：两条曲线的分裂

<strong>工具使用率和准确率可以完全脱钩</strong>——见 Figure 2：(a) 控制使用率，准确率几乎不动；(b) 不控制使用率、只调多样性，准确率跳。

### 4.2 消融：熵正则的收益依赖工具

<strong>这是全文最硬的一个消融（§3.5）</strong>：

> <strong>禁工具 + 熵正则 = 57.8%</strong>，<strong>不比禁工具的 58.1% 高</strong>，也远低于"能用工具有熵正则"的 62.9%。

→ <strong>不是"熵高就好"，而是"熵高 + 能去探索更多视觉证据"才好。</strong>工具不可用时，加大探索压力可能<strong>中性甚至有害</strong>。

### 4.3 泛化：只有熵正则两榜都涨

| 方法 | 3DSRBench（专用） | CV-Bench-3D（通用） |
|-|-|-|
| Qwen2.5-VL 7B（通才基线） | 48.4 | 82.9 |
| DeepEyes（零样本工具 agent） | 51.6 | 76.7 |
| Mini-o3（零样本工具 agent） | 54.5 | 77.6 |
| SpatialReasoner（专家参考） | 60.3 | 80.3 |
| vanilla RFT | 59.2 | 76.7 |
| 加工具奖励 | 59.9 | <strong>74.5</strong>（掉） |
| <strong>加熵正则</strong> | <strong>62.9</strong> | <strong>78.8</strong> |

- <strong>只有熵正则同时在专用榜和通用榜上改善</strong>
- 另两种方法在 CV-Bench-3D 上都<strong>掉到预训练权重（77.6）以下</strong>——<strong>专用能力涨了，通用能力被牺牲</strong>（典型的"跷跷板"）
- <strong>对比专家模型</strong>：SpatialReasoner 是<strong>显式把 3D 坐标塞进文字推理</strong>才做到 60.3，而这篇<strong>没有任何空间监督、也没用显式 3D 表示</strong>就做到 62.9

### 4.4 跨模型 / 跨任务（Table 4）

换 <strong>OpenThinkIMG</strong> + <strong>异构工具集</strong>（OCR、目标检测、分割、点定位、画轴），在医学 <strong>VQA-RAD</strong> 上：

| 方法 | VQA-RAD 准确率 |
|-|-|
| vanilla RFT | 46.34 |
| 工具奖励 RFT | 47.23 |
| <strong>熵正则</strong> | <strong>48.78</strong> |

��势复现：<strong>工具坍缩、逼工具无效、熵正则最好</strong>。说明这个动态<strong>不只属于裁剪这一种工具、也不只属于 3D 空间推理</strong>。

## 五、Limitations

### 论文自述的（只有两处，且都是训练工程）

- <strong>① 训练 100 步之后就震荡</strong>，验证集不再稳定提升——所以只报 100 步内的结果
- <strong>② DAPO 动态采样的开销</strong>：当一个 group 出现退化 rollout（比如所有 reward 一样）就会整批重采，若一步内重采超过 10 次，wall-clock 成本急剧上升，只能终止

<strong>⚠️ 没有独立 Limitations 章节</strong>，也<strong>没有讨论方法本身的适用边界</strong>——比如"如果任务必须靠工具才能做（HR-Bench 8K 那种不看就看不见的），工具 fade 会不会变成损伤？"这个问题全文没碰。

### 我读出的 6 条

1. <strong>⭐ 增益不大，而且全文没有方差</strong>：59.2 → 62.9（+3.7），VQA-RAD 46.34 → 48.78（+2.4）。<strong>没有一个误差棒、没有报种子数、没有显著性检验</strong>。考虑到他们自己说"100 步后震荡"，seed 方差很可能吃掉相当一部分增益
2. <strong>⭐ "脚手架"这个核心论点，唯一的直接证据是 1.1 分</strong>：禁工具 58.1 vs vanilla 59.2。用 1.1 分（无方差）去支撑"早期工具经验塑造了表示、并迁移到无工具策略"这种<strong>机制性主张</strong>，证据强度明显不够
3. <strong>"同样是低使用率，一个叫 collapse 一个叫 fade"——逻辑有循环</strong>：vanilla 塌到 2% 是"病理"，熵正则塌到 3% 是"自然退场"。<strong>指标上两者无法区分，区分完全靠准确率</strong>。这就有点循环论证的味道（结果好 = 退场，结果差 = 坍缩）
4. <strong>视觉多样性只测了一个 checkpoint</strong>：mIoU 0.494 vs 0.554 是在 <strong>step 40</strong> 这一个点上测的，且只证明了<strong>相关性</strong>——没有证明"熵正则 → 视觉探索变宽 → 准确率提升"这条因果链
5. <strong>主实验单一底座、1.2k 数据</strong>：全部建立在 Mini-o3 一个 checkpoint 上。跨模型验证只有一个医学 VQA 的补充，而且<strong>工具集、任务、数据全变了</strong>——没法区分"方法可迁移"还是"这个任务恰好受益"
6. <strong>未给硬件与训练细节</strong>：<strong>没有 GPU 型号/数量、没有训练时长</strong>，只给了 100 步、1.2k 样本。复现成本无法估计

## 六、前文对照

> 🔗 <strong>一句话定位</strong>：这篇和 <strong>iVGR（10/14）</strong>从两个相反的方向得到<strong>同一个结论</strong>——<strong>接地的价值在训练期，不在推理期</strong>。iVGR 说"训练时保留报框、推理时不报"，这篇说"训练时必须有工具、推理时可以不用"。

### 6.1 与 iVGR（10/14）：同一结论的两个入口

|   | iVGR | 本篇 |
|-|-|-|
| 争议对象 | 推理链里要不要<strong>写坐标框</strong> | 推理时要不要<strong>调裁剪工具</strong> |
| 发现 | 写框反而更差（75.7 vs 74.7） | 不调工具反而更好（工具自然 fade） |
| 但训练期 | <strong>必须</strong>训接地流（只训文字流 69.1 &lt; 只训接地流 71.1） | <strong>必须</strong>能调工具（禁掉掉 1.1 分） |
| 结论 | 接地能力要内化进文字推理 | 工具是训练期脚手架 |

<strong>这两篇合起来，对"think with image"这个领域构成一个相当强的判断</strong>：<strong>推理期显式接地/调工具，收益远小于大家以为的；它的真正作用是在训练期把探索打开。</strong>（差别在于：iVGR 的框是<strong>写出来</strong>的，本篇的框是<strong>被执行</strong>的——本篇的证据更强，因为工具真的改变了模型看到的东西。）

### 6.2 与 AFIP（10/16）：一个想"推理期补"，一个说"训练期做"

AFIP 的路线是<strong>推理时手动把视觉注意力补回去</strong>；本篇的结论恰好相反——<strong>推理期的手动补丁，不如训练期把探索做开</strong>。而且本篇还给了 AFIP 那类方法一个更根本的质疑：<strong>如果模型最终能不用工具、不补注意力就做对，那推理期的干预是不是在治一个训练期就该解决的问题？</strong>

### 6.3 与 EAPO（10/15）：都在谈"探索"，但在不同空间

- <strong>EAPO</strong>：agent 在<strong>环境里</strong>该不该多试几步 → 结论是"要有的放矢"，靠<strong>奖励 + 分组</strong>
- <strong>本篇</strong>：agent 在<strong>推理和视觉两个空间</strong>里探索得够不够宽 → 结论是"多样性比频率重要"，靠<strong>熵控制器</strong>
- <strong>共同点</strong>：都把"探索"当成训练期的核心变量，而不是推理期的行为目标
- <strong>差别</strong>：EAPO 改的是<strong>信用分配</strong>（奖励 + 分组），本篇改的是<strong>探索压力</strong>（熵）。<strong>这是两个不同的旋钮</strong>

### 6.4 在「分锅 / 控制变量」谱系里的位置

lib 之前的"分锅家族"（BSBT 模态 / PCD 因果阶段 / GiGPO 时间步 / POLIA 视觉物体 / π-Distill 师生角色 / iVGR 跨数据流 / EAPO 动作类型×访问深度 / AFIP 注意力头）全都在回答<strong>"这个功劳该记给谁"</strong>。

<strong>本篇换了一个问题</strong>：不是"功劳记给谁"，而是<strong>"训练时该给多少自由度"</strong>。所以它补的是<strong>另一个维度</strong>——<strong>熵 / 探索压力</strong>。这一点挺重要：<strong>信用分配做得再准，如果 rollout 早就坍缩成一模一样，也没多少功劳可分。</strong>

### 6.5 与用户的 Coord-OPD：直接对得上

Coord-OPD 自己的数据里有两个一直没解释清楚的现象：

- <strong>"学生学会了果断的工具策略"</strong>——crop 率在三个榜上稳定 93\~97%，而 GT-SFT 之后反而打平（抛硬币）
- <strong>工具价值因榜而异</strong>——V\* 上 +14.1，TreeBench 上 +2.96 甚至 S0\_T 是 −2.47

<strong>本篇给出了一个自洽的解释框架</strong>：<strong>工具的价值主要在训练期</strong>（把探索打开、把细粒度证据带进学习信号），<strong>推理期是否继续用是次要的</strong>。这正好解释了"OPD 装上的是果断的工具策略"——它是训练动力学的产物，不是推理期的目的。<strong>而且它给出了一个可测的预测</strong>：COR-OPD 的学生如果在训练期 rollout 多样性更高，即使推理期 crop 率下降，成绩也可能更好。

## 七、启发与待跟进

### 启发

1. <strong>「工具使用率」不是好指标，甚至是坏指标</strong>：2% 叫 collapse、3% 叫 fade，指标上完全一样。<strong>别去优化工具调用率</strong>——这是全文最直接可用的一条
2. <strong>诊断不确定性要看"框之前的文字"，不是框坐标</strong>：他们做熵探针发现，不确定性主要表达在 <strong>&lt;grounding&gt;</strong> 之前的 think span 里。这对<strong>任何"先想再调工具"的 agent 都适用</strong>，也是加熵正则时该盯的位置
3. <strong>熵系数必须自适应</strong>：固定值太脆（小了无用、大了生成崩坏）。<strong>λ\_t = Kp·\[H\_target − H\_t\]\_+</strong> 是个即插即用的控制器，一行代码，且天然"只补不推"
4. <strong>多样性要分两个轴测</strong>：文本侧 n-gram ratio、视觉侧裁剪框的 pairwise IoU。<strong>这套诊断很便宜</strong>（只需采样 + 统计），可以做成训练时的实时监控
5. <strong>⚠️ 读"scaffolding"这类机制性主张时，先看它唯一的直接证据有多大</strong>：这里只有 1.1 分，而且没有方差
6. <strong>通用能力的跷跷板是真实存在的</strong>：vanilla 和 tool-encourage 都把 CV-Bench-3D 从 77.6 拉到 76.7 / 74.5。<strong>只报专用榜的 agent 论文，都该被问一句"通用榜呢"</strong>

### 待跟进（按性价比）

1. 【最贴合自己主线】<strong>在 Coord-OPD 的 crop/zoom 训练里加上 λ\_t = Kp·\[H\_target − H\_t\]\_+</strong>，看能否复现"探索变宽 + 工具使用率自然下降 + 准确率上升"。这是<strong>一行代码级的改动</strong>，且直接对应他们尚未解释的"工具价值因榜而异"
2. 【最便宜】<strong>把双轴多样性诊断（n-gram + 框 IoU）做成训练监控</strong>：训练时每隔 N 步采一批 rollout，看两条曲线是否在塌。塌了就是过拟合到模板的早期信号
3. <strong>验证那 1.1 分的脚手架证据</strong>：禁工具 vs 不禁，<strong>多种子</strong>重跑。如果 1.1 分在种子间不稳，这个核心论点的证据基础要重写
4. <strong>在"必须用工具"的任务上测</strong>（HR-Bench 8K 这类，不裁剪根本看不清）——这时"工具 fade"会不会从"自然退场"变成"能力损伤"？这是论文完全没碰的边界
5. 【方法论对照】<strong>熵正则 vs 直接提高采样温度</strong>：两者都在增加探索，区别在哪？如果温度就够了，这个方法的价值要打折
6. <strong>对齐 over-turn masking 的口径</strong>：他们的"超预算 rollout 排除出优势计算、不判失败"，与 Coord-OPD 里踩过的 <strong>exceeded\_crop\_budget</strong> 处理是否一致——这直接关系到"crop 率"这个指标可不可比

## 八、结论

> 🎁 <strong>今日一句</strong>：<strong>别劝 agent 多用工具。在混合效用的推理任务上，vanilla RL 会让工具使用率从 20% 塌到 2% 而准确率还在涨；把工具彻底禁掉反而掉 1.1 分；用奖励把使用率逼到 100% 只换来 0.7 分。真正的瓶颈是 rollout 多样性——文本推理越练越模板、裁剪框越练越挤在同一块。加一个自适应熵正则，成绩从 59.2 涨到 62.9，而工具照样自己退场到 3%。</strong>
>
> <strong>方法成本极低</strong>：GRPO/DAPO 加一项 λ\_t·E\[H̄(τ)\]，λ 用比例反馈自适应（H\_target=0.9、Kp=0.03），<strong>一行代码</strong>。而且它不奖励也不惩罚工具——工具使用率是自然演化出来的，不是被优化的目标。
>
> <strong>最该记住的一条</strong>：<strong>这篇与 iVGR（10/14）从两个相反方向得到了同一个结论——接地的价值在训练期，不在推理期。</strong>iVGR 说"训练时保留报框、推理时不报"，这篇说"训练时必须有工具、推理时可以不用"。两篇合起来，对"think with image"这个方向构成了一个相当强的判断。
>
> <strong>最大的保留</strong>：+3.7 分<strong>没有方差、没有种子、没有显著性</strong>；而支撑"脚手架"这个核心论点的唯一直接证据只有 <strong>1.1 分</strong>。

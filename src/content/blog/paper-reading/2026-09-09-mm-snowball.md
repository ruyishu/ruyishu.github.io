## TL;DR

**一句话：多模态模型在单轮 VQA 上已经不太幻觉了，但一进入多轮对话就现出原形——早期某一轮"看错"了一个东西，模型会把错话当事实反复引用、越编越离谱，逐渐脱离图像、只靠被污染的聊天历史硬撑（幻觉雪球 hallucination snowballing）。这篇做了两件事：① 造了第一个多轮幻觉雪球基准 MM-Snowball（4,992 条六轮对抗对话，用因果干预把"真值状态"篡改成"幻觉状态"再诱导模型走偏）——连 GPT-5 都会滚雪球（SRS 仅 23.25%）；② 提出无训练修复 CAVR——在深层表示里监测不确定性、高不确定就重新注入视觉（RVR），在输出端仲裁"带历史 vs 纯视觉"的冲突、冲突大就跳过被污染的历史（LCR），把模型锚回视觉事实。**

- **核心问题**：单轮防幻觉方法（VCD/DeCo 等）在**多轮**失效——错误的不是单轮生成，而是"错误跨轮传播放大"（E[‖ε\_{k+1}‖] > E[‖ε_k‖]）；模型逐轮忽视视觉 grounding、过度依赖被污染的文本历史
- **基准构建（AHTS）**：① 视觉原子命题 VAP（LLM 把图解析成 object/attribute/relation 三层"不可再分语义元组"= 真值状态 S_GT）② 因果干预（实体替换/属性翻转/关系反转 → 反事实幻觉状态 S_Hall）③ 六轮对抗对话模拟（Deceptive Attacker 诱导 → 四阶段：感知锚定 → 对抗分叉 → 幻觉雪球 → 视觉修正）
- **方法（CAVR，无训练 test-time 双机制）**：① **RVR**（表示级）：解码时逐层监测归一化熵 U_ℓ，超阈值 = 视觉-语言错位信号 → 当前隐藏态当 query 去注意视觉 token，把视觉记忆刷回 FFN 输出；② **LCR**（logit 级）：三流并行（full context / 纯视觉锚无历史 / 纯语言先验），JSD(视觉锚‖语言先验) 量化冲突度，冲突大则 logit 偏向视觉锚
- **结果**：MM-Snowball 让所有模型中轮（T3-5）崩落（LLaVA 跌到 <2%）；**Kimi K2.5 最抗雪球（SRS 36.95）**、GPT-5 也会中招（23.25）；CAVR 让 Qwen2.5-VL-7B 全程优于基线/VCD、T6 达 47.85
- **主题轮换**：今日**多模态推理/感知**（按序列从推理/agentic（9/8 GiGPO）切出；与 BSBT/CFPO 的"语言先验 vs 视觉"主线构成单轮→多轮完整谱系）

## 一、先看例子（大白话：幻觉怎么"滚雪球"）

> **铺垫**：你测过单轮 VQA——问一次、答一次，模型表现不错。但真实使用是**多轮对话**：先问"图里有什么"，再追问细节，再让它推断。这个场景里出现了一种单轮看不到的病：**早期某一轮看错了，后面每轮都把错话当真、越滚越大**。论文称之为"幻觉雪球"。

> **场景**（论文构建的对话）：一张交通图（红灯 + 人行横道）。

> **关键机制**：模型错的不只是"某一轮答错"，而是**把错误写进对话历史，历史反过来污染后续所有轮的视觉判断**——轮次越深，模型越依赖"文本历史"、越不"看图"。

## 二、动机：单轮防幻觉方法管不了"跨轮放大"

### 2.1 现象

- 多轮里幻觉更致命：初始错误被当成**事实锚点**，模型在其上构建越来越复杂的推断——**内部自洽但逐步脱离视觉证据**（"internally coherent but progressively detached from the visual evidence"）
- 形式化：设 ε_k 为第 k 轮语义错误，雪球 = **E[‖ε\_{k+1}‖] > E[‖ε_k‖]**——错误幅度跨轮递增

### 2.2 现有基准与方法的两层缺口

- **基准层**：POPE/MMVP/HallusionBench 全单轮——测不出"错误传播动力学"
- **方法层**：VCD/DeCo 等单轮防幻觉方法到了多轮失效（论文实测）——它们防的是"这一次生成幻觉"，防不了"历史里已经写进去的错"

### 2.3 核心问题

- *能不能造一个能精确诊断"雪球从哪一 roll 开始、在哪一步滚大"的基准，并给出不训练就能打断雪球链的修复？*

> **炸裂发现（Figure 3 的 V 形轨迹）**：几乎所有模型的中轮（T3-5）都会崩，但**强模型在 T6（被引导重新看图）能大幅恢复**——说明视觉信息没有被永久遗忘，只是被"历史污染"暂时压制；弱模型（LLaVA）则 T4 后跌到 1% 以下、救不回来。**"能不能在 T3 就打断雪球"就是 CAVR 的战场。**

## 三、方法 A：MM-Snowball 基准构建（AHTS 三阶段）

### A. 视觉原子命题（VAP）：把图变成"可篡改的真值状态"

- 图 I + 描述 c → LLM 抽取出三层**不可再分的语义元组** p=(e, α, φ)：

  - object 层：{(e_i, exist, true)}（图里有哪些实体）
  - attribute 层：{(e_i, attr, v_j)}（实体属性：颜色/数量/状态）
  - relation 层：{(e_i, rel, e_k)}（实体间关系）
- 这组被验证的原子命题 = **真值状态 S_GT**（对话正确答案的锚）

### B. 因果干预与状态扰动：造出"反事实幻觉状态"

- 对 S_GT 施加语义扰动 → S_Hall = (S_GT \ {p_target}) ∪ {p'\_hall}，三类算子：

  - **实体替换** T_sub（猎豹→豹子，视觉相似但语义不同）
  - **属性翻转** T_flip（红→橙）
  - **关系反转** T_inv（"在…上"→"在…下"）
- 关键：**不是随机噪声**，是"看起来合理"的假前提——才有诱导力

### C. 六轮对抗对话轨迹模拟

![图片展示了MM-Snowball构建框架，分为A视觉原子命题（VAP）、B因果干预造幻觉状态、C六轮对抗轨迹模拟（四阶段）三部分。A部分将图像和caption转换为视觉原子命题；B部分通过实体替换、属性翻转、关系反转等操作，从真实状态生成幻觉状态；C部分包含感知锚定（T1）、对抗分叉（T2-3）、幻觉雪球（T4-5）、视觉修正（T6）四个阶段，以六轮对话模拟幻觉生成过程，最终通过视觉修正阶段纠正错误。](/images/paper-reading/2026-09-09-mm-snowball/2026-09-09-d34-2.webp)

▲ 论文 Figure 1：MM-Snowball 构建框架——A 视觉原子命题（VAP）→ B 因果干预造幻觉状态 → C 六轮对抗轨迹模拟（四阶段）

- Deceptive Attacker（用户）诱导 + Bifurcated Responder（模型），六轮走完四阶段：感知锚定（T1）→ 对抗分叉（T2-3）→ 幻觉雪球（T4-5）→ 视觉修正（T6）
- 规模：**4,992 条 6 轮轨迹（29,952 samples）**，测试分片 2,000 条

### D. 指标（比单轮 Acc 多了两个专门指标）

- **逐轮 Acc**：GPT-5 当统一裁判（与 3 位人类专家 r>0.85）
- **VFR（视觉衰减率）**：VFR = (Acc_T1 − Acc_T5)/Acc_T1——测"视觉感知随对话深度衰减多少"（越高越糟）
- **SRS（雪球抵抗分）**：T3-T5 三连正确的轨迹占比——同时要求"拒绝假前提(T3) + 躲开记忆陷阱(T4) + 抵抗逻辑编造(T5)"

## 四、方法 B：CAVR——无训练的双机制"锚回视觉"

### 4.1 RVR（表示级视觉修正）：不确定性高了就"重新看一眼"

- 深层网络里视觉信息会**逐层衰减**，深层表示被语言先验和历史主导 → 与图像失联
- 解码时逐层监测**归一化熵** U_ℓ（=预测分布熵/最大熵，∈[0,1]）——高熵 = 语言上下文不足以确定下一个 token = 视觉-语言错位的信号
- U_ℓ 超阈值 τ 时触发**流形级视觉重追踪**：把当前隐藏态 h 当 query 去注意视觉 token V：

  - 视觉矫正项 Δ(h,V) = Σ_j φ(⟨h,v_j⟩)·v_j
  - FFN 输出 = (1−λ)·FFN(h) + λ·Δ(h,V)——**把视觉记忆刷回深层**

### 4.2 LCR（logit 级冲突修正）：三流仲裁，"历史"和"看图"打架时听图的

- 解码时并行三路预测：

  - **full context 流** P_full（图+全部历史+当前问——连贯但带历史噪声）
  - **纯视觉锚流** P_res（只有图+当前问，剥掉历史——干净视觉）
  - **纯语言先验流** P_prior（只有当前问——"盲猜"基线）
- 冲突度 τ = JSD(P_res ‖ P_prior)：视觉给出的答案和语言先验差多大
- 校正系数 α = min(β·τ, 1)，最终 logit：**L_final = (1−α)·L_full + α·L_res**

  - 冲突大（视觉说了算 vs 历史在编）→ α 大 → 跳过被污染历史、优先视觉锚
- **双机制互补**：RVR 治"深层视觉遗忘"（表示层），LCR 治"历史错误传播"（输出层）

> **三个观察**：① **熵 = 免费的视觉失联报警器**（和 REOPOLD/EOPD 用熵当不确定性代理同一工具）；② **三流分锅**——LCR 把"历史 / 视觉 / 语言先验"三个来源的 logit 显式分离再仲裁，是"分锅哲学"在解码层的应用；③ **无训练**：所有模型推理时即插即用，不用改权重。

## 六、Limitations & 批判性思考（论文有 Conclusion + 我的阅读）

1. **评测依赖 GPT-5 裁判**：虽然与人类专家 r>0.85，但"用模型判模型"在幻觉类任务上仍有系统性偏置风险（裁判本身可能吃同一套历史污染）
2. **六轮固定结构**：轨迹固定 6 轮、固定"触发-雪球-峰值"窗口——真实对话轮次/节奏任意，基准的对抗窗口假设可能高估真实雪球频率
3. **CAVR 无训练的代价**：RVR 每步多一次视觉注意、LCR 要并行三路解码——延迟开销论文没量化（无训练方法的通用软肋）；阈值 τ、强度 λ/β 是否模型相关未细报
4. **只测对话式 QA**：agent 动作场景（会"做"而不只是"说"）的雪球未覆盖——模型执行中把幻觉当事实会否更危险
5. **Kimi/GPT-5 的鲁棒来源未归因**：为什么它们抗雪球（更强的视觉-历史解耦？训练数据含更多多轮？）——论文没分析，只是"更强模型更抗"的观察
6. **单图对话**：跨多图的引用（图 A 的结论带到图 B）场景没测——那可能是更严重的雪球

> **定位差异**：
> - **vs BSBT/CFPO（感知主线）**：你 lib 的感知工作全在"单轮 + 训练时"（盲测/反事实正则）；MM-Snowball 补上"多轮 + 推理时"两个象限——完整拼出"语言先验压过视觉"在所有场景的谱系
> - **vs 已读的"无训练"方法**：AutoTool 有推理侧但不同域；CAVR 是纯解码干预——RVR 的熵监测 = REOPOLD/EOPD 的熵工具搬到解码、LCR 的三流 = 显式"分锅"（历史/视觉/语言先验谁说了算）
> - **对 OPD 主线的钩子**：雪球本质 = 模型在对话中"模式坍塌到文本历史"——如果 agent 的 OPD 蒸馏让学生学教师的**多轮轨迹**，教师自己也滚雪球的轮次就是"脏轨迹"，Δcf/熵/三流仲裁都能当"哪些历史 token 不值得蒸"的信号源

## 八、启发与待跟进

> **核心启发**：
> 1. **多轮 = 新病种**：单轮 SOTA 防幻觉 ≠ 多轮安全——**错误一旦写进上下文历史就成了"既成事实"，后面所有轮都在它上面盖楼**；评测必须测"跨轮错误传播"，只测单轮会被严重高估
> 2. **熵是表示层的"失联报警器"**：解码到深层，视觉信息逐层衰减，归一化熵超阈值 ≈ "语言编不下去了，该回头看图"——同一个"熵当不确定性代理"在训练（REOPOLD/EOPD）和解码（RVR）都能用
> 3. **三流分离 = 解码层的"分锅"**：full/视觉锚/语言先验三路 logit 显式分离再按冲突度加权——把"谁污染了答案"在输出端一次说清
> 4. **无训练方法的战略位置**：RL 防不住推理期的历史污染（训练时没有"脏历史"这个分布）——**test-time 修复和训练一样重要**

## 九、今日阅读结论

MM-Snowball 是"多模态可靠性的新体检科"（ICML 2026，复旦+南科大+浸会+华为多校厂合作）：指出单轮防幻觉的盲区——**多轮里错误会写进历史、当事实反复引用、越滚越大**（连 GPT-5 都只有 23% 的雪球抵抗率）；然后用**因果干预**造出第一个能精确诊断雪球的基准（把真值状态篡改成幻觉状态、诱导模型走偏四阶段），再用**无训练 CAVR**（熵报警的视觉重注入 RVR + 三流冲突仲裁 LCR）把模型锚回视觉。对你 lib 的感知主线，这篇补齐了"语言先验压过视觉"的**多轮 × 推理时**象限（BSBT/CFPO 是单轮 × 训练时）；而它揭示的"污染历史"问题，正是 agent OPD 做多轮蒸馏时必须处理的脏数据源——**教师滚雪球的轮次，学生凭什么学？** 这又是个现成选题。

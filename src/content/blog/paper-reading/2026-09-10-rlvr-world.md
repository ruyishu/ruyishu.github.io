## TL;DR

**一句话：世界模型（预测"做这个动作，世界会变成什么样"）一直用最大似然（MLE）训练——但那优化的是"像不像训练数据"，不是任务真正要的"预测得准不准、看起来真不真"；RLVR-World 把世界模型统一成 token 序列预测后，直接用 RLVR（可验证奖励 = 解码后预测的 accuracy/F1/LPIPS/SSIM）做后训练——文本游戏 +30.7% 准确率（1.5B 媲美 GPT-4）、网页状态预测 +15.1% F1（web agent 成功率 +18.4%）、机器人视频预测 LPIPS +9.2% 且重复伪影 -79.6%，而 RLVR 只需几百步——比 MLE 预训练快 4 个数量级。**

- **核心问题**：世界模型的训练目标（MLE/似然）与使用目标（转移预测指标）**错位**——MLE 只管"复现数据分布"，不管"预测对不对/画得像不像"；而且自回归生成里，下一个 token 的似然与最终解码帧的感知质量并不一致
- **方法**：① 把各种模态的世界模型**统一成 sequence modeling**（语言 BPE / 视频 learned visual tokenizer / 连续值量化分桶；模板构造 q(s,a) → o(s′)）② **预训练用 MLE**（Eq.2）③ **后训练用 RLVR+GRPO**：对同一输入采 G 个样本 → 模态特定解码器抽出预测状态 ŝ′ → 奖励 = 任务指标 D(ŝ′, s′)（带符号，MSE/LPIPS 取负、accuracy/F1 取正）→ GRPO 组相对优势更新（Eq.1）
- **结果**：text game 7.11%→**63.24%**（1.5B）/ 7B 65.53% 超 GPT-4 64.76%；web page F1 11.83%→**65.11%**、web agent 12.06%→**14.29%**；RT-1 机器人多步预测 LPIPS 相对 **+9.2%**、重复率 48.6%→**9.9%**（-79.6%）；MLE 要 10⁴ 步量级、RLVR 只要 10⁰ 步量级
- **主题轮换**：今日**世界模型**（按序列从多模态推理/感知（9/9 MM-Snowball）切出；与 9/1 WPT、9/2 DeltaWorld 构成世界模型三连——"怎么用/怎么做/怎么后训练"）

## 一、先看例子（大白话：MLE 训的"像"，不等于任务要的"对"）

> **铺垫**：世界模型 = "给你当前状态 s 和一个动作 a，预测下一个状态 s′"（你熟悉的那套）。它可以写成文本（"开灯后灯的状态变成 on"）、也可以写成视频（机械臂下一步动作后画面会怎样）。**训练它的传统方式是最小化似然（MLE）——让预测的 token 概率尽量贴近训练数据。**

> **场景**：让模型预测"打开抽屉后，画面会变成什么样"。**MLE 训练会发生什么**：模型学会"让下一个 token 的概率最高"——但**我们真正在乎的不是每个 token 的概率，而是解码出来的那几帧画面像不像真实未来**。这两个目标并不一致：一个 token 的似然提升，可能对最终画面的感知质量（LPIPS/SSIM）毫无贡献，甚至有害。**另一个典型病**：视频世界模型在 MLE 下会**重复**——预测出来的帧卡住不动（重复率 48.6%）——因为"复现最可能的下一帧"退化成"抄上一帧"最省事。**RLVR-World 的做法**：把"解码后的预测"拿去和真值比，**直接拿任务指标当奖励**（LPIPS 好=奖励高、F1 高=奖励高），用 GRPO 优化——训练目标和使用目标第一次对齐了。

## 二、动机：代理目标与任务目标错位

### 2.1 病灶

- 世界模型越来越强（架构、规模、模态都在涨），但训练目标仍是 **MLE 这类代理目标**（surrogate objective）：`J_MLE(θ) = log p_θ(o(s′) | q(s,a))`（Eq.2）
- **代理 ≠ 目标**：MLE 优化"数据似然"，而任务要的是"转移预测指标"——语言域是准确率/F1，视觉域是 LPIPS/SSIM/PSNR
- 后果：模型在似然上很好，但在"预测得对、画得像"上仍有明显缺陷（视频重复、状态预测犯傻）

### 2.2 为什么不能靠调 MLE 解决

- 似然是**逐 token 的局部目标**，感知质量是**整帧的全局指标**——两者的优化方向不一致（与 RL-Cap #30 的结构同源：代理目标 ≠ 想要的能力）
- 需要一种**直接优化目标指标**的后训练方式——这正是 RLVR 在推理模型上做的事（可验证奖励 + RL）

### 2.3 核心问题

- *能否把 RLVR 从"推理任务"推广到"生成式世界模型"：把可验证的预测指标当奖励，直接后训练世界模型？*

> **炸裂对比（量级差）**：MLE 预训练要 **10⁴ 步量级**，RLVR 后训练只需 **10⁰ 步量级**（几百步）——**4 个数量级**。因为 RLVR 的奖励是任务指标的**直接测量**，梯度方向与目标一致；而 MLE 是绕远路的代理。这同时也呼应 RL-Cap 的观察：RLVR 在"目标可验证且稠密"时，效率高得惊人。

## 三、方法：把世界模型统一成序列，用指标当奖励

![图片展示了RLVR-World框架中语言世界模型和视频世界模型的结构。语言世界模型通过BPE分词、Tokenization、Language World Model、GRPO等步骤，最终得到可验证奖励（Accuracy/F1 score等）；视频世界模型则由Visual Encoder量化、Visual Decoder解码、GRPO等环节构成，产出MSE/LPIPS/SSIM等可验证奖励。该图与上下文紧密相关，直观呈现了论文中提到的统一各模态、用decoder-only Transformer的next-token prediction进行序列建模的方法。](/images/paper-reading/2026-09-10-rlvr-world/2026-09-10-d35-2.png)

▲ 论文 Figure 2：RLVR-World 框架——(a) 语言世界模型（BPE → GRPO → Accuracy/F1 奖励）(b) 视频世界模型（visual tokenizer → GRPO → MSE/LPIPS/SSIM 奖励）

### 3.1 问题形式化（Eq. 4.1）

- 世界模型模拟的环境是 MDP `M = (S, A, p, r, γ)`；世界模型的本质是学**转移分布** `p(s_{t+1} | s_{t-k+1:t}, a_{t-k+1:t})`（支持高阶 Markov）
- 奖励可视为状态的扩展维度，所以焦点放在"学转移"

### 3.2 世界模型 = 序列建模（统一各模态）

- 用 decoder-only Transformer 的 next-token prediction 统一所有模态：

  - 语言：BPE 分词
  - 图像/视频：**学出来的 visual tokenizer**（VQGAN 风格，per-frame）
  - 低维连续值（本体感觉）：**量化到固定区间的均匀 bin**
- 用模板把 `(s, a)` 拼成"问题" q(s,a)、把 `s′` 当作"回答" o(s′)——和 LLM 的 prompt/response 完全同构

### 3.3 预测指标 = 可验证奖励（核心）

- 对输入 q(s,a) 采一组样本 `{o_i}_{i=1}^G` → 用**模态特定解码**抽出预测状态 ŝ′\_i（语言：规则抽取器；视频：visual decoder）
- 奖励 = 与真值 s′ 的任务指标（Eq.3）：`R_i = sign(D) · D(ŝ′_i, s′)`

  - D 是任务指标：MSE/LPIPS/SSIM（视觉，越小越好 → 符号取负）或 Accuracy/F1-score（语言，越大越好）
- 用 **GRPO**（Eq.1）组相对优势更新（clip + KL 惩罚），不用 value function

### 3.4 三条 Remarks（论文自述的设计哲学）

1. **不求解原环境的 MDP**，而是把"下一状态预测"本身当成另一个 MDP 来 RL 优化（避免"在世界模型里做规划"的复杂度）
2. 框架通用：输入输出序列与奖励函数都可按域定制
3. **不绑定 GRPO**：兼容各种 RL 算法

## 四、实验

### 4.1 语言世界模型 · 文本游戏状态预测（Table 1 全数据）

| 模型（ByteSized32-State-Prediction，76,369 转移/31 游戏） | Unchanged ↑ | Changed ↑ | Overall ↑ |
| --- | --- | --- | --- |
| Base（R1-Distill-Qwen-1.5B） | 11.98% | 0.08% | 7.11% |
| SFT | 38.88% | 24.21% | 32.87% |
| **+ RLVR-World（binary 奖励）** | 73.57% | 33.14% | **57.01%** |
| **+ RLVR-World（task-specific 奖励）** | **83.66%** | **33.80%** | **63.24%** |
| Base（R1-Distill-Qwen-7B）+ SFT | 65.94% | 31.32% | 51.76% |
| **+ RLVR-World（7B）** | 83.08% | **40.33%** | **65.53%** |
| GPT-4（论文引用基线） | 73.90% | 51.60% | 64.76% |

- **亮点**：1.5B 模型从 7.11% → 63.24%（**+30.7% 相对准确率的来源**）；7B RLVR 版 **65.53% 超 GPT-4 的 64.76%**；"task-specific 奖励"（按域定制）优于简单 binary 奖励
- 任务难度体现在 Changed 子集（真值状态确实变了的部分）：所有模型都在这子集上吃力（GPT-4 也才 51.6%）——但 RLVR 提升最明显

### 4.2 语言世界模型 · 网页状态预测 + Web Agent（Table 2 全数据）

| 模型（R1-Distill-Qwen-1.5B） | Precision ↑ | Recall ↑ | F1 ↑ | Web Agent 成功率 ↑ |
| --- | --- | --- | --- | --- |
| Base | 15.59% | 15.70% | 11.83% | n/a |
| SFT | 48.99% | 56.05% | 49.94% | 12.06% |

- 奖励 = 预测条目变化与真值的 F1；下游价值：**用强化后的世界模型做 web agent 的模型预测控制（MPC）**——成功率 12.06% → 14.29%（+18.4%，WebArena）

### 4.3 视频世界模型 · RT-1 机器人轨迹预测（Table 3 全数据）

| 任务 / 模型 | Repetition ↓ | MSE ↓ | PSNR ↑ | SSIM ↑ | LPIPS ↓ | ∆ |
|-|-|-|-|-|-|-|
| 单步 · Base | n/a | 0.336 | 25.3 | 81.7 | 13.0 | — |
| **单步 · RLVR-World** | n/a | **0.287** | **25.9** | **83.1** | **12.2** | MSE +14.3% / LPIPS +6.0% |

### 4.4 应用 · Real2Sim 策略评估（Figure 5）

- **场景**：真实机器人的策略评估很贵（跑真机）——用视频世界模型当"仿真器"，把真实策略放进世界模型里跑
- 对比手工仿真器 SIMPLER（VA/VM 两个变体）：**世界模型的"真实-仿真成功率差"更小**（曲线更贴近 y=x 对角线），RLVR 版进一步优于 Base
- 这就是"世界模型当仿真器"的实用价值：**评估的成本从真机转移到模型，而 RLVR 让这个替代品更可信**

## 五、Limitations & 批判性思考（论文自述 5 条 + 我的阅读）

1. **性能天花板（论文自述）**：RLVR 训练"几百步就收敛"——继续提升需要深挖模型/数据/算法瓶颈（好消息是便宜，坏消息是提前撞墙）
2. **OOD 泛化未知（论文自述）**：RLVR 让 LLM 在训练域外泛化的好处，能否延伸到世界模型（尤其对**没见过的动作**做反事实推理）——未验证
3. **依赖通用世界模型生态（论文自述）**：当前视频世界模型是"同数据集两阶段"，要等到社区做出通用视频世界模型，才能解锁完整的"大规模预训练 → SFT → RL 后训练"范式
4. **扩散模型世界模型未纳入（论文自述）**：核心思想 model-agnostic，但扩散模型的 GRPO 是并行工作，本文只覆盖自回归 token 模型
5. **奖励仍是"经典指标"（论文自述）**：LPIPS/SSIM 比 MLE 更对齐任务，但仍不能完全代表"用户想要的质量"——物理规则、时序一致性等更复杂的奖励设计待做
6. **（我的阅读）指标本身可能是坏目标**：用 LPIPS 当奖励 = 让模型优化"人类视觉相似度"，可能诱发新的"奖励 hacking"（比如生成感知上相似但物理上错的帧）——论文没有做"指标作弊"检验
7. **（我的阅读）语言域的胜利有蒸馏成分**：web page 任务的 SFT 数据来自 WMA 的 CoT，RLVR 的增益叠加在其上——"RLVR 独立贡献"的纯净度不如 text game 那条线

| 28 | DeltaWorld | delta token 高效世界模型（架构/表征） | **正交互补**：DeltaWorld 解决"世界模型的表示与效率"（怎么做小），RLVR-World 解决"世界模型的训练目标"（怎么训对）——架构与目标两个维度 |
| 30 | RL-Cap（分析篇） | RLVR 只提采样效率、不扩能力边界 | **关键对照**：RL-Cap 说 RLVR 在**稀疏结果奖励**下只重排；RLVR-World 用的是**稠密的、可验证的预测指标**——奖励一稠密，RLVR 立刻从"重排"变成"实打实的提升"（+30.7%）——两篇合读把 RLVR 的适用边界划清楚了 |
| 32 | GiGPO | GRPO 的 advantage 粒度改进（step 级） | 同为 GRPO 系改造：GiGPO 改"怎么分配优势"（算法侧），RLVR-World 改"奖励从哪来"（目标侧）——两个正交的改进轴 |
| **34** | **RLVR-World（本作）** | **用 RLVR 后训练世界模型（指标当奖励）** | **NeurIPS 2025，清华 THUML：MLE 是代理目标，RLVR 直接优化任务指标——语言/视频世界模型全覆盖，快 4 个数量级** |

> **定位差异**：
> - **vs RL-Cap（#30，最有价值的对照）**：RL-Cap 用 pass@k 证明"RLVR 只重排不扩界"——但那是**稀疏结果奖励**（对错 0/1）下的结论；RLVR-World 用**稠密可验证指标**（LPIPS/F1）当奖励，立刻拿到 +30.7% 的实打实提升——**两篇一起读，RLVR 的边界清晰了：奖励稠密且与目标一致时，RLVR 是真提升；奖励稀疏且只是结果代理时，RLVR 只是重排**
> - **vs WPT/DeltaWorld（世界模型三连）**：9/1 WPT=世界模型怎么**用**（蒸馏进策略）、9/2 DeltaWorld=世界模型怎么**做小**（delta token）、今天 RLVR-World=世界模型怎么**训对**（RLVR 后训练）——"用/做/训"三件事齐了
> - **对 OPD 主线的钩子**：RLVR-World 的奖励是"解码后**任务指标**"，OPD 的监督是"教师分布"——**两者都是"外部信号驱动生成"**。一个自然的问题：OPD 能不能也用"可验证任务指标"当奖励（而不是教师分布）？那就是"RLVR 版的蒸馏"——你 lib 里的 Distilled RL 已经在单轮推理上试过，世界模型给了它新的舞台

## 七、启发与待跟进

> **核心启发**：
> 1. **代理目标与任务目标必须区分着看**："最大化似然"是手段，"预测得像/对"是目的——**当两者错位时，换目标比换架构更有效**（RLVR 几百步 > MLE 万步）
> 2. **RLVR 的真正适用条件浮现**：奖励**稠密 + 可验证 + 与任务目标一致** → 真提升；奖励**稀疏 + 只是结果代理** → 只重排（RL-Cap 的结论）。这个判据可以拿来评估任何 RL 后训练方案
> 3. **世界模型的后训练范式正在成形**：预训练（MLE）→ SFT → RL 微调，和语言模型走过的路一模一样——**"世界模型 = 生成模型 + 后训练"是接下来的主线**
> 4. **后处理治表、后训练治本**：Base+去重规则只能让重复率归零但质量不涨（MSE 0.593）；RLVR 从根上把预测质量提上去（0.486）——**遇到生成质量问题，先问"能不能改训练目标"而不是"能不能加个后处理"**

## 八、今日阅读结论

RLVR-World 把"后训练"这把刀从推理模型递到了**世界模型**手上（NeurIPS 2025，清华 THUML）：诊断出世界模型的根本错位——MLE 这个代理目标优化的是"数据似然"，而任务要的是"预测指标"（准确率/F1/LPIPS）；解法是把世界模型统一成序列建模后，**直接用解码后预测的任务指标当可验证奖励做 RLVR（GRPO）**。结果：文本游戏 +30.7%（1.5B 媲美 GPT-4）、网页状态 F1 +15.1%（web agent +18.4%）、机器人视频 LPIPS +9.2% 且重复伪影 -79.6%——而 RLVR 只要几百步，比 MLE 快 4 个数量级。对你 lib，这篇的意义是双重的：**世界模型三连（用/做/训）补上最后一环**，同时它和 RL-Cap 构成一组绝妙的对照——**RLVR 在稀疏结果奖励下只重排（RL-Cap），在稠密可验证指标下是真提升（本篇）**，这条判据值得写进你评估任何后训练方案的清单。

> **今日一句**：世界模型一直被"最大似然"教着复现数据——但我们要的不是"像训练数据"，而是"预测得准、画得真"；把解码后的预测直接拿去和真值比、把指标当奖励做 RLVR，几百步就超了 MLE 的几万步。论文：arXiv:2505.13934（NeurIPS 2025）· 代码数据模型全开源 · 笔记挂在 lib 中 · 2026-09-10

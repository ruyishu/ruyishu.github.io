## TL;DR

<strong>一句话：VLM 语义很强、空间很弱；现有两条路都不好——塞 3D 点云/深度要专用硬件，外接 spatial encoder 又会在大规模 3D 数据微调时把通用能力打坏。SpatioLM 的做法是：把视觉编码器和 LLM 全部冻结，只挂一个约 3 亿参数的「空间-视觉模块」旁路，用 Depth Anything V3 的伪深度和相机射线当教师把它训出来；推理时这个旁路只在 prefill 阶段前向一次，之后照常 KV-cache 解码，零额外开销。VSI-Bench 拿到 71.6，是第一个破 70 的模型。</strong>

- <strong>最刺眼的一组数（Table 2，VSI-Bench Avg）</strong>：<strong>SpatioLM-SenseNovaSI-8B 71.6</strong> —— 压过 <strong>Cambrian-S-7B 67.5</strong>、<strong>SenseNovaSI-8B 68.7</strong>、<strong>GS-Reasoner 64.7</strong>、<strong>Qwen3-VL-235B-A22B 51.0</strong>、<strong>Gemini-2.5 Pro 51.5</strong>、<strong>GPT-4o 34.0</strong>
- <strong>深度感知涨得更夸张（Table 1）</strong>：同一底座 SenseNovaSI-8B，指标 δ&lt;1.25 ↑ —— MD-S <strong>52.6 → 83.5</strong>、MD-M <strong>37.7 → 69.0</strong>、DA-2K <strong>71.8 → 83.8</strong>、DR <strong>17.5 → 41.8</strong>
- <strong>只训 \~300M 参数</strong>：<strong>K=6 个 SV-Block × 每个 50M</strong>，视觉编码器与 LLM 全程冻结
- <strong>推理零额外开销</strong>：DPT 头评测时可整块去掉；SV-Module 只在 <strong>prefill 阶段前向一次</strong>，之后就是标准 VLM 解码 + KV cache
- <strong>两个关键设计</strong>：① <strong>取 ViT 第 16 层（共 24 层）的中间层 token</strong> 当输入，理由是中间层比最后一层保留更丰富的空间信息 ② <strong>zero-initialized projection</strong> 把旁路注入 LM block，保证训练起步时对主干零扰动
- <strong>监督有两个来源</strong>：<strong>VTS</strong>（用 Gram 矩阵把 SV-Block 特征对齐到 <strong>Depth Anything V3</strong> 教师特征的 token 结构）+ <strong>DGS</strong>（双 DPT 头预测稠密深度与相机射线图）。总损失 <strong>L = 0.6·L\_L + 0.2·L\_d + 0.2·L\_g</strong>
- <strong>通用能力是"掉得少"而不是"不掉"</strong>（Fig 6，相对各自底座）：<strong>SpatioLM-SenseNovaSI-8B</strong> 掉 MMMU −1% / VideoMMMU −2% / VideoMME −3% / MVBench −7%；而对照的 <strong>Spatial-MLLM</strong> 分别掉 −8% / −67% / −8% / −23%
- <strong>下游能迁到操作任务</strong>：LIBERO 上 Discrete <strong>79.2 → 91.0</strong>、Continuous <strong>95.3 → 96.3</strong>
- <strong>仓库是本系列目前最完整的</strong>：<strong>Apache-2.0</strong>、53 star、7 commits、训练入口 <strong>spatiolm sft3d</strong>（基于 <strong>MS-SWIFT</strong>）、评测基于 <strong>LMMs-Eval</strong>、权重与数据都在 Hugging Face
- <strong>⚠️ 论文自述 3 条限制</strong>：① 重度依赖 Depth Anything V3 的<strong>伪标签</strong>，噪声给 3D 理解设上界 ② <strong>几何监督与时间动态冲突</strong>，MVBench 上动作计数/移动方向掉分 ③ 安全关键场景建议不要直接部署
- <strong>主题</strong>：<strong>多模态推理 / 感知</strong>（本周第 2 篇；昨天是 DoF，讲"工具是训练期脚手架"，今天这篇走的是完全相反的路线——不用工具，把能力训进模型内部）

## 一、先看例子（大白话：怎么让一个「会说话不会看空间」的模型学会量距离？）

> 💡 <strong>铺垫</strong>：现在的 VLM 能描述图里有什么、能回答常识问题，但<strong>问到「这张床有多长」「厕所在床的前右还是后左」就崩了</strong>。原因很直白：<strong>它是在海量「图文对」上预训练的，学到的是语义，不是几何。</strong>

> <strong>把这件事想成教一个文学系学生做木工测量：</strong>
>
> <strong>现成的两条路：</strong>
>
> <strong>路 A（塞 3D 数据）</strong>：给他配一台激光测距仪、一副深度眼镜。<strong>测得准，但离开这些设备就废了</strong>——而且线上服务不可能给每个用户配一台。
>
> <strong>路 B（换一副眼镜）</strong>：给他装一个专门看深度的「空间眼镜」模块。<strong>能用，但装上去之后他原来的文学本事也退化了</strong>——因为眼镜和大脑要重新磨合，一磨合就把原有能力磨掉了。
>
> <strong>SpatioLM 的路 C</strong>：<strong>不动他的大脑，也不给他换眼镜</strong>，而是在大脑旁边<strong>挂一个小本子</strong>——这个本子只做一件事：把眼睛看到的画面换算成「深度 + 光线方向」。上面写的内容用<strong>外部教材</strong>（Depth Anything V3）一笔一笔教。写熟了之后，<strong>本子上的内容可以直接喂给大脑用，而大脑一个参数都没动。</strong>
>
> <strong>关键：考试的时候，这个本子只在「读题」那一下翻一次，之后答题完全按原来的流程走 —— 所以线上几乎没有额外成本。</strong>

![论文 Figure 2：三条技术路线。(a) 融合 3D 先验——把深度图、点云或相机参数直接塞给模型，依赖传感器或辅助估计模型；(b) 融合额外的空间编码器——外接一个 Spatial Encoder，需要侵入式 3D 微调；(c) SpatioLM——从视觉编码器的中间层取 token，送进可插拔的 Spatio-Vision Module，主干完全不动](/images/paper-reading/2026-10-21-spatiolm/2026-10-21-d61-1.webp)

## 二、动机：两条现成的路，各有硬伤

- <strong>路 A · 显式几何增强</strong>（DepthLM、SpatialBot、OmniEVA、3DRS、RoboRefer、MM-Spatial 等） 
  - 做法：把<strong>深度图、点云、相机内参</strong>这些 3D 先验，从传感器或辅助估计模型拿过来，直接喂给 VLM
  - <strong>硬伤</strong>：依赖<strong>专用硬件或脆弱的预处理管线</strong>，在「只有 RGB」的开放场景里直接不可用
- <strong>路 B · 架构级改造</strong>（SpatialLLM、VLM-3R、VG-LLM、Spatial-MLLM 等） 
  - 做法：外接一个专门的 spatial encoder，或者在 3D 数据上大规模微调
  - <strong>硬伤</strong>：这不是「唤醒 VLM 内在的空间知识」，而是<strong>在外面又造了一套空间推理</strong>；更糟的是——<strong>在大规模 3D 数据上微调会破坏预训练特征分布，把通用能力打掉</strong>
- <strong>于是核心问题被定义成</strong>：<strong>怎么在不引入 3D 输入、不接第三方 spatial encoder 的前提下提升空间智能，同时保住通用能力？</strong>
- <strong>论文的三个主张</strong>：① 纯 2D 框架，从 VLM 的视觉 token 里<strong>引出</strong>隐含的 3D 几何结构 ② 可插拔、非侵入式，避免灾难性遗忘 ③ 空间感知、空间理解、下游操作三类任务都赢

## 三、方法：冻主干 + 挂旁路 + 几何蒸馏

![论文 Figure 3：SpatioLM 总览。左侧：第 i 个 Spatio-Vision Block 用交替注意力（Frame Attention 看帧内、Global Attention 看跨帧）处理从视觉编码器中间层选出的 token，经零初始化投影后注入第 j 个 LM Block；上方双 DPT 头在训练时预测深度与相机射线图，右侧是 LM Head 出文本。灰色冻结、橙色可训](/images/paper-reading/2026-10-21-spatiolm/2026-10-21-d61-2.webp)

### 3.1 主干全冻，只训 300M

- <strong>视觉编码器与 LLM 的全部参数冻结</strong>——这是「保住通用能力」的物理保证，不是靠调学习率
- 只有 <strong>SV-Module（K=6 个 SV-Block × 50M）+ 零初始化投影层</strong> 可训，约 <strong>300M</strong> 参数
- <strong>K=6、每个 50M 是默认配置</strong>

### 3.2 取「中间层」而不是最后一层

- 视觉 token 不从 ViT 最后一层取，而是取 <strong>第 16 层（共 24 层）</strong>
- 依据：<strong>中间层比最后一层保留更丰富的空间信息</strong>（引 Bolya et al. 2026 及经验分析，16/24 附近的空间嵌入最强）
- <strong>🔗 这一点和 10/19 那篇 PEZ 完美对上</strong>——PEZ 用探针证明「物理/空间表征在中间层达峰、朝输出层衰减，最后一层不保留最有信息量的结构」。<strong>PEZ 在「证」，SpatioLM 在「用」。</strong>

### 3.3 旁路怎么插进去而不打乱主干

- <strong>zero-initialized projection</strong>：注入项 <strong>Ĥm\_j\[Iv\] = Hm\_j\[Iv\] + Pz(Hg\_i)</strong>，而 Pz 初始输出为 0
- 效果：<strong>训练第 0 步时旁路对主干完全零扰动</strong>，主干看到的分布和原来一模一样，之后再由训练慢慢加上去
- <strong>交替注意力只发生在 SV-Block 内部</strong>，<strong>完全不动冻结 LLM 的因果自注意力</strong>——这是「非侵入式」的真正含义

### 3.4 两个监督信号

| 损失 | 做什么 |
|-|-|
| <strong>L\_L</strong>（α=0.6） | 标准文本交叉熵，管「答对」 |
| <strong>L\_d</strong>（β=0.2）<br>VTS | <strong>Vision Token Supervision</strong>：用 <strong>Gram 矩阵</strong>匹配（Frobenius 范数），把 SV-Block 的特征对齐到 <strong>Depth Anything V3</strong> 教师特征的 token 结构相似度——<strong>学的是「结构关系」，不是逐元素对齐</strong> |
| <strong>L\_g</strong>（γ=0.2）<br>DGS | <strong>Dense Geometric Supervision</strong>：双 DPT 头（借自 Depth Anything V3）分别预测<strong>稠密深度图</strong>与<strong>相机射线图</strong>，用伪标签监督 |

<strong>总损失</strong>：<strong>L = 0.6·L\_L + 0.2·L\_d + 0.2·L\_g</strong>

### 3.5 推理：零额外开销

- <strong>DPT 头评测时整块去掉</strong>（它只在训练时用）
- <strong>SV-Module 只在 prefill 阶段前向一次</strong>，把空间上下文编码进去
- 之后<strong>就是标准 VLM 解码 + KV cache</strong> —— <strong>不产生额外推理开销</strong>
- 这一点很关键：<strong>它不是「每次生成都多算一遍」的推理期方法</strong>，所以不会被线上延迟否决

### 4.4 下游：能迁到机器人操作

LIBERO 上 <strong>Discrete 79.2 → 91.0</strong>、<strong>Continuous 95.3 → 96.3</strong>（SpatioLM-VLA0 / SpatioLM-OFT）。<strong>说明这套空间表示不是只对答题有用的过拟合。</strong>

### 4.5 失败在哪

论文自己做了失败一致性分析：<strong>Route Planning 与底座「高度重叠失败」</strong>——这类题需要长程记忆和连续更新空间参考系，<strong>属于从底座继承下来的限制，SpatioLM 没改善</strong>。而在 Rel. Direction 上重叠明显下降，说明旁路对<strong>局部空间关系</strong>确实有效。

## 五、Limitations

### 论文自述的 3 条（§5）

1. <strong>伪标签依赖</strong>：训练重度依赖 Depth Anything V3 生成的伪标签，<strong>标签噪声给整体 3D 理解设了上界</strong>，误差会传播进学到的表示
2. <strong>运动动力学权衡</strong>：几何监督强调<strong>静态</strong>空间结构，与<strong>时间动态</strong>线索部分竞争 → MVBench 上动作计数、移动方向这类子任务掉分（Fig 6 的 −7% 就是这个）
3. <strong>安全关键场景</strong>：鉴于上面两条，建议在没有额外严格验证的情况下<strong>不要部署到安全关键应用</strong>

### 我读出的 6 条

1. <strong>⭐ 71.6 这个头条不是「通用 VLM」拿到的</strong>：它是在 <strong>SenseNova-SI-8B</strong> 之上 +2.9，而 <strong>SenseNova-SI 本身就已经是一个专门的 spatial 模型（基线 68.7）</strong>。<strong>真正意义上的通用 VLM 版（InternVL3.5-8B）只有 65.0 —— 低于 Cambrian-S-7B 的 67.5。</strong>所以「第一个破 70」成立，但「通用 VLM 也能到 70」不成立；标题里的 <strong>Towards General</strong> 有点超前
2. <strong>⭐「不用第三方 spatial encoder」只在推理期成立</strong>：训练全程用 <strong>Depth Anything V3</strong> 当教师做特征蒸馏 + 伪标签。<strong>它没有消灭依赖，只是把依赖挪到了训练期</strong>——和 iVGR（10/14）把「框」从推理挪到训练是<strong>同一个模式</strong>
3. <strong>「唤醒 VLM 固有空间知识」和「用外部教师训一个 DPT 头」是矛盾的</strong>：如果知识本来就在模型里，为什么要让它在训练时预测稠密的深度图和相机射线图？<strong>更像是「让 VLM 内部长出一个几何编码器」</strong>，而不是「唤醒」
4. <strong>600 epochs 感知 / 2 epochs 理解，配比极端</strong>：这直接解释了「深度暴涨、理解微涨」。如果目标是「通用空间智能」，<strong>这个配比本身就是问题</strong>，而不是一个细节
5. <strong>没有报方差/种子</strong>：主表都是单次结果（至少正文未见）。VSI-Bench 里 Rel. Dist. 55.7、Route Plan 47.9 这些单项并不突出，<strong>Avg 的提升有多少来自 Obj. Cnt（81.9）这类单项，需要拆开看</strong>
6. <strong>两个底座差 6.6 分（71.6 vs 65.0）</strong>：同一个方法在 InternVL3.5 上只有 65.0，说明<strong>收益高度依赖底座是否已经有空间先验</strong>。<strong>「方法有效」和「底座本来就强」必须分清</strong>

## 六、前文对照

> 🔗 <strong>一句话定位</strong>：本周两篇恰好构成「<strong>外部工具</strong> vs <strong>内部能力</strong>」的一组对照——<strong>DoF（10/20）</strong>说「工具是训练期脚手架、推理期可以不用」；<strong>SpatioLM</strong>说「根本不用工具，直接把几何能力训进模型内部」。而它和 <strong>PEZ（10/19）</strong>之间有一次非常漂亮的「证 ↔ 用」呼应。

### 6.1 与 PEZ（10/19）：一个在「证」，一个在「用」

SpatioLM 取 <strong>ViT 第 16 层（共 24 层）</strong>的中间层 token，理由是「中间层比最后一层保留更丰富的空间信息」。而 PEZ 用线性探针<strong>直接证明了这件事</strong>：物理/空间表征在<strong>约 1/3 到中间层达峰，然后朝输出层衰减</strong>，<strong>最后一层并不保留最有信息量的结构</strong>。

<strong>PEZ 是观察，SpatioLM 是工程落地。</strong>而且 SpatioLM 引用的 Bolya et al. 2026 与 PEZ 引的是同一篇 —— <strong>说明「取中间层」这件事在这个领域已经形成了共识</strong>。

### 6.2 与 DoF（10/20）：同周同领域，路线相反

|   | DoF（10/20） | SpatioLM（本篇） |
|-|-|-|
| 怎么补细节 | 给 agent 一个<strong>裁剪工具</strong>，训练期用它打开探索 | <strong>不给工具</strong>，把几何能力直接训进模型 |
| 推理期 | 工具<strong>自然 fade 到 3%</strong> | 旁路<strong>prefill 一次</strong>，零额外开销 |
| 共同点 | 重资产放在训练期 | 轻接口留给线上 |

<strong>两篇的共同点：都把重资产放在训练期，把轻接口留给线上。</strong>

### 6.3 与 iVGR（10/14）：同一个「训练期用、推理期去」的模式

| 论文 | 训练期用的强信号 | 推理期还需要吗 |
|-|-|-|
| iVGR | 显式<strong>坐标框</strong> | 不需要，内化进文字推理 |
| <strong>SpatioLM</strong> | <strong>Depth Anything V3</strong> 的深度/射线 | 不需要 3D 输入，也不需要 DPT 头 |
| DoF | 裁剪<strong>工具</strong> | 不需要（自然退场） |

<strong>这三篇连起来看，是一条很清晰的工程规律</strong>：<strong>推理期能拿到的「重」信号（框、3D、工具调用），往往在训练期最值钱，在线时最不该留。</strong>

### 6.4 与 AFIP（10/16）：同一个问题，两种成本结构

AFIP 想在<strong>推理期手动补视觉注意力</strong>（training-free，但每步都要算）；SpatioLM 的思路是<strong>训练期训进去，推理期一次前向解决</strong>。<strong>两者要解决的是同一件事（模型没看对该看的地方），但成本结构完全相反</strong>：AFIP 把成本摊到每次推理，SpatioLM 把它一次性付在训练。

### 6.5 在 lib 的谱系里

之前几篇多在「<strong>分锅</strong>」（功劳记给谁）或「<strong>奖励设计</strong>」（怎么打分）上做文章。<strong>SpatioLM 属于另一条线：参数高效微调 / 旁路注入</strong>（ControlNet、side-tuning 那一族）。它不动信用分配、不动奖励，只解决「<strong>怎么在不破坏主干的条件下加一个新能力</strong>」。

## 七、启发与待跟进

### 启发

1. <strong>「冻主干 + 旁路 + 零初始化投影」是保通用能力最省事的组合拳</strong>：只训 300M、主干全冻、<strong>zero-init 保证起步零扰动</strong>。这套组合对任何「想让 VLM 学个新能力又怕遗忘」的场景都直接可用
2. <strong>「取中间层」这条现在有理论支撑了</strong>：ViT 第 16/24 ≈ 2/3 深度。要做几何/物理类下游，<strong>别取最后一层</strong>——这是 PEZ 证的，SpatioLM 用的
3. <strong>「训练期用强教师、推理期不用」是一个反复出现的好模式</strong>：iVGR、SpatioLM、DoF 三篇独立地做了同一件事。<strong>把重资产放在训练期，把轻接口留给线上</strong>——这可能是当前 VLM 工程最值得抄的一条经验
4. <strong>但要盯住「无依赖」的措辞</strong>：SpatioLM 说「不需要 3D 输入」，实际是「<strong>推理期</strong>不需要、<strong>训练期</strong>重度依赖 Depth Anything V3」。<strong>看到这类声明，先问一句「训练期呢」</strong>
5. <strong>感知和理解要分开看</strong>：600 epochs 感知 / 2 epochs 理解 → 感知暴涨、理解微涨。<strong>如果目标是「通用空间智能」，配比本身就是结论的一部分</strong>
6. <strong>zero-initialized projection 值得单独记</strong>：它把「加旁路」这件事的风险降到最低——训练第 0 步时模型行为和原模型逐位一致，之后慢慢偏离。<strong>任何往预训练模型里插模块的场景都该这么做</strong>

### 待跟进（按性价比）

1. 【最贴合主线】<strong>把「中间层」这条搬到自己的 crop/zoom 流程</strong>：如果视觉编码器 2/3 深度携带更多几何信息，那「裁剪后重新编码」也许不如「在中间层直接取区域 token」来得省
2. 【最便宜】<strong>把「冻主干 + 旁路 + zero-init」试到一个新能力上</strong>（比如细粒度读数、表格结构、图表数值），看是否也能「只训 300M 就够」
3. <strong>核验 InternVL3.5 版为什么只有 65.0</strong>：同一个方法在两个底座上差 6.6 分，<strong>说明收益高度依赖底座是否已有空间先验</strong>。「方法有效」和「底座本来就强」必须分清
4. <strong>测「训练期教师」的边际</strong>：把 Depth Anything V3 换成更弱的教师，收益掉多少？这决定方法的真实门槛
5. <strong>做一次感知/理解的 epoch 配比对照</strong>（比如 100 vs 10），看理解榜能否更好——现在 600:2 太极端
6. <strong>VSI-Bench 单项拆解</strong>：Avg 71.6 里哪几项贡献最多？Obj. Cnt 81.9 是不是主要贡献者（这类计数题可能更吃「看得清」而不是「懂几何」）

## 八、结论

> 🎁 <strong>今日一句</strong>：<strong>VLM 空间弱，是因为它只学过图文对、没学过几何。SpatioLM 不去塞 3D 点云、也不外接空间编码器，而是把视觉编码器和 LLM 全冻住，只挂一个约 3 亿参数的旁路（6 个 50M 的 SV-Block），用 Depth Anything V3 的深度和相机射线当教师把它训出来；推理时这个旁路只在 prefill 前向一次，之后照常 KV-cache 解码，零额外开销。VSI-Bench 71.6，第一个破 70。</strong>
>
> <strong>三个设计值得抄</strong>：① <strong>取 ViT 第 16/24 层</strong>（中间层比最后一层保留更多空间信息）② <strong>zero-initialized projection</strong>（训练起步对主干零扰动）③ <strong>交替注意力只发生在旁路内部</strong>，不动冻结 LLM 的因果自注意力。
>
> <strong>最该记住的一条</strong>：<strong>它和 PEZ（10/19）完成了一次「证 ↔ 用」的接力</strong>——PEZ 用探针证明「空间/物理表征在中间层达峰、朝输出衰减」，SpatioLM 直接拿第 16 层当输入。<strong>而它和 iVGR（10/14）、DoF（10/20）一起，构成了同一条工程规律：训练期用重信号，推理期给轻接口。</strong>
>
> <strong>最大的保留</strong>：<strong>71.6 是在已经专门的 spatial 底座（SenseNova-SI，基线 68.7）上拿到的；通用 VLM 版（InternVL3.5）只有 65.0，低于 Cambrian-S-7B 的 67.5。</strong>所以「Towards General」这个定语，还得再等等。

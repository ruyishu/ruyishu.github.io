## TL;DR

**一句话：视频世界模型都太重了——每帧要预测几千个空间 token（或扩散多步去噪）；DeltaWorld 把"相邻两帧之间的变化"压成**单个 delta token\*\*，让世界模型只预测"哪里变了"而不是"下一帧长什么样"——一帧一个 token，token 数减 1024×、参数少 35×、FLOPs 省 2000×，靠"多假设训练"（一次前向出 K 个未来、只监督最像真的那个）还能生成多样的未来，稠密预测任务上全面压过 Cosmos。\*\*

- **核心问题**：判别式世界模型（DINO-world）给出确定性预测，遇到多分支未来时退化成"平均帧"（模糊、不真实）；生成式世界模型（扩散/离散自回归）能出多样未来，但一次前向一个样本、算力贵到天上
- **方法（四步递进）**：① 判别式基线（冻结 DINOv3 特征 + transformer 预测器）；② **Best-of-Many（BoM）**——用 K 个高斯噪声 query 生成 K 个未来假设，**只监督最接近真值的那一个**，一次前向出多样预测；③ 帧级压缩（每帧压成 1 个 token）——快了但单 token 装不下整帧；④ **DeltaTok（核心）**——只压缩"帧与帧的变化"成单个 delta token，预测器在 delta token 序列上做 next-token prediction，解码器用上一帧特征 + delta token 还原当前帧（视频编码的帧间压缩思想）
- **结果**：中程预测 Cityscapes mIoU 45.4→48.7（mean 45.5）、VSPW 44.8→46.8；**best-of-20 全指标超 Cosmos（2B/12B）**，而 FLOPs 少 \~2000×（Cosmos 带 7B 扩散解码器）；训练 300K 步、512×512、K=256
- **主题轮换**：今日**世界模型**第 2 弹（昨天 WPT=占用级+蒸馏落地，今天 DeltaWorld=特征空间+效率架构；连续 2 天，明日切具身智能）

## 一、先看例子（大白话：世界模型怎么"偷懒"）

> **核心直觉（视频编码类比）**：你看监控录像回放，注意力其实只在"变了的地方"——人走没走、车动没动，静止的墙和路根本不用重新看。视频压缩（H.264）早就懂这个：**不传整帧，只传"跟上一帧比哪里变了"**（帧间压缩）。DeltaWorld 把这个思想搬进世界模型：**每帧只用一个"变化 token"，世界模型只预测"接下来会变什么"，不预测"下一帧长什么样"。**

> **场景**：一个行人站在路口，你要预测 3 秒后他在哪。**判别式世界模型（DINO-world）**：直接给一个"最可能的答案"——但如果行人 30% 可能往左、30% 往右、40% 停住，模型只能给"平均值"：一个站在中间的模糊影子，**哪个都不是真的**。**老式生成式世界模型（Cosmos）**：能出多种可能（往左/往右/停住），但每种都要扩散去噪几十步或自回归几千个 token——**出一个未来都贵，出 20 个未来贵上天**。**DeltaWorld（今天）**：每帧只用一个"变化 token"（这一帧比上一帧变了啥），一次前向同时生成 K 个未来（每个对应一个"行人往左/往右/停住"的假设），**只挑最像真值的那一个来学**——便宜，而且预测的多样性是真的。

## 二、动机：判别式模糊，生成式太贵

### 2.1 判别式世界模型的病

- DINO-world 系：在冻结 VFM 特征空间预测下一帧特征，参数少、效果好——但**输出是确定性的单点**
- 未来天生多分支（行人往左还是往右？），回归损失逼着模型输出"所有可能的平均"——**预测出的帧不真实，无法支持可靠决策**

### 2.2 生成式世界模型的病

- 离散自回归：逐空间位置预测离散码（像 LLM 逐 token）——每帧几千个位置，一次前向只出**一个**未来
- 连续扩散：多步去噪——生成一个样本要几十次前向
- 结论：**"能出多样未来"和"便宜"在这个领域是二选一**

### 2.3 核心问题

- 特征空间（VFM）已经证明"预测特征比预测像素省 35× 参数"——但**怎么在特征空间里做生成（多样）又不增加算力？**
- 论文的回答：把"预测未来"从"预测下一帧"改成"预测下一帧的变化量"——**变化的维度天然远小于完整帧的维度**

> **炸裂点**：一帧 512×512 的特征图 = H×W 个 patch token（DINO 系 \~1024 个）；DeltaTok 把它压成**1 个 token**。预测从"1024 个 token 的生成"变成"1 个 token 的生成"——**1024× 的 token 减少**，这就是所有效率收益的源头。

## 三、方法：四步递进，最后一步是精髓

### 3.1 Step 0：判别式基线（DINO-world 架构）

- 冻结 VFM ϕ 逐帧编码：`x_i = ϕ(v_i)`（H×W 个 patch token/帧）
- 预测器 f：单个可学习 query q 对历史帧 X_1:t 做交叉注意力，输出未来帧每个位置的预测特征（Eq.1）
- smooth L1 + teacher forcing；推理时可自回归 rollout

### 3.2 Step 1：Best-of-Many（BoM）——把判别式变生成式

- 用 K 个高斯噪声 query `q^k ~ N(μ, Σ)` 替换单个 q → K 个未来假设 `x̂^k_{t+1}`（Eq.2-3）
- **只监督最接近真值的那一个**：`k* = argmin_k Σ ℓ(x_{t+1}, x̂^k_{t+1})`，`L_BoM = ℓ(x_{t+1}, x̂^{k*})`（Eq.4）
- 效果：一次前向出多样未来，且不用扩散的多步去噪
- **代价**：K 个假设都要在 H×W 空间算，训练变贵 4.9×（Table 2）

### 3.3 Step 2：帧级压缩（每帧压成 1 个 token）

- 连续自编码器：编码器 g 把整帧特征图压成单个帧 token `z_t = g(x_t, z_init)`，解码器 h 从 z_t 重建特征图（Eq.5-6）
- 预测器序列长度 H×W → 1，多假设成本变可忽略
- **局限**：单 token 表达整帧容量有限，细节变化丢失 → 精度反而降（Cityscapes 42.7 vs 45.4）

### 3.4 Step 3：DeltaTok + DeltaWorld（核心创新）

- **DeltaTok**：不压整帧，只压"帧间变化"——编码器输入两帧 `z_t = g(x_{t-1}, x_t, z_init)`，解码器用上一帧特征 + delta token 还原当前帧 `x̂_t = h(x_{t-1}, z_t)`（Eq.8-9）

  - 类比视频编码的帧间压缩；自然处理遮挡和新物体（warping 类方法做不到）
  - 时间冗余越低，delta token 信息量越大；帧率决定每个 token 承载多少变化
- **DeltaWorld**：预测器在 delta token 序列 Z_1:t 上做 next-token prediction：`ẑ_{t+1} = f(q^k, Z_1:t, T_1:t, τ_{t+1})`（Eq.10）

  - 序列开头补黑帧，让第一个 delta token 编码绝对特征
  - 训练：BoM 在 delta token 空间选最优，**无需解码**；推理：K 个噪声 query 一次前向出 K 个多样未来；自回归 rollout 全在 delta token 空间，解码器最后统一还原

![图片展示了DeltaTok+DeltaWorld方法的训练与推理流程。训练时，输入三帧图像，通过VFM提取特征，经DeltaTok Encoder编码生成z_t，再通过Predictor预测下一个delta token，最后用Smooth L1 Loss计算损失，仅通过最优预测反向传播。推理时，输入两帧图像，同样经VFM和DeltaTok Encoder处理，生成z_t后，通过Predictor预测未来delta token，再经DeltaTok Decoder解码，输出多帧图像。该图直观呈现了上下文介绍的模型工作原理。](/images/paper-reading/2026-09-02-deltaworld/2026-09-02-d29-2.webp)

> **三个观察**：① **"预测变化"比"预测完整"便宜且更准**——静态背景不用重画，模型算力全花在真正动的东西上（Table 2：Delta 压缩 0.5× 开销 + 精度反超帧压缩）；② **BoM 是"免费"的生成机制**——K 个 query 对应 K 个未来，只监督最优，不需要扩散/归一化流；③ **判别式的确定性 vs 生成式的多样性，被 BoM 一刀切开**——best（至少有一个准）和 mean（整体一致）两个指标都强，说明多样性不是噪声。

## 四、实验

### 4.1 渐进消融（Table 2，256×256，K=16，mid-horizon \~0.6s mIoU）

| 步骤 | GFLOPs ↓ | 训练开销 | 内存 | VSPW ↑ | Cityscapes ↑ |
|-|-|-|-|-|-|
| (0) 判别式基线 | 959 | 1.0× | 1.0× | 44.8 | 45.4 |
| (1) +BoM 训练 | 12013 | 4.9× | 1.0× | 47.0 (39.4) | 46.8 (31.1) |
| (2) +帧压缩 | 6315 | 0.4× | 0.2× | 45.7 (40.3) | 42.7 (35.5) |
| **(3) +Delta 压缩（DeltaWorld）** | 6721 | 0.5× | 0.2× | **46.8 (44.4)** | **48.7 (45.5)** |

- 括号为 best-of-20 的 mean；(1)-(3) GFLOPs 是生成全部 20 个样本的总开销
- **解读**：BoM 让 best 大涨但 mean 暴跌（多样但噪声大）→ 帧压缩降本但掉精度 → **delta 压缩同时把 mean 拉回来**（Cityscapes mean 45.5 vs 基线 45.4），又快又准

### 4.2 主结果（Table 3，512×512，K=256，best-of-20 vs Cosmos）

| 方法 | 参数 ↓ | GFLOPs ↓ | VSPW ↑ | Cityscapes ↑ | KITTI(深) ↑ | 说明 |
|-|-|-|-|-|-|-|
| Cosmos-2B | 2B+ | 极高 | \~ | \~ | \~ | 像素潜空间扩散 |
| Cosmos-12B | 12B | 极高 | \~ | \~ | \~ | +7B 扩散解码器 |
| **DeltaWorld（ours）** | **ViT-B 级** | **\~2000× 更少** | **best 全超** | **best 全超** | **best 全超** | 单前向出 K 个未来 |

- **DeltaWorld 的 best-of-20 全指标超过 Cosmos，mean 也几乎全超**——尽管 Cosmos 用 \~2000× 的 FLOPs（其 7B 扩散解码器主导）
- DeltaWorld 的 best-mean 差距比 Cosmos 大 → **更有意义的多样性**（不是噪声）
- mean 与判别式 DINO-world 打平（Cityscapes 略好）→ 多样未来不是靠"乱猜"换的

### 4.3 设置与细节

- VFM = 冻结 DINOv3 ViT-B；tokenizer 单独训练 50K iters（batch 1024）；predictor 300K iters @512×512（K=256）或 100K @256×256（K=16）；预测器训练后再以 10× 低 lr 微调 5K
- 时间偏移 Δτ 均匀采样自 [1/25, 1/3] 秒 → 支持任意未来时刻预测
- 训练数据 \~4M 视频（多样域，含评测域外），评测 VSPW/Cityscapes（分割）+ KITTI（深度），短程 \~0.2s / 中程 \~0.6s

## 五、Limitations & 批判性思考（附录 D 实锤，论文自述）

1. **BoM 缺显式分布目标**：扩散有去噪目标保证贴近数据分布，BoM 没有——采样分布不保证接近真实概率，覆盖度受限于训练时 query 数 K；**但**实践中不同 query 确实给出不同未来，query 空间可能隐含"动作条件"语义
2. **误差累积（特征漂移）**：delta token 编码的是"差"，重建绝对特征要反复解码；tokenizer 重建误差 + predictor 预测误差在多步 rollout 中叠加（自回归视频生成的已知难题）；缓解方向：tokenizer 在自己的重建上自回归计算 delta（而非从真值帧）
3. **帧压缩是失败路径**：Step 2 的帧级单 token 方案精度下降，论文如实展示——说明"每帧 1 token"只对 delta（变化）成立，对绝对帧不成立
4. **评测偏短程**：\~0.6s 中程预测为主，长程（秒级+）误差累积下的表现未充分验证
5. **无独立代码验证**（我读的）：代码虽开源，但训练数据 (\~4M 视频) 未公开，复现需要自备数据

## 七、启发与待跟进

> **核心启发**：
> 1. **"预测变化"是通用降维哲学**：视频里时间冗余极高（静态背景），只建模 delta 让 1024 维问题变 1 维——这个"差空间建模"思想可迁移到任何时序预测（loss 预测、reward 变化、token 间差）
> 2. **BoM 让判别式模型免费变生成式**：不需要扩散/流，K 个噪声 query + 只监督最优——简单到"一个 argmin"，效果却接近专用生成架构
> 3. **best-mean 双指标是生成式模型的试金石**：best 强而 mean 弱 = 多样性是噪声；两者都强 = 真多样性——后训练评估多样采样时同样适用

### 待跟进 checklist

- [ ] **DeltaWorld × WPT**：delta token 世界模型 + 奖励蒸馏——把"变化预测"的预判力蒸馏进策略，效率与落地两全

- [ ] **delta 思想搬到 LLM 后训练**：token 间的"差"建模（如 OPD² 的 delta 信号、HPD 的 KL 差）与视频 delta 是否同一数学结构

- [ ] **BoM 与 PCD/BSBT 的择优对比**：argmin 选最优 vs 软 AND 门加权 vs 盲测路由——多假设场景的"只学最好的"何时最优

- [ ] **误差累积实测**：长程 rollout（>2s）下特征漂移有多严重；tokenizer 自回归自训练能否缓解（论文提的缓解方向）

- [ ] **query 空间=隐式动作条件**：论文观察到相似 query 产生相似未来——能否显式把动作（导航/速度）注入 query 做动作条件化生成

- [ ] **代码复现**：开源了但训练数据未公开；先用 HF 权重在自备视频上验证 1024× token 压缩的实际效果

## 八、今日阅读结论

DeltaWorld 是"世界模型效率化"的干净一作（CVPR 2026）：用**视频编码的帧间压缩思想**，把"预测下一帧"改写成"预测下一帧的变化"，再配一个\*\*只监督最优假设（BoM）\*\*的免费生成机制——一帧一个 token，token 减 1024×，参数 -35×、FLOPs -2000×，生成多样未来还全面压过 Cosmos。与昨天 WPT 合读，世界模型的两块拼图齐了：**WPT 教它怎么落地（训完就扔），DeltaWorld 教它怎么做小（只预测变化）**。对后训练研究者，BoM 的"多假设择优"和"变化空间建模"是两个可直接迁移的思想——前者是你熟悉的采样择优，后者是"差空间"这个通用降维哲学。

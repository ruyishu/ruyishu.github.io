## TL;DR

一句话：**把多步 Agent 的交互历史画成图，省的是 token，跑偏的是策略——不是 OCR 读不出来，而是搜什么、何时停、怎么用证据系统性变了。CAPS 用同一模型更强的文本历史策略，分两阶段把决策行为迁到视觉接口上。**

- **核心发现**：GRPO 把 7B 视觉历史 Agent 的 SearchQA 从 14.0% 拉到 40.1%，History QA 反而从 82.78% 掉到 78.22%——任务涨分不是因为更会读图。同一语义状态下，只换历史模态，第一步检索后视觉策略有 55.4% 直接作答，文本策略只有 29.8%。
- **方法 CAPS**：冻结文本历史教师，训练视觉历史学生。Stage 1 把成功文本轨迹渲染成图再做完整响应 SFT；Stage 2 在 GRPO 里对学生自己走到的状态，用配对文本历史做全词表 forward KL。
- **炸裂结果**：SearchQA 相对 AgentOCR 提升 5.0 / 3.4 分（3B / 7B）；ALFWorld 全历史提升 15.6 / 14.5 分。7B CAPS 在 SearchQA 上 43.5，超过自己的文本教师 43.0；峰值上下文最多省 83.4%。

## 一、先看问题：历史画成图，Agent 就不一样了

多步 Agent 每走一步，就把观察和动作往上下文里堆。轮次一多，token、显存、延迟一起涨。Vision–Text Compression（VTC）的想法很直：别删、别摘要，把同一段历史**渲染成图**，用更少的视觉 token 塞进同样的信息。AgentOCR 把这套搬到多步 Agent 上，确实把峰值上下文压下去了。

但论文开篇就甩出一张总览图：同一条轨迹，左边是文本历史，右边是视觉历史——token 少了，成功率也掉了。

![图 1 ｜ 文本历史 vs 视觉历史：省 token 的同时换掉了策略本身（论文原文 Figure 1）](/images/paper-reading/2026-08-13-caps-2/2026-08-13-d15-1.nl)

这张图要按四块读，逻辑是层层加码，不是四张独立柱状图。

**(a) 同一条轨迹，两种接口。** 左边文本历史展开成密密麻麻的 text token，机器人开心地打出正确动作；右边把同一段内容画成图，视觉 token 少一截，机器人却选错了。论文的原话翻译过来就是：上下文效率 ≠ 能力保持。

**(b) 涨分不是因为更会读图。** 7B 视觉 Agent 做 GRPO：SearchQA 从 14.0% 飙到 40.1%，看起来像「学会看图了」。但 History QA（专门考「历史图里写了什么」）从 82.78% **掉到** 78.22%。文本历史同一套题还能到 90%。读得出来，不代表会拿来决策。

**(c) 同一语义状态，只换模态，决策就变。** 从真实文本轨迹里抽 1 万个决策前缀，两边看到的问题和交互内容完全一样，只改历史是文本还是图：

- 下一步动作类型对不上：29.13%
- 第一次检索之后，视觉策略 55.41% 直接作答，文本策略只有 29.80%
- 两边都选择 Search 时，query token Jaccard ≥ 0.8 的比例只有 5.22%

**(d) 轨迹质量五个维度，文本全面包住视觉。** 证据吸收、实体关系追踪、查询递进、停止校准、答案 grounding，雷达图里蓝圈把橙圈整个罩住。

> **这篇的真正 punchline**：缺口主要不是「图上的字认不出来」，而是「认出来之后，搜什么、何时停、怎么用证据」系统性跑偏。作者把它叫作 **Agentic Policy Gap**。

视觉历史长什么样？附录里有两张**运行时渲染器直接打出来的真图**，没有额外压缩。SearchQA 是蓝 `<search>` + 红 `<information>`；ALFWorld 是蓝 Observation + 红 Action。Agent 每一步看到的就是这种「把终端日志截成图」的东西。

![图 1a ｜ SearchQA 真实视觉历史：两次 Search–Information 之后、第三次决策之前（论文附录）](/images/paper-reading/2026-08-13-caps-2/2026-08-13-d15-2.png)

![图 1b ｜ ALFWorld 真实视觉历史：十轮 Observation–Action 之后、第十一次决策之前（论文附录）](/images/paper-reading/2026-08-13-caps-2/2026-08-13-d15-3.png)

这就是为什么「读得见」和「会推理」能被拆开：图上的字清清楚楚，但策略已经不是原来那套了。

## 二、CAPS：让文本老师教图像学生

诊断清楚之后，监督信号其实现成——**同一个模型、同一套动作空间，文本历史上本来就更强**。每个交互状态都能配成一对：$x_t^T=(\mathcal{I}, h_t)$ 和 $x_t^I=(\mathcal{I}, I_t)$，内容相同，只是历史接口不同。

CAPS（Cross-modal Agentic Policy Self-distillation）就干一件事：冻结文本历史教师 $\pi_\phi^T$，训练视觉历史学生 $\pi_\theta^I$。框架图是论文原文 Figure 2，三块拼在一起看。

![图 2 ｜ CAPS 总览：离线轨迹自蒸馏 + GRPO + 在线策略自蒸馏（论文原文 Figure 2）](/images/paper-reading/2026-08-13-caps-2/2026-08-13-d15-4.nl)

### 2.1 Stage 1：离线轨迹自蒸馏（图中紫色块）

先用 GRPO 训一个文本历史教师，再只留**成功、动作可解析、没被长度截断**的轨迹。同一题有多条成功轨迹时，按「步数少 → 重复动作少 → 回复短 → 上下文短」挑一条。

然后做一次跨模态搬运：历史前缀渲染成图，**目标仍是教师那一整段回复**（推理 + 可执行动作），对学生做 next-token SFT：

*{off}(\theta)=-\mathbb{E}\frac{1}{|y^T|}\sum_k\log\pi*$\mathcal{L}\theta^I(y_k^T\mid \mathcal{I}, I, y_{<k}^T)$

SearchQA 3B / 7B 滤完大约 1.8 万 step 级样本，ALFWorld 大约 1.5 万。训练题没有多加，全是后续 GRPO 会用到的那批。

> **一个很容易踩的坑**：如果 Stage 1 不渲染成图，直接拿成功文本轨迹做 SFT 再 GRPO，7B 平均只有 40.7，几乎贴着没蒸馏的 AgentOCR（40.1）。教师的成功轨迹本身不够，学生必须在**视觉接口**上学会怎么想、怎么动。

### 2.2 Stage 2：GRPO + 在线策略自蒸馏（图中蓝块 + 绿块）

离线蒸馏覆盖的是教师走过的状态。部署时学生会走到自己的状态分布上，这才是 OPD 要补的那一截。

学生用视觉历史采样回复 $\hat y$。系统同时保留同一串观察/动作对应的**规范文本历史**，冻结核教师在文本接口上对学生前缀打全词表分布，再做 clip 过的 forward KL：

*{on}=\frac{\sum*$\mathcal{L}{b,k}m_{b,k}\min(D_{b,k}^{FKL},\tau)}{\max(1,\sum m_{b,k})}$

无效动作的回复不计入蒸馏。联合目标仍以环境奖励为主：

*{GRPO}+\lambda\mathcal{L}*$\mathcal{L}=\mathcal{L}{on}$

SearchQA 上 $\lambda=0.05$，ALFWorld 上 $\lambda=0.01$，KL clip $\tau=0.05$，教师温度 1.1。

> **和 Vision-OPD / SEED 的特权差在哪**：那些工作的特权是「看得更清的局部 crop」或「更好的推理轨迹」。CAPS 的特权是**同一段历史的文本接口**。教师没有标准答案，只是换了个更顺手的输入模态，在学生自己采样的轨迹上提供稠密 token 级监督。

## 三、实验结果：视觉接口追上甚至超过文本老师

### 3.1 SearchQA：六项第一，峰值上下文最多省 83.4%

训练只用 NQ + HotpotQA，其余五套测 OOD。Agent 调 E5 检索 top-3，最多 4 步。

| 方法 | 3B Avg | 7B Avg | 7B Avg tok | 7B Peak tok |
|-|-|-|-|-|
| Text (w/o RL) | 15.9 | 17.5 | 0.70k | 10.96k |
| Text + GRPO（教师） | 41.7 | 43.0 | 0.60k | 3.83k |
| OCR (w/o RL) | 12.7 | 14.0 | 0.26k | 2.21k |
| AgentOCR | 34.2 | 40.1 | 0.36k | 2.65k |
| SKILL0 | 40.8 | 44.4 | 0.34k | — |
| **CAPS** | **39.2** | **43.5** | **0.29k（-51.3%）** | **1.74k（-54.6%）** |

相对 AgentOCR：3B **+5.0**，7B **+3.4**。7B CAPS 平均 43.5，**超过自己的文本教师 43.0**。SKILL0 总平均更高，几乎全靠 Bamboogle。3B 峰值 token 相对文本教师降 **83.4%**。

### 3.2 ALFWorld：长程任务甩开 AgentOCR 十几分

主结果全历史 $H=50$，另报 GiGPO 默认 $H=2$。

| 方法 | H | 3B 成功率 | 7B 成功率 | 7B 峰值 token |
|-|-|-|-|-|
| Text + GRPO（教师） | 50 | 91.0 | 92.6 | 2.90k |
| AgentOCR | 50 | 78.2 | 81.2 | 1.22k |
| SKILL0 | 50 | 87.9 | 89.8 | — |
| **CAPS** | 50 | **93.8** | **95.7** | **0.87k（-70.0%）** |
| CAPS | 2 | 74.6 | 84.8 | 0.13k |

全历史上 CAPS 比 AgentOCR 高 15.6 / 14.5 分，比 SKILL0 高 5.9 分，连文本教师都超了 2.8 / 3.1 分。没改渲染器、也没额外压图，token 更少是因为**决策更好、步数更短**。

### 3.3 消融：两阶段缺一不可

| 变体 | 3B | 7B |
|-|-|-|
| **CAPS（Off-SD → GRPO + On-SD）** | **39.2** | **43.5** |
| 只做离线蒸馏再 GRPO | 37.4 | 42.9 |
| 只做 GRPO + 在线蒸馏 | 37.1 | 41.4 |
| 文本轨迹 SFT → GRPO（不渲染成图） | 36.3 | 40.7 |

离线负责「在视觉接口上把成功行为装进去」，在线负责「学生自己走到的状态还能被教师纠正」。单开哪一边都不够。

### 3.4 别靠把图压得更糊来省 token

默认压缩因子 $c=1$。论文 Figure 3：$c$ 从 1.0 到 2.5，7B SearchQA 从 43.54% 掉到 35.50%，平均检索从 1.83 次涨到 2.15 次。图越糊，策略越靠重复搜索补信息。CAPS 省 token 的正道是更好的决策，不是把字压到看不清。

## 四、机制验证：涨分真的不是因为更会 OCR

### 4.1 History QA 继续下降

| 指标 | Base VLM | AgentOCR | CAPS |
|-|-|-|-|
| SearchQA 成功率 | 14.0 | 40.1 | **43.5** |
| Image History QA | **82.78** | 78.22 | 73.70 |
| Text History QA | 90.03 | 89.78 | 89.35 |

Base VLM 最会从图里抄字，任务却最差。CAPS 任务最好，History QA 反而最低。增益来自**更会用已经读到的信息做决策**。

### 4.2 匹配状态下，提前作答被按回去

| 指标（%） | AgentOCR | CAPS | 变化 |
|-|-|-|-|
| 动作类型一致率 | 70.87 | 79.53 | +8.66 |
| 文本要 Search、视觉却 Answer | 51.67 | 32.42 | **-19.25** |
| Search 内容匹配（Jaccard ≥ 0.8） | 5.22 | 23.53 | +18.31 |
| Answer 内容匹配 | 71.82 | 72.89 | +1.07 |

最大变化不是「答案写得更像」，而是少了很多「证据还没齐就交卷」。

### 4.3 轨迹质量：五维都往文本老师靠

论文 Figure 4 哑铃图：总分从 AgentOCR 的 5.510 提到 5.977，文本老师是 6.303。证据吸收 +0.112、实体关系 +0.120、答案 grounding +0.106，停止校准只 +0.054，仍是最短的一截。

| # | 方法 | 核心创新 |
|-|-|-|
| 1 | TOPD | 用近未来引导弥合推理轨迹 |
| 2 | COPD | 对比式 On-Policy 蒸馏 |
| 3 | Re² | 让 LLM 学会重启推理 |
| 4 | RLCSD | 对比式 On-Policy 自蒸馏 |
| 5 | SEED | 自演化 On-Policy 蒸馏赋能 Agentic RL |
| 6 | Vision-OPD | 用视角特权自蒸馏让多模态模型看细节 |
| 7 | OPLD | 把多模态 CoT 蒸馏进隐空间 |
| 8 | ReVisual-R1 | 三阶段训练解锁多模态推理 |
| 9 | Distilled RL | 把教师监督融进 RL 目标 |
| 10 | Invisible Reasoning | 并非所有推理都写在思维链里 |
| 11 | O²-CritiCuRL | 离在线课程 RL 让多模态推理聚焦关键步骤 |
| 12 | Remember-R1 | 用 RL 缓解多模态长链推理中的视觉遗忘 |
| 13 | PRISM | 黑盒 OPD 预对齐，插在 SFT 与 RLVR 之间 |
| **14** | **CAPS** | **跨模态策略自蒸馏：特权是同一历史的文本接口** |

> 前 13 篇大多在问蒸馏信号从哪来、OPD 放在后训练哪一段。CAPS 问的是：**当历史接口从文本换成图像，丢失的到底是感知还是策略？**
> - **SEED / OPSD**：在线蒸馏打在学生自己访问的状态上；CAPS 把特权上下文换成文本历史。
> - **Vision-OPD**：同一模型、两种视角；那边是 crop vs 全图，这边是 text-history vs image-history。
> - **PRISM**：黑盒判别对齐 SFT 漂移；CAPS 是白盒 token 级 KL。
> - **Remember-R1**：长链里视觉信息被冲掉；CAPS 说即便字还在图上，决策策略也可能已经换人。

## 六、训练细节、局限和结论

离线蒸馏 2 epoch、LoRA rank 32，视觉栈 linear 也开了。GRPO 学习率 $1\times10^{-6}$，无 reference KL。SearchQA：128 题 × 8 rollout、最多 4 步；ALFWorld：16 题 × 8 rollout、最多 50 步。H200 上 SFT 约 3 小时，一档 RL 约 1–2 天。

局限：Bamboogle 仍弱于 SKILL0；History QA 继续下降；停止校准仍是五维最短的一截；代码未公开；教师要先训一轮文本 GRPO。

> **一句话收束**：有效的视觉历史压缩，要对齐的是策略，而不只是「图上的字还能不能抄下来」。Reading is not reasoning——标题把刀口已经亮出来了。

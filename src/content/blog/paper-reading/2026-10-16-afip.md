## TL;DR

<strong>一句话：多模态模型胡说八道（幻觉）的根因，论文定位到两个可测量的注意力现象——① 多个注意力头在看图时「各看各的」（空间不一致，正确词的注意力锐利集中、幻觉词的注意力一片弥散）② 解码越往后、分配给图像的注意力越少（时序衰减，幻觉集中在「图片注意力最低的那 30% 区间」）。AFIP 就在推理时直接改注意力矩阵：把头间共识加进去、把历史视觉注意力补回来，再用一个门控决定什么时候才动手。训练完全不需要。</strong>

- <strong>最刺眼的一组数（Table 1，CHAIR，max new token 512）</strong>：AFIP 五个模型全部第一，<strong>平均 CS 17.5 / CI 5.9</strong>；最强基线 HGAI 是 <strong>26.7 / 7.5</strong>，普通 greedy 是 <strong>46.9 / 13.3</strong> → <strong>相对最强基线 CS 再降 9.2%，相对 greedy 降了一半以上</strong>
- <strong>诊断一 · 空间不一致（Figure 2）</strong>：正确词 <strong>"computer"</strong> 的注意力锐利地集中在电脑上；幻觉词 <strong>"potted plant"</strong> 的注意力在整张图上一片弥散。real token 的平均注意力熵 <strong>−0.053</strong> vs hallucinated token <strong>0.303</strong>，<strong>p &lt; 0.01</strong>
- <strong>诊断二 · 时序衰减（Figure 3）</strong>：<strong>所有模型的 VAR（图像注意力占比）都随解码持续下降</strong>；幻觉 token 集中出现在生成后期、低 VAR 区——<strong>VAR 最低 30% 的区间幻觉率显著更高</strong>
- <strong>真有理论（Theorem 5.1）</strong>：Rademacher 复杂度上界 ∝ √( H·ā² + Σ(a\_h − ā)² )，<strong>当且仅当各注意力头贡献均匀时取最小</strong>；任何偏离都增大复杂度、削弱泛化保证
- <strong>方法三件套</strong>：① <strong>头级注意力涣散校正</strong>——按「每个头对图像 token 的最大响应」选 top-k 视觉头，算头间<strong>均值 Avg 与方差 Var</strong>，做 <strong>B̂ = B + Avg − α·Var</strong>（均值当「哪些是真图 token」的判据、方差当「不够集中」的惩罚）② <strong>动态历史注意力增强</strong>——维护一块历史视觉注意力记忆，把之前看过的地方补回来 ③ <strong>动态门控</strong>——只当「文本区最大注意力将要超过视觉区」时才干预
- <strong>消融分得清主次（Table 4）</strong>：去掉头级校正，7B 的 CS 从 16.8 <strong>暴增到 49.6</strong>；去掉门控 → 22.6；去掉历史增强 → 19.3。<strong>头级校正是主力，另两个各值 2–3 分</strong>
- <strong>POPE 上也赢（Table 2）</strong>：LLaVA-1.5-7B 平均 <strong>87.11 / 87.82</strong>，压过 HGAI（85.72 / 86.01）与 greedy（84.87 / 84.90）；五个模型里除 MiniGPT-4 外全部第一
- <strong>长文越长越占优（Table 3）</strong>：max new token 取 64 / 128 / 256 都稳，且<strong>长序列增益更明显</strong>——这正好对应「时序衰减」那个诊断
- <strong>⚠️ 一个必须点明的裂缝：这篇的理论和方法方向是相反的</strong>。定理说「<strong>各头越均匀越好</strong>」，而方法做的是「<strong>先 top-k 挑出少数几个头、再强化它们</strong>」——<strong>这恰恰在制造头间异质性</strong>。两部分之间没有推导链，是两条并行的叙事

## 一、先看例子（大白话：一个人盯着屏幕看久了会走神）

> 💡 <strong>铺垫</strong>：多模态模型写一段图片描述时，会编出图里根本没有的东西——这叫物体幻觉。
>
> <strong>论文的类比很好懂</strong>：人在「注意力被分散」的时候，看东西会变模糊、描述会出错。而模型身上出现了<strong>同样两件事</strong>。

> <strong>把这件事想成你一边刷手机一边看一份合同：</strong>
>
> <strong>第一种毛病：眼睛不知道该盯哪（空间上涣散）。</strong>你的目光在整页纸上乱飘，没有落在任何一处。<strong>模型身上的表现是：多个注意力头各看各的</strong>——Head15 盯着键盘，Head16 盯着窗外的植物，Head17 又飘到别处。<strong>没有共识 = 没有真正看清楚 = 容易编。</strong>
>
> <strong>第二种毛病：越看越不看（时间上衰减）。</strong>读了五行之后你放弃了，剩下的靠"猜大概"。<strong>模型身上的表现是：分配给图像的注意力随着生成推进一路下跌</strong>。<strong>论文实测：幻觉大量出现在「图片注意力最低的那 30% 区间」。</strong>
>
> <strong>AFIP 就是针对这两个毛病下药——而且是在推理时实时下药，不重训。</strong>

## 二、动机：幻觉不只是「看得少」，是「看得散」和「看得越来越不看」

- <strong>先给两个可测量的指标（论文自己定义）</strong>： 
  - <strong>注意力熵 D</strong>：当前 token 对图像 patch 的（头平均）注意力分布的熵。<strong>小 = 集中，说明有明确、有选择的视觉关联；大 = 弥散，说明视觉接地散乱而不确定</strong>
  - <strong>视觉注意力占比 VAR</strong>：分给图像 token 的注意力总量占比。<strong>大 = 依赖图像；小 = 主要靠文本上下文生成</strong>
- <strong>Finding 1 · 多头空间不一致 = 幻觉</strong>：受人类「稳定注视显著区域」启发，有视觉依据的 token 应该表现出<strong>集中且跨头一致</strong>的注意力；幻觉 token 则相反。实测（COCO 验证集随机抽样、LLaVA-1.5-7B 为主）： 
  - 正确词「computer」：注意力锐利集中，三个头都盯着电脑
  - 幻觉词「potted plant」：注意力在整张图上大片铺开，三个头各飘各的
  - <strong>real token 平均熵 −0.053 vs hallucinated token 0.303，p &lt; 0.01</strong>
  - 进一步用<strong>跨头散度 D\_kl</strong>（各头分布相对头平均分布的 KL 均值，衡量头间共识有多差）分位数分组：<strong>D\_kl 越大 → 预测熵越高、幻觉率也越高</strong>（Figure 4 左，bootstrap 2000 次重采样给置信区间）
- <strong>Finding 2 · 时序衰减 = 幻觉</strong>：让模型生成长回复并逐解码步记录各层注意力，按层平均得到 VAR 曲线——<strong>所有骨干模型的 VAR 都持续下降</strong>，说明随解码推进、对视觉证据的依赖在系统性减弱。把 real / hallucinated token 按归一化后的位置铺开（Figure 3 右）：<strong>幻觉 token 集中在低 VAR 区域、且出现在生成后期；VAR 落在最低 30% 的 token，幻觉发生率显著高于其余</strong>
- <strong>论文的措辞（值得注意）</strong>：把这两个现象统称为「<strong>注意力涣散导致的视觉模糊</strong>」，并与人类「注意力分散 → 视觉清晰度下降 → 描述不准」的现象类比

## 三、理论：注意力头之间越不均匀，泛化越差

<strong>论文把多头注意力理解为「来自多个来源的多样信息」，然后从泛化角度给出两个定理。</strong>

> <strong>Theorem 5.1（复杂度上界）</strong>：对以自注意力为核心的 Transformer 函数类，其 Rademacher 复杂度满足
>
> <strong>ℜ̂\_D(F) ≤ (4·B\_w·B\_WC·B\_O·L\_σ·R³ / √n) · √( H·ā² + Σ\_{h=1..H} (a\_h − ā)² )</strong>
>
> 其中 <strong>a\_h = ‖W\_V^(h)‖\_F · ‖W\_QK^(h)‖\_F</strong>，ā 是 a\_h 的均值。<strong>该上界当且仅当 a\_1 = … = a\_H = ā（各头贡献均匀）时取到最小</strong>；任何偏离都会引入额外弥散、增大复杂度、削弱泛化保证。

- <strong>论文的解读</strong>：这条「形式化了『维持多头同质性有助于最优泛化』这一原则」
- <strong>Theorem 5.2（泛化误差界）</strong>：给出 R(f) − R̂\_D(f) ≤ ẼK₁/n^(1/2)H^(1/2) + ẼK₂/n^(3/4)H^(1/4) + ẼK₃·√(…) 的形式，<strong>误差界随头数 H 增大而收紧</strong>，但其中的常数项受头间不一致影响
- <strong>论文的连接语</strong>：attention distraction「削弱了模型在词表选择时的判别能力」——<strong>这一句是从复杂度界跳到了 token 级幻觉，中间没有推导</strong>（见我自己读出的第 3 条批判）

## 四、方法：AFIP，推理时直接改注意力矩阵

![论文 Figure 4：(左) 头间不一致程度 D_kl 与预测熵的关系——D_kl 越大预测熵越高（幻觉 token 恒高于真实 token），柱状为对应幻觉率，也随 D_kl 上升；(右) 注意力校正的案例研究——生成 sign 与 platform 时的注意力图（上为校正前、下为校正后），校正后视觉焦点明显落在了相关区域](/images/paper-reading/2026-10-16-afip/2026-10-16-d58-4.webp)

### 4.1 组件 S3：头级注意力涣散校正（主力）

- <strong>取出 softmax 之前的注意力分数矩阵 B\_t^(l,h) = (Q\_{l,h} K\_{l,h}ᵀ / √d\_t)|\_t</strong>（用分数而非概率，避免 softmax 后过度扭曲）
- <strong>选头</strong>：用「每个头在<strong>所有图像 token 上的最大绝对响应</strong>」排序，每层选出 <strong>top-k 个视觉头 H\_k^(l)</strong>——<strong>响应越强，说明这个头对图像的判读越有参考价值</strong>
- <strong>算两个量</strong>（对图像 token i，在选出的头上）： 
  - <strong>Avg^(l)</strong> = 各头注意力分数的均值 → <strong>当作「哪些才是真图像 token」的判据（跨头共识）</strong>
  - <strong>Var^(l)</strong> = 各头相对均值的方差 → <strong>当作「注意力不够集中」的惩罚项</strong>
- <strong>校正公式</strong>：<strong>B̂\_t^(l,h)(a\_t, i) = B\_t^(l,h)(a\_t, i) + Avg^(l) − α·Var^(l)</strong>，把增量项记作 <strong>Δ₁^(l)</strong>
- <strong>一句话读法</strong>：<strong>「跨头都同意的部分加进去，头间分歧大的部分扣掉」</strong>——共识加权、分歧惩罚。论文说校正后注意力分布变得更集中，模型更容易把视觉内容和文本语义对上

### 4.2 组件 S2：动态历史注意力增强

- <strong>动机</strong>：直接对应 Finding 2（时序衰减）。既然越写越不看图，那就<strong>把「之前看过的」补回来</strong>
- <strong>做法</strong>：维护一块<strong>历史视觉注意力记忆窗口 C\_t</strong>；每一步确定「最依赖的文本」，再从中检索相关历史，得到增量项 <br><strong>Δ₂^(l,h) = γ · C\_{t−1−r^(l,h)}(s + j)</strong>
- <strong>注意这不是「记住内容」，而是「记住之前看过哪」</strong>——记忆的对象是注意力分布本身

### 4.3 组件 S1：动态门控（什么时候才动手）

- <strong>取两个最大值</strong>：当前头上，<strong>文本区的最大注意力 T\_t^(l,h)</strong> 与<strong>视觉区的最大注意力 V\_t^(l,h)</strong>
- <strong>门控条件</strong>：<strong>G\_t = 𝟙( D\_t &lt; τ )</strong>，其中 D\_t 体现「文本注意力将要压过视觉注意力」的程度——即 <strong>T − V &lt; τ 时才干预</strong>
- <strong>为什么必须有这一层</strong>：<strong>无条件地改注意力会伤性能</strong>。消融显示去掉门控，7B 的 CS 从 16.8 涨到 22.6（变差）——门控值 2–3 分
- <strong>最终</strong>：<strong>校正后注意力 = Origin Attn + Δ₁ + Δ₂</strong>，且只在门控打开时施加；只作用在 <strong>\[l\_e, L\] 的后半段层</strong>
- <strong>论文的核心卖点</strong>：<strong>plug-and-play、免训练、名义上不增加推理延迟</strong>

## 六、Limitations

### 论文自述：没有独立章节

<strong>⚠️ 这篇论文在 Conclusion 之后直接进入 Acknowledgments 与 Impact Statement，没有 Limitations 段落。</strong>Impact Statement 只提到「推动 MLLM 更安全可靠地部署，不认为引入额外伦理风险」。

### 我读出的 7 条

1. <strong>⭐ 理论与方法的方向是相反的</strong>（本篇最值得说的一条）： <br>Theorem 5.1 的结论是「<strong>各注意力头贡献越均匀，复杂度上界越小、泛化越好</strong>」，论文自己也在正文写「maintaining homogeneity across multi-head attention supports optimal generalization」。 <br>但 AFIP 的做法是「<strong>先用 top-k 挑出少数几个视觉头，再强化它们</strong>」——<strong>这恰恰是在放大头间差异</strong>。 <br><strong>两部分之间找不到推导链</strong>：定理既没有推出「top-k 选头」，也没有给出「Avg − αVar」这个具体形式；方法也没有验证「按定理去做会更好」。 <br><strong>更关键的是：论文没做那个最该做的对照实验——按定理字面建议去「均衡各头贡献」，性能会怎样？</strong>
2. <strong>复杂度界 → token 级幻觉的跨层跳跃</strong>：Rademacher 复杂度刻画的是<strong>整个函数类的泛化误差</strong>，不是「某一个词会不会幻觉」。用它解释 token 级幻觉现象是跨越了层级，中间缺一步（比如「头间不一致 ↑ → 该步判别裕度 ↓ → 幻觉概率 ↑」的形式化）
3. <strong>「无额外推理延迟」没有数字</strong>：每一步解码要做的事情不少——算分数矩阵、排序选 top-k 头、算头间均值方差、检索并维护历史注意力记忆、算门控。虽然都是轻量张量操作，但论文只给了 Figure 6 的超参敏感性，<strong>没有 wall-clock 延迟或吞吐对照</strong>
4. <strong>基线全是推理期方法</strong>：Greedy / Beam / OPERA / VCD / MemVR / HGAI 全都是 inference-time 干预，<strong>没有和任何训练类幻觉缓解方法对比</strong>（如基于 RL/SFT 的路线，lib 里就有一批）。所以结论的正确表述是「<strong>在推理期方法里最好</strong>」，不是「最好」
5. <strong>观察是相关性，"indicates" 是因果口吻</strong>：Figure 2（p &lt; 0.01）、Figure 3（分布偏移）、Figure 4（D\_kl 与预测熵正相关）都是<strong>统计关联</strong>，而标题与正文大量使用 "indicates"、"drives"、"underlying mechanism"。<strong>有没有可能是反向——模型即将幻觉时才导致注意力涣散？论文没有做时间先后上的因果控制</strong>
6. <strong>门控的判据偏启发式</strong>：G\_t = 𝟙(D\_t &lt; τ)，阈值 τ 靠调（Figure 6 给了敏感性）；而「文本最大注意力 − 视觉最大注意力」这个判据只取单点最大值，对单个离群 token 敏感
7. <strong>对 HiRes 场景未验证</strong>：CHAIR 的 COCO 图分辨率有限；论文诊断里最关键的「空间不一致」在高分辨率、目标很小的场景（lib 里 iVGR / ActiveScope 处理的那类）会不会更严重，没有测

## 七、前文对照

> 🔗 <strong>一句话定位</strong>：AFIP 是 lib 里 <strong>VisualSwap（10/8）的「病理报告」</strong>——VisualSwap 发现「模型嘴上说再看看图、其实根本没看」，AFIP 给出了<strong>为什么</strong>：多头各看各的（空间）＋ 越看越不看（时间）。同时它给「分锅家族」补上了最后一个没被用过的一维：<strong>注意力头</strong>。

### 7.1 与 VisualSwap（10/8）—— 症状 vs 病理 ⭐

|   | VisualSwap（10/8） | AFIP（本篇） |
|-|-|-|
| <strong>发现了什么</strong> | <strong>现象</strong>：模型在文字里说「我再看看图」，但把图偷偷换掉，准确率最多掉 60%——<strong>它其实没在看</strong> | <strong>机理</strong>：给出「没在看」的两个可测形式——<strong>头间空间不一致</strong> 与 <strong>VAR 时序衰减</strong> |
| <strong>抓手</strong> | 输入侧：换图（扰动输入看输出） | 内部侧：注意力分布（读内部信号看哪一步没看） |

<strong>连起来读才对</strong>：VisualSwap 回答「有没有看」，AFIP 回答「<strong>为什么看着看着就不看了</strong>」——<strong>VAR 随解码下降</strong>这一条，恰好是 VisualSwap 那个现象在内部信号上的对应物。

### 7.2 与 BSBT/MoCA（8/31）—— 粗颗粒与细颗粒的互补

- <strong>MoCA</strong> 的问法是「<strong>看错了还是想错了</strong>」——<strong>模态级</strong>的信用分配，用纯文本模型盲测来判定感知是否充分，再把奖励路由到「保护感知」或「惩罚感知」
- <strong>AFIP</strong> 深入到「看错」<strong>内部</strong>：不是「模态层出了多少力」，而是「<strong>哪几个头在看、各头看的一不一致、看到后面还看不看</strong>」
- <strong>合起来是三个层级</strong>：模态层（MoCA）→ 头层（AFIP）→ token 层（PCD / VGS）

### 7.3 与「感知-推理归因」这条线上的同类

| 工作 | 干预在哪一层 | 怎么做 |
|-|-|-|
| <strong>PCD（8/17）</strong> | 损失层 | 感知-推理归因的软 AND 门 <strong>(1−PSR)·KL̃</strong> |
| <strong>VGS（8/21）</strong> | 梯度层 | 把 OPD 梯度掰向视觉子空间（ℓStandard + γℓVis + λℓLP） |
| <strong>iVGR（10/14）</strong> | 输出层 | 别让模型把坐标写出来，用双流 + 一致性奖励把接地内化 |
| <strong>AFIP（本篇）</strong> | <strong>注意力层</strong> | 推理时直接改注意力分数矩阵（共识加权 + 分歧惩罚 + 历史补偿 + 门控） |

<strong>四篇是同一诊断在四个不同层级上的干预</strong>：训练侧的损失（PCD）与梯度（VGS）、推理侧的输出格式（iVGR）与注意力矩阵（AFIP）。<strong>「让模型真的去看图」这件事，lib 里已经集齐了四把不同层的刀。</strong>

### 7.4 与其他相邻工作

- <strong>与 ACTIVE-O3（8/27）</strong>：ACTIVE-O3 让模型<strong>主动选区域放大看</strong>（外部动作，需要额外 forward）；<strong>AFIP 是被动地每步校正内部注意力</strong>——「外求」对「内修」
- <strong>与 lib 的「trace 记忆」母题</strong>：AFIP 的历史视觉注意力记忆 C\_t <strong>记住的不是内容，而是「之前看过哪」</strong>——这是「记忆形态」谱系里全新的一档，与 JitRL 经验库 / PERSIST 3D 状态 / Forget-Me-Not 回放缓冲 / WorldPlay 重构上下文 / SOMA 物体级空间记忆 / iVGR Rollout Archive / EAPO 自写文字记忆<strong>全部正交</strong>
- <strong>与 EAPO（10/15）的隐含呼应</strong>：EAPO 说 agent「不该一视同仁地探索」，AFIP 说注意力「不该一视同仁地分配」——<strong>两篇都在讲「分配要随状态变化」，一个在行动空间、一个在注意力空间</strong>
- <strong>「分锅家族」新增一轴 = 注意力头（哪个头在看）</strong>：lib 已有 BSBT 模态 / PCD 因果阶段 / GiGPO 时间步 / GraphGPO 状态-动作边 / POLIA 视觉物体 / π-Distill 教师-学生角色 / iVGR 跨数据流对齐 / EAPO 动作类型×访问深度 → <strong>AFIP 补上了「头（head）」这一维，这条族谱基本补全了</strong>

## 八、启发与待跟进

### 启发

1. <strong>「多头不一致」是个便宜、可复用、而且双向可用的信号</strong>——只需注意力矩阵就能算，<strong>既能当检测器（判断这个 token 会不会幻觉），又能当干预目标（把它校回去）</strong>。相比「用另一个模型当裁判」或「多次前向做对比解码」，这个信号的边际成本几乎为零
2. <strong>「时序衰减」解释了长文生成为什么越写越离谱</strong>：VAR 随解码单调下降、幻觉集中在最低 30% 区间。<strong>这条规律对任何长文生成任务都成立，而且给出一个很直接的操作点：在低 VAR 区间主动补视觉注意力</strong>
3. <strong>门控是承重件，不是装饰</strong>：无条件地「增强视觉注意力」会伤性能（消融里去掉门控 7B 的 CS 从 16.8 涨到 22.6）。<strong>推而广之：「多看图」不是越多越好，关键是在正确的时机看</strong>——这与 EAPO 的「不该一视同仁地探索」是同一个道理的两种表述
4. <strong>⚠️ 「Algorithm and Theory」这种标题要单独检查两部分有没有连上</strong>：这篇的定理结论（<strong>各头越均匀越好</strong>）与方法（<strong>top-k 挑少数头强化</strong>）方向相反，而且论文自己没做那个关键对照。<strong>以后看到带理论的论文，把「理论说了什么」和「方法做了什么」并排写一行，一看就知道裂没裂</strong>
5. <strong>「无额外延迟/开销」这类声明应该要数字</strong>：训练免费、无需重训、无额外延迟——这些是这篇最吸引人的卖点，恰恰也是只给超参敏感性、没给 wall-clock 的地方

### 待跟进（按性价比）

1. 【最贴合主线·也是本文最大的裂缝】<strong>按 Theorem 5.1 的字面建议做那个缺失的对照</strong>：不改 top-k，改成<strong>让各头的视觉贡献尽量均匀</strong>（例如对 a\_h 做重归一化），看 CS/CI 会怎样。<strong>如果「均匀化」真的更好，这篇的方法就该重写；如果不如 top-k，那定理就该重新解读</strong>——无论哪种结果都是高价值发现，且成本很低（改几行）
2. <strong>把「头间不一致 D\_kl」当成幻觉检测器单独评测</strong>（论文只在 Figure 4 里作为相关图展示）。对照 POPE 的标签算 AUROC，并与 lib 里既有的内部信号类检测器（注意力熵、隐状态探针）比
3. <strong>做因果顺序的控制实验</strong>：注意力涣散是<strong>先于</strong>幻觉 token 出现（因），还是幻觉 token 一出现才伴随涣散（果）？论文只给了相关性
4. <strong>把「时序衰减 VAR」搬到多轮 agent 场景</strong>：EAPO 的「访问深度 κ」与 AFIP 的「VAR 随解码下降」<strong>是不是同一个病的两种表现</strong>（一个在行动空间衰减、一个在注意力空间衰减）？合并起来可能得到一个跨模态统一诊断
5. <strong>AFIP × iVGR 正面对照</strong>：一个改注意力矩阵（AFIP）、一个改输出格式（iVGR），在同一个细粒度基准上比；两者理论上可叠加（一个动内部状态、一个动输出形态）
6. <strong>补 wall-clock 数字</strong>，并做与 VCD 的等延迟对照（VCD 需要两次前向，AFIP 声称一次就够——这正是最有说服力的卖点，却没量化）
7. <strong>验证「VAR 最低 30% 区间幻觉率更高」这个统计</strong>——它是全文最有操作性的结论，也是最该独立复现的一条
8. <strong>在高分辨率 / 小目标场景重测诊断</strong>：COCO 图分辨率有限，「空间不一致」在小目标上会不会更严重

## 九、结论

> 🎁 <strong>今日一句</strong>：<strong>模型胡说八道不是因为「没看图」，而是因为「看得散」和「越看越不看」——论文把这两件事都变成了可测的量：头间注意力不一致（正确词各头共识强、幻觉词各头各飘）和视觉注意力随解码衰减（幻觉密集出现在图像注意力最低的 30% 区间）。AFIP 的做法就是在推理时直接改注意力矩阵：共识加权、分歧惩罚，再把历史看过的补回来，并加一道门控只在必要时动手。</strong>
>
> <strong>数据很硬</strong>：CHAIR 上五个模型全部第一，平均 CS 17.5 对最强基线 26.7、对普通 greedy 46.9；消融显示头级校正是绝对主力（去掉后 CS 暴涨到 49.6）。<strong>而且它自己承认的卖点很实在——免训练、plug-and-play。</strong>
>
> <strong>但全文有一道明显的裂缝</strong>：它的定理说「<strong>各头越均匀，泛化界越紧</strong>」，而它的方法做的是「<strong>top-k 挑少数头再强化</strong>」，<strong>方向恰好相反，两部分之间没有推导链</strong>，也缺了那个最该做的对照实验。这是今天最值得记下来的一条教训——<strong>看到「Algorithm and Theory」并列，要单独检验它们有没有真的连上。</strong>
>
> <strong>最值得带走的一条</strong>：<strong>这篇是 VisualSwap（10/8）的病理报告</strong>——VisualSwap 发现模型嘴上说「再看看图」其实没看，AFIP 给出了为什么（头间不一致 + 时序衰减）。放在 lib 的坐标里，「让模型真的去看图」这条线已经集齐四把不同层的刀：<strong>损失层（PCD）、梯度层（VGS）、输出层（iVGR）、注意力层（AFIP）</strong>。

# 一、为什么今天选这篇

> SEED 同时覆盖本轮关注的四个关键词中的三个核心交集：OPD、RL 与长程推理，并提供视觉 Agent 扩展。论文发布约两周时，开源仓库已获得约 206 个 GitHub Stars（截至 2026-07-31），代码、模型和训练脚本均已公开，兼具时效性、社区关注度与可复现性。

更重要的是，它与前四篇笔记形成自然演进：TOPD、COPD 和 RLCSD 都在追问“如何构造更精细、更可信的 token 级监督信号”，Re² 则在扩展推理过程中的策略动作。SEED 把问题推进到长程 Agent：轨迹结束后得到的经验，怎样变成当前策略可吸收的密集监督，而不是只靠一个稀疏的成功或失败分数？

![Figure 1: Overall performance overview. Compared with powerful baseline methods, Seed achieves the strongest average performance across three representative agentic benchmarks.](/images/paper-reading/2026-07-31-seed/2026-07-31-d05-1.png)

# 二、TL;DR

长程 Agent 的 outcome-based RL 只有 episode 级奖励，中间每一步为什么对、为什么错通常无人指导。SEED 让当前策略在完成轨迹后分析自己的行为，提炼出自然语言形式的 hindsight skill；随后对同一个已采样动作，分别在“普通上下文”和“加入该技能的上下文”中重新评分。技能带来的 log-probability 增量被转化为 token 级 OPD 信号，并与 GRPO 的轨迹级奖励联合训练。

直观地说，SEED 不是要求模型在推理时查技能库，而是在训练时问：“如果你事先知道这条事后经验，哪些动作 token 会更有把握？”然后把这部分概率变化蒸馏回不带技能提示的普通策略。最终部署时只保留策略模型，不需要分析器、检索模块、技能库或额外提示。

# 三、Motivation：Agentic RL 的监督鸿沟

长程 Agent 任务通常包含多轮观察、行动、工具调用与环境反馈。一次任务可能有几十个决策，但 outcome reward 往往只有最终成功或失败。GRPO 可以比较同一问题下多条轨迹的回报，却仍难判断究竟是哪一步观察、规划或动作导致了结果，这就是 episode-level outcome 与 token-level policy learning 之间的监督鸿沟。

完成后的轨迹实际上蕴含丰富的事后知识：哪些子目标已经完成、哪个观察是决定性的、哪里发生了策略偏离、怎样避免循环、什么工作流可以复用。传统做法通常把这些知识固化为静态经验库，或在推理时作为 prompt 注入。前者会随着策略更新而过时，后者增加推理成本，而且模型可能“读到技能”却没有真正内化。

SEED 的关键问题是：能否让 hindsight supervision 随策略共同演化，并把技能的行为作用直接蒸馏进策略参数？

# 四、Method：从事后技能到自演化 OPD

![Figure 2: Overview of Seed. Stage 1 (Hindsight Skill SFT) equips the policy to extract hindsight skills from completed trajectories. Stage 2 (Self-Evolving On-Policy Distillation) jointly optimizes outcome-based RL and skill-conditioned OPD in a self-evolving agentic loop.](/images/paper-reading/2026-07-31-seed/2026-07-31-d05-2.png)

## 4.1 POMDP 形式化

论文把 Agent 任务建模为部分可观察马尔可夫决策过程。时刻 t 的策略依据历史 `h_t = (o_0, a_0, ..., o_t)` 生成动作 `a_t`，完整轨迹记为 `τ`，训练目标是最大化轨迹回报 `R(τ)`。难点在于 `R(τ)` 是稀疏的，而动作内部又由多个 token 构成。

![Figure 11: Prompt of actor (the policy model) in ALFWorld.](/images/paper-reading/2026-07-31-seed/2026-07-31-d05-3.png)

## 4.2 Stage 1：Hindsight Skill SFT

第一阶段先让模型学会“复盘”。基础策略对训练任务采样多条完整轨迹，外部分析器根据每条成功或失败轨迹生成自然语言技能，内容可以是可复用工作流、决定性观察或失败规避规则。格式校验通过的样本组成 SFT 数据，模型学习从完整轨迹生成对应的 hindsight skill。 n

这一阶段的作用不是直接提升 Agent 解题能力，而是初始化一个与策略同源的轨迹分析器。论文实验中使用外部模型生成初始技能标注；进入 RL 阶段后，技能生成不再依赖固定的外部分析器，而由当前策略快照承担。

![Figure 10: Prompt of analyzer.](/images/paper-reading/2026-07-31-seed/2026-07-31-d05-4.png)

## 4.3 Stage 2：Self-Evolving OPD

每轮 RL 开始时冻结当前策略快照。该模型同时扮演两个角色：一是 actor，在环境中采集 on-policy 轨迹；二是 analyzer，对刚完成的轨迹生成 hindsight skill。随着策略能力提升，采样到的行为和模型总结出的技能一起变化，因此监督信号不是静态经验，而是与当前策略分布对齐的自演化信号。

对轨迹中的同一个动作 token，SEED 做两次重新评分：

- **普通分支：**仅输入原始历史，得到 `log π(a | h)`。
- **技能分支：**在历史中加入该轨迹提炼出的技能，得到 `log π(a | h, s)`。

二者之差 `Δ = log π(a | h, s) - log π(a | h)` 表示技能对当前动作置信度的影响。SEED 对该差值停止梯度，并通过 sigmoid 置信门控，让技能明显提高概率的 token 获得更强蒸馏权重。换言之，技能分支充当一个“同模型、特权上下文”的 teacher，普通分支是最终需要部署的 student。

## 4.4 RL 与 OPD 的联合目标

SEED 保留基于组内回报标准化的 GRPO 目标，用 episode outcome 保证整体方向；同时加入 token 级 OPD 损失，解决中间动作的 credit assignment。最终目标可概括为：

$$\mathcal{L}_{SEED}=\mathcal{L}_{RL}+\lambda_{OPD}\mathcal{L}_{OPD}$$

这里 RL 决定“整条轨迹是否值得鼓励”，OPD 则回答“事后技能具体改变了哪些动作 token”。两者互补：只用 RL 太稀疏，只用技能蒸馏又可能缺少最终任务正确性的锚点。

![Figure 9: OPD loss dynamics. The loss generally decreases and stabilizes during training, indicating progressive internalization of hindsight skills.](/images/paper-reading/2026-07-31-seed/2026-07-31-d05-5.png)

## 4.5 推理阶段

训练结束后直接使用普通策略分支。分析器、hindsight skill、静态技能库和检索模块全部移除，因此 SEED 的额外成本主要发生在训练期，而非线上推理期。

# 五、Result：跨环境与跨骨干的提升

## 5.1 任务设置与主结果

论文覆盖三类文本 Agent 环境：ALFWorld（文本化具身交互）、WebShop（网页购物导航）和 Search-based QA（需要搜索工具收集证据的问答）。Search-based QA 又包含 NQ、TriviaQA、PopQA、HotpotQA、2WikiMultiHopQA、MuSiQue 与 Bamboogle。模型骨干包括 Qwen2.5-3B-Instruct、Qwen2.5-7B-Instruct 和 Qwen3-1.7B-Instruct；附录还使用 Qwen2.5-VL-7B 在视觉 Sokoban 与桌面操作任务上验证多模态扩展。

# 六、Ablation 与定性观察

## 6.1 消融实验

| Qwen2.5-3B / ALFWorld 配置 | 平均成功率 | 下降 |
|-|-|-|
| 完整 SEED | **91.8** | — |
| 移除 Hindsight Skill SFT | 86.0 | -5.8 |
| 移除 Self-Evolving OPD | 87.0 | -4.8 |
| 改用静态离线技能库 | 84.4 | -7.4 |

静态技能库带来的下降最大，支持论文的核心主张：技能必须跟随当前策略及其 on-policy 轨迹刷新。否则技能可能描述旧策略的错误模式，或者强调当前模型已经掌握、不再构成瓶颈的内容。

## 6.2 ALFWorld 轨迹案例

ALFWorld 的案例中，GRPO Agent 先访问目标容器，再寻找目标物，过程中拿取无关物品并陷入循环；SEED Agent 则先系统搜索可能存放物品的位置，找到目标后直接完成放置，只用了 5 步。这个案例说明 hindsight skill 不只是改善最终动作，还可能重塑搜索顺序与子目标规划。

# 七、局限与批判性阅读

**论文没有单列 Limitations 章节。**以下是基于方法和实验边界的阅读判断，而非作者明确声明。

**训练成本并不低。**每轮既要采样轨迹、生成技能，又要在普通与技能增强上下文下对同一动作重新评分。虽然推理阶段零额外模块，但训练阶段的分析和双分支前向计算可能显著增加成本。论文应进一步报告相对 GRPO 的 wall-clock、显存与 token 开销。

**初始技能质量仍依赖外部分析器。**第一阶段依靠外部模型生成 hindsight skill，这会引入标注偏差。若外部分析器错误归因，SFT 后的自分析器可能继承这种偏差。

**“概率上升”不等同于“因果正确”。**技能分支提高某个动作 token 的概率，只说明技能与该动作相容，并不能自动证明该 token 对最终成功具有正向因果贡献。GRPO outcome 是必要锚点，但 token 级 credit 是否忠实仍需诊断。

**自演化可能放大自偏好。**同一个模型既是 actor 又是 analyzer，容易偏爱自身熟悉的表达与策略。若缺少外部校准，它可能把风格一致性误认为技能价值；这与 RLCSD 揭示的 style drift 风险高度相关。

**多模态证据仍偏初步。**视觉扩展覆盖 Sokoban 与桌面操作，但离真实机器人、复杂 GUI、视频长程推理仍有距离。多模态场景中“技能改变动作概率”究竟来自更好的视觉 grounding，还是更强的语言规划，尚需拆分实验。

# 八、与前四篇工作的对照

| 方法 | 核心问题 | 监督信号 | 关键区别 |
|-|-|-|-|
| TOPD | 长推理轨迹中的真实偏离点难识别 | Near-future trajectory guidance | 利用近未来信息修正 token 级轨迹对齐 |
| COPD | 并非所有 prefix 都同样有价值 | Contrastive prefix signal | 对比好、坏 prefix，选择更有效的前缀监督 |
| Re² | 模型陷入错误路径后不愿回头 | Outcome reward on re-solving | 扩展 action space，让模型学会放弃并重启 |
| RLCSD | OPD 信号被风格 token 主导 | Correct hint 与 wrong hint 的差值 | 通过对比抵消特权上下文带来的共性风格漂移 |
| **SEED** | 长程 Agent 只有稀疏 episode reward | 技能增强与普通上下文的 log-prob shift | 把 on-policy 轨迹转为随策略演化的 hindsight skill，再蒸馏回无技能策略 |

这几篇工作的共同趋势是把监督信号从“整条轨迹对不对”不断细化到“哪个 prefix、哪个 token、哪条事后经验真正改变了决策”。SEED 的新意在于监督来源不再只是 verified solution 或 correct/wrong hint，而是策略对自己完整交互轨迹的结构化复盘。

# 九、最值得跟进的研究问题

1. **SEED 是否也存在 style drift？** 可以复用 RLCSD 的诊断，把技能诱导的概率增量按 task token、tool token、style token 分组，检查信号是否真的集中在决定性动作上。
2. **成功技能与失败规避技能应否分开建模？** 当前自然语言技能可能混合“应该做什么”和“不要做什么”，可尝试双分支对比，构造 positive hindsight 与 negative hindsight 的差分信号。
3. **能否加入 verifier-gated OPD？** 只有当技能增强分支改善局部 value 或最终 outcome 时才信任概率偏移，降低错误归因。
4. **多模态技能如何验证 grounding？** 在视觉 Agent 中对图像区域、视觉 token 和动作 token 分别分析概率变化，确认技能不是只改变语言规划风格。
5. **动态调节 OPD 权重。** 训练早期技能可能价值较大，后期可能产生自我确认偏差；可根据策略熵、技能新颖度或回报方差动态调整 `λ_OPD`。

# 十、今日阅读结论

SEED 的核心贡献可以压缩成一句话：**把“事后才知道的经验”变成训练时的特权上下文，再把特权上下文对动作概率的影响蒸馏回普通策略。**

它把 OPD 从单轮数学推理推进到长程 Agent，并给出一种很有启发性的自演化 teacher：teacher 不一定是更大的模型，也可以是“当前模型 + 对自己刚完成轨迹的复盘”。其优势是监督与当前 on-policy 分布同步更新，部署时无额外负担；其风险则是同源 actor-analyzer 可能产生自偏好、风格放大和错误归因。

如果沿着前四篇的研究脉络继续，下一步最值得做的不是简单复现 SEED 的总分，而是分析它的 token 级 skill-induced shift 到底在教什么。这正好把 RLCSD 的信号诊断方法与 SEED 的 Agentic OPD 结合起来。

## TL;DR

**一句话：多模态 RL 只奖励"最终答对"，分不清模型是"真看图答对"还是"靠语言先验蒙对"——CFPO 在注意力层内部造一条"反事实路径"：把高显著性的视觉注意力（μ+2σ 统计异常区）的 value 换成无信息先验，逼模型"闭眼重答一遍"，然后要求"睁眼答"和"闭眼答"的分布必须有显著分歧（Δcf）——分歧小=没看图=惩罚。这个因果正则即插即用地挂进 GRPO/DAPO（零外部 RM、零感知标注、无 SFT），Qwen2.5-VL-3B 上 10 个榜相对提升 +3.17%（GRPO 系）/+6.25%（DAPO 系），比最强的感知感知方法 PAPO 还高 +1.32%\~2.13%。**

- **核心问题**：结果奖励下的捷径学习（shortcut learning）——优化器无法区分"真跨模态理解"和"利用数据里的伪相关"；病灶诊断为**跨模态显著性的病态分布**：Saliency Deficiency（不看图靠语言先验猜）、Misalignment（注意力被显著干扰物劫持）、Inertia（静态视觉锚点压过逻辑指令）
- **方法**：① 注意力矩阵分解 A = A_H-sal + A_L-sal（高显著区 = 跨模态注意力 Ac 里 >μ+2σ 的统计异常值）；② **反事实路径**：把高显著区的 value V 换成非信息先验 V̄，前向算出"闭眼版"预测 π_cf；③ **Δcf = logπ(睁眼) − logπ(闭眼)** = 视觉证据的净信息增益，作为正则项 γ·KL_cf 加进策略目标；④ CFPO_G / CFPO_D 分别即插进 GRPO/DAPO
- **结果**：ViRL39K（38,870 题）纯 RL 直训 Qwen2.5-VL-3B，**仅 2×A800**；10 榜：GRPO 53.88→CFPO_G 55.30、DAPO 55.60→CFPO_D 58.49；对 PAPO 全胜；训练收敛更快、8 次采样方差更低（稳定性，不是碰运气）
- **主题轮换**：今日**多模态 RL**（按序列从 OPD（9/4 RL-Cap）切出；与 PAPO/BSBT 构成"让模型真看图"三部曲的最新一环）

## 一、先看例子（论文 Figure 3 的真实案例）

> **题目**："如果图里的动物没有条纹、全身一个颜色，它可能是什么动物？"（图里是斑马，**标准答案：马**）

- **GRPO 模型**（训练后仍蒙）："没有条纹的斑马……树林环境……应该是**白犀牛**" ← 完全没看图，靠语言先验编
- **PAPO**（感知感知基线）："森林环境常见**鹿**……" ← 被"森林"背景先验带偏
- **CFPO**（本文）："没有条纹、纯色，就像**马**——同属马科、体型一致，马就是纯色" ← 真的从图上提取了"体型"这个视觉证据

> 三个模型都"在推理"，但前两个的推理里**图根本没参与**——结果奖励给 0 分才能发现，而 RL 训练恰恰只在答案错时笼统惩罚所有 token，分不清"没看"和"想错"。

## 二、动机：结果奖励"看破不了"的捷径学习

### 2.1 病灶

- PPO/GRPO/DAPO 都只按最终答案对错发奖励 → 优化器**无法区分"真跨模态理解"和"钻数据伪相关的空子"**（shortcut learning）
- 论文把 LVLM 的因果不一致按"跨模态显著性分布"分成四种失败模式：

  - **Saliency Deficiency**：高显著视觉区没被用（不看图）
  - **Saliency Misalignment**：注意力被显著**干扰物**劫持（看错地方）
  - **Inertia**：静态视觉锚点压过假设性指令（改不动）
  - 及组合（Deficiency+Inertia）

### 2.2 现有感知感知方法的不足

- PAPO（#17，ICLR 2026）：原图 vs **输入层随机掩码图**的策略 KL——但随机 masking 破坏语义结构完整性，掩掉的可能是背景也可能是证据，信号不干净
- 反事实推理传统（do-算子、因果干预）在 CV 有，但**没人把它塞进 RL 训练回路**

### 2.3 核心问题

- *能不能不靠外部标注、只在模型内部做一场"闭眼重答"的因果必要性测试，把"你有没有真看图"变成可优化的信号？*

> **炸裂点**：CFPO 的"闭眼重答"不是模糊图片、不是删 token，而是**在多头注意力的 value 上做手术**——把高显著跨模态区的 value 换成非信息先验，等价于"只掐断视觉证据的因果通路，保留语言通路"。这是 do(·) 算子在 LLM 隐空间的合法实例化（Rao et al. 2021 的 SCM-隐空间桥接），测出来的 Δcf 就是**这个 token 的回答有多少信息来自图**。

## 三、方法：造一条"反事实路径"，闭眼重答一遍

### 3.1 注意力矩阵分解：谁在"看"？

- 跨模态注意力子矩阵 A_c：文本 query token 对图像 token 的注意力块（过滤系统提示词去格式噪声）
- **高显著掩码**：M_cross[i,j] = 1 若 A_c[i,j] > μ+λσ（λ=2，统计异常值检测——"对当前推理真正关键的证据是少数异常值"假设）
- A 分解为 A_H-sal（证据区）+ A_L-sal（背景/语言区）

### 3.2 反事实路径：把证据掐掉再前向一次

- 事实路径：Z = A_L-sal·V + A_H-sal·V（正常）
- **反事实路径**：Z_cf = A_L-sal·V + A_H-sal·**V̄**（证据区的 value 换成非信息先验 V̄，do(Z=Z_cf)）
- 得到反事实策略 π_cf(o|q,I) = π_θ(o|do(Z=Z_cf))——"闭着眼（只看背景+语言先验）会怎么答"

### 3.3 分歧度 = 视觉证据的净信息增益

- **Δcf = log πθ(o|Z) − log πθ(o|do(Z_cf))**（Eq.8）：睁眼/闭眼的对数似然差，近似两个分布的 KL
- 直觉：Δcf 大 → 这个 token 的回答**强依赖图**（好信号）；Δcf≈0 → 看图闭眼一个样 → 语言先验在开车（捷径，要罚）

### 3.4 即插即用的目标

- J_CFPO = E[Ĵ_clip − β·KL_ref + **γ·KL_cf** − η·Ent]：标准裁剪代理 + 反事实正则（最大化睁闭眼分歧=逼模型用图）+ 可选熵稳定项（η=0.03）
- 挂 GRPO = CFPO_G，挂 DAPO = CFPO_D；**纯 RL、无 SFT、无外部 RM、无感知标注**；干预只多一次同模型前向

## 四、实验

### 4.1 主结果（Table 1，Qwen2.5-VL-3B，ViRL39K 训，10 榜平均 %）

| 算法 | 真实世界榜 AVG | 数学榜 AVG | 总平均 |
|-|-|-|-|
| GRPO / +PAPO_G / **+CFPO_G** | 60.02 / 60.55 / 60.98 | 47.73 / 48.62 / 49.61 | 53.88 / 54.59 / **55.30**（相对 GRPO +3.17%） |
| DAPO / +PAPO_D / **+CFPO_D** | 61.75 / 61.69 / 63.25 | 49.45 / 52.78 / 53.72 | 55.60 / 57.24 / **58.49**（相对 DAPO +6.25%） |

- **对最强感知基线 PAPO 也全面占优**：+1.32%（GRPO 系）/+2.13%（DAPO 系）——差别在干预位置：PAPO 在输入层 mask 图像（破坏语义结构），CFPO 在隐空间做值干预（结构完好）
- **DAPO 收益最大**：DAPO 没有 KL_ref 约束 → 更容易被伪相关带偏 → CFPO 的因果正则恰好当"稳定器"（防止策略漂进幻觉）
- 训练效率：accuracy reward 持续上升不平台化（Fig 2a）；n=8 采样 95% 置信区间方差更低（Fig 2b）——**提升来自因果一致推理，不是随机波动**

### 4.2 消融（Table 2/3）

- **反事实怎么做**：图像 token 均值 V̄ +3.17% > 加噪声 +2.59% > 文本 token 均值 +0.41%（≈无效）——**掐视觉证据才有信号，掐别的没用**，正证 Δcf 度量的是视觉信息
- **阈值 λ**：μ+2σ 最优（+3.17%）；μ+1σ +1.96（太多背景混进"证据"）、μ+3σ +1.39（漏掉关键证据）——统计异常值假设成立
- **正则强度 γ**：CFPO_G γ=0.02 最优（55.30）；CFPO_D γ=0.01+熵 最优（58.49）——与 DAPO 无 KL_ref 的结构互补

### 4.3 配置（全部一手）

- 2×A800 80G（双卡！多模态 RL 论文里罕见的省）；PyTorch 2.6；2 epochs、lr 1e-6、wd 1e-2、rollout batch 384、每题 5 responses
- 10 评测：真实世界（C-VQA-Real/MARS-Bench/POPE/TextVQA/MMMU-Pro-V）+ 数学（Geo3K/We-Math/MMk12/MathVerse/LogicVista）

## 五、Limitations & 批判性思考（论文有独立小节 + 我的阅读）

1. **论文自述**：反事实路径引入**额外计算开销**（每次前向都要拆注意力+多走一条干预路径，附录 B）；未来做效率优化
2. **只在 3B 验证**：附录 D 有大模型/新架构对比，但主表全在 Qwen2.5-VL-3B；γ/λ 的最优点在更大模型上是否移动未知
3. **"证据=统计异常值"是强假设**：μ+2σ 抓的是显著性**峰值**——弥散但关键的视觉信息（整图氛围、纹理类）可能整个落在阈值下，反事实测不到
4. **V̄ 非信息先验的选择影响结论**：图像均值 vs 噪声 vs 文本均值消融显示信号方向正确，但"均值图"仍是分布内样本（模型可能从均值反推场景）——更彻底的对照（如随机置换 token）没做
5. **与 PAPO 的差距小（1.3-2.1%）**：虽然全面占优且稳定性有优势，但输入层 masking 和隐空间干预孰优的**机制归因偏弱**（一个理论卖点，一组消融没扫透）
6. **单轮静态任务**：agent/多轮/视频里"高显著区"快速转移，掩码 μ+2σ 的稳定性没验证

> **定位差异**：
> - **vs PAPO（正面竞争）**：两篇是"感知感知 RL"的上下位——PAPO 证明"要感知对比信号"，CFPO 证明"信号要在干净的因果位置提取"；PAPO 是输入层 masking 的天花板，CFPO 把它卷进了隐空间
> - **vs BSBT（哲学对照）**："怎么检验模型真看了图？"——BSBT 让模型把看到的写出来、别人盲测（外化）；CFPO 直接掐掉视觉通路做消融实验（内化）。外化可解释、内化可微分，互补
> - **对 OPD 主线的钩子**：Δcf 本质是一个**教师无关的稠密奖励**（每次前向自带）——搬进蒸馏就是"教师的视觉证据必要性蒸馏"：学生学教师的模式时，同时学"这些模式有多少来自图"

## 七、启发与待跟进

> **核心启发**：
> 1. **"闭眼重答"是最便宜的因果探针**：不标注、不训 RM，同模型多一次 value 干预前向就拿到"这个 token 有多少来自视觉"——do-算子在隐空间的工程化样板
> 2. **统计异常值定位证据**（μ+2σ）：关键视觉信息是稀疏峰值而非弥散背景——给"什么是重要的感知"一个免监督的操作化定义
> 3. **正则的"位置"决定信号纯度**：同一种对比思想，输入层 masking（PAPO）被结构损坏拖累，隐空间干预（CFPO）干净——设计对比信号时先问"干预打在哪一层，会不会引入混淆"
> 4. **无约束 RL 更需要因果锚**（DAPO 无 KL_ref → CFPO 增益最大）——奖励越松，过程约束越值钱

### 待跟进 checklist

- [ ] **CFPO × OPD**：把 Δcf 当学生侧"视觉必要性"门控（接 PCD 软 AND 门的坑位）——蒸馏时教师的 Δcf 小 token 降权（教师可能也是蒙的）

- [ ] **CFPO × BSBT**：内化探针（注意力干预）+ 外化盲测（蒙眼推理器）双信号一致性验证——同一个"看没看"的两个测量应强相关

- [ ] **λ 的自适应性**：证据弥散任务（风格/氛围判断）里 μ+2σ 失效的边界在哪；能否 top-k 或信息论自适应

- [ ] **开销量化**：附录 B 只承认"有开销"——多一次干预前向的实测倍率（论文没给具体数字），值不值 1.3-2.1% 的 PAPO 差距

- [ ] **多轮/视频扩展**：显著区动态转移下掩码稳定性

- [ ] **代码核对**：GitHub 已开源——看干预实现在哪些层（逐层还是抽样层），论文正文未细说

## 八、今日阅读结论

CFPO 是"让模型真看图"这条感知感知 RL 线的最新一环（ICML 2026，北邮）：它把"你有没有用图"从玄学变成一个**可微的因果测量**——在注意力 value 上掐断高显著视觉证据（do-算子），让模型闭眼重答，睁眼闭眼分歧（Δcf）不够大就说明你在靠语言先验开车，罚。即插进 GRPO/DAPO，零外部依赖，10 榜相对提升最高 +6.25%，比 PAPO 还稳赢 1.3-2.1%。连上你最近的阅读链：RL-Cap（#30）诊断"RLVR 缺细粒度过程信号"，PAPO（#17）用输入掩码开第一版药，BSBT（#26）用外化盲测开第二版，**CFPO 用隐空间反事实开第三版——三版药方都指向同一件事：后训练的下一步竞争，在"过程信号的因果纯度"**。对你 OPD 主线，Δcf 这个"教师无关的稠密视觉贡献信号"是最该抢的积木：把它接进蒸馏门控（教师 Δcf 小=蒙对的别学），就是下一篇论文的选题。

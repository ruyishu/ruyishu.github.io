> 2026-11-04 · 每日阅读 #71 · 本周 <strong>OPD / 蒸馏</strong>（第 3 周第 3 篇）· <strong>没有外部老师：模型看着范例当自己的老师</strong> · MIT Improbable AI Lab + ETH Zurich · ICML 2026 Spotlight

## TL;DR

<strong>一句话：只有示范答案、没有奖励时，以前只能做 SFT（逐字抄示范），学了新本事、旧本事掉一大截。这篇让同一个模型演两个角色：看过示范的它当老师，没看示范的它当学生；学生自己答，老师逐 token 打分。结果新任务学得更好，旧能力几乎不掉。</strong>

- <strong>新意在哪</strong>：老师不是另一个大模型，也不是 GRPO 训出来的，就是<strong>把示范塞进 prompt 的自己</strong>。这样「只有示范」的数据也能做 on-policy 学习，不用先学奖励函数
- <strong>主结果（Qwen2.5-7B-Instruct，新任务准确率 / 6 个旧榜平均）</strong>：Science <strong>SFT 66.2 / 53.4 → SDFT 70.2 / 64.5</strong>；Tool Use <strong>63.2 / 56.0 → 70.6 / 65.4</strong>；Medical <strong>35.5 / 60.2 → 40.2 / 65.4</strong>；底座旧榜平均 <strong>65.5</strong>
- <strong>最刺眼的一格</strong>：在 Science 上做 SFT，IFEval 从 <strong>74.3 掉到 35.3</strong>；SDFT 是 <strong>66.8</strong>
- <strong>灌新知识（2025 年的 9 篇灾害百科）</strong>：严格准确率 SFT <strong>80</strong> → SDFT <strong>89</strong>（Oracle RAG 91）；间接提问 SFT <strong>80</strong> → SDFT <strong>98</strong>
- <strong>只有答案、没有思维链的数据</strong>：Olmo-3-7B-Think 做 SFT 从 <strong>31.2 掉到 23.5</strong>，回答长度 4612 → 3273；SDFT 涨到 <strong>43.7</strong>，长度 4180
- <strong>⚠️ 理论和实际用的 loss 不是一个</strong>：全文推导（含「等价于逆强化学习」）都是 <strong>reverse KL</strong>，但正文一句话承认实际 <strong>forward KL 更好</strong>，仓库 README 更直接：<strong>论文里所有结果都是 forward KL 跑的</strong>
- <strong>⚠️ 要靠模型本身会「照着例子学」</strong>：3B 上 SDFT 比 SFT <strong>低 3.3</strong>，7B 高 4.0，14B 高 6.9
- <strong>⚠️ 贵</strong>：比 SFT 多 <strong>2.5 倍 FLOPs、约 4 倍墙钟时间</strong>；没和 RL（GRPO）比，可 Science 和 Tool Use 都有现成的对错判分
- <strong>✅ 仓库</strong>：728 star / 85 fork，TRL 实现，单张 H200 能跑，Science + Tool Use 的训练、数据、评测都在，TRL 官方也集成了 SDFTTrainer；<strong>⚠️ 没有 LICENSE、没有权重、Medical 和知识数据还没放</strong>

## 一、先看例子（大白话：同一道题，SFT 和 SDFT 怎么教）

> 🧪 <strong>题目（Tool Use，示意）</strong>：给模型一份天气 API 文档，用户说「帮我查明天北京会不会下雨」。
>
> <strong>示范答案</strong>：先说一句思路，再写出 getForecast(city=Beijing, days=1)。
>
> 底座 Qwen2.5-7B 在这类题上只做对 <strong>42%</strong>。

<strong>SFT 怎么教</strong>：逼模型把示范<strong>一个字一个字抄下来</strong>。示范是 GPT-4o 或人写的，句式、长短、口吻都和模型自己不一样。模型为了抄得像，会把自己原来的说话习惯一起改掉。这就是为什么在 Science 上 SFT 完，<strong>IFEval（按格式要求回答）从 74.3 掉到 35.3</strong>：任务学会了，原来会的东西被冲掉了。

<strong>SDFT 怎么教</strong>：

1. <strong>学生</strong>（只看题）自己先答一遍，比如写了 getWeather(location=北京)。
2. <strong>老师</strong>是同一个模型，但 prompt 里多塞了示范：「这是一个参考答案……现在用你自己的话答」。它不重新写答案，只给学生写的每个 token 打分。
3. 老师看过示范，知道该调 getForecast、参数叫 city，所以在 getWeather 和 location 这几个 token 上给的概率很低，<strong>学生就知道错在哪几个字</strong>。
4. 学生朝老师的分布挪一点，下一题再来。

<strong>关键差别</strong>：学生学的是「自己的话 + 老师的修正」，不是「别人的原话」。论文量了一下：SFT 训完的模型离底座 <strong>1.26 nats</strong>，看过示范的老师离底座只有 <strong>0.68 nats</strong>，差不多一半。<strong>离原来的自己越近，旧本事掉得越少。</strong>

## 二、动机

- <strong>已知</strong>：on-policy RL（学生自己采样再学）比 SFT 忘得少，作者自己的 RL's Razor 和 Retaining by Doing 都说过这一点
- <strong>问题</strong>：RL 要奖励函数。很多真实场景只有<strong>示范</strong>（人写的标准答案、专家轨迹），没有能自动判分的规则
- <strong>老办法</strong>：要么 SFT（off-policy，会忘），要么逆强化学习先学一个奖励（难、要强假设，基本只在 RLHF 里落地了）
- <strong>这篇的想法</strong>：大模型本来就会「看一个例子照着做」（in-context learning）。那就让<strong>看过示范的自己</strong>来当老师，直接拿到逐 token 的 on-policy 信号，不用显式学奖励

## 三、方法

![论文 Figure 2。左：同一个 LLM 两种模式，学生只看问题得到分布 P，老师多看一份示范得到分布 Q，学生按 P 采下一个 token，再按 P 与 Q 的差更新学生。右：示意图，等高线是离底座的 KL，看过示范的老师（Teacher）比示范本身（Demonstrator）离底座近得多，SDFT 训完落在底座和老师之间](/images/paper-reading/2026-11-04-sdft/2026-11-04-d72-1.webp)

### 3.1 老师的 prompt（就这么简单）

> 题目 → 「This is an example for a response to the question:」→ 示范 → 「Now answer with a response of your own, including the thinking process:」

作者说这句话足够让老师不去原样复读示范，而是按自己的理解重新组织。

### 3.2 训练目标

- <strong>写在论文里的</strong>：学生采样 y，最小化 KL(学生 ‖ 老师)，也就是 <strong>reverse KL</strong>，逐 token 拆开、对全词表算解析值
- <strong>理论包装</strong>：把「看过示范的自己」当成 trust-region RL 的最优下一步策略，那么隐式奖励就是 log 老师概率 − log 学生概率，它的策略梯度正好等于 reverse KL 的梯度。所以作者说 <strong>SDFT 等价于一种逆强化学习</strong>
- <strong>⚠️ 实际跑的</strong>：正文同一节一句话：<strong>实践中 forward KL 最好</strong>。仓库 README（2026-04-07）：查了一下发现<strong>论文所有结果都是 on-policy 采样 + 逐 token forward KL</strong>，类似 GKD。也就是说上面那套逆强化学习推导，<strong>不是论文数字背后的那个算法</strong>

### 3.3 三个工程细节（缺一个就训不稳）

1. <strong>老师用 EMA</strong>：冻住的底座当老师，稳但学不动；直接用当前学生当老师，会自我放大直至发散；EMA 折中最好（附录 Figure 8）
2. <strong>解析 KL 估计</strong>：比只看采到的那个 token 方差小、更稳；无偏的 Rao-Blackwell 版本更贵但没带来收益；每题采多条也几乎没用，所以每题 1 条
3. <strong>跳过前 3 个 token</strong>：老师看过示范，开头爱说「根据例子……」，学生会跟着学，于是前几个 token 不计 loss。作者自己承认这是土办法

## 四、实验

### 4.1 学新技能 + 不忘旧本事（Table 5）

| 方法 | Science 新任务 | Science 旧榜 | Tool 新任务 | Tool 旧榜 | Medical 新任务 | Medical 旧榜 |
|-|-|-|-|-|-|-|
| 底座 | 32.1 | 65.5 | 42.9 | 65.5 | 30.1 | 65.5 |
| SFT | 66.2 | 53.4 | 63.2 | 56.0 | 35.5 | 60.2 |
| SFT + re-invoke | 66.0 | 60.2 | 63.1 | 63.7 | 35.6 | 62.6 |
| DFT | 54.8 | 60.2 | 64.2 | 60.8 | 36.2 | 64.0 |
| <strong>SDFT</strong> | <strong>70.2</strong> | <strong>64.5</strong> | <strong>70.6</strong> | <strong>65.4</strong> | <strong>40.2</strong> | <strong>65.4</strong> |

<strong>怎么读</strong>：看「旧榜」三列，SDFT 只比底座低 0.1\~1.0；SFT 低 5.3\~12.1。re-invoke（SFT 完再用底座做一轮 OPD 补救）能补回一部分，但补不满，而且要多训一个阶段。<strong>新任务列 SDFT 也是最高</strong>，比 SFT 高 4.0 / 7.4 / 4.7。

![论文 Figure 4：横轴新任务准确率，纵轴旧能力平均。灰点是底座，SFT（红）往右下掉，re-invoke 往上补一截，DFT（绿）在中间，SDFT（蓝）几乎水平往右走](/images/paper-reading/2026-11-04-sdft/2026-11-04-d72-2.webp)

### 4.2 连续学三个任务（Figure 3）

![论文 Figure 3：同一个模型依次学 Tool Use、Science、Medical，纵轴按底座＝0、两种方法里的最好成绩＝1 归一化。左 SDFT 学新任务时老任务基本保持；右 SFT 每换一个任务，前一个任务就掉到 0 以下](/images/paper-reading/2026-11-04-sdft/2026-11-04-d72-3.webp)

SFT 那张图很直观：一换任务，上一个任务就从 0.8 左右掉到负数。SDFT 好得多，但<strong>也不是完全不掉</strong>：Tool Use 在开始学 Science 后从约 0.95 降到约 0.8，之后一直在 0.8 附近。

### 4.3 灌新知识（Table 1）

| 方法 | 严格准确率 | 宽松准确率 | 间接提问（OOD） |
|-|-|-|-|
| 底座 | 0 | 0 | 0 |
| Oracle RAG（直接给对的文章） | 91 | 100 | 100 |
| CPT（直接在文章上续训） | 9 | 37 | 7 |
| SFT（在问答对上训） | 80 | 95 | 80 |
| <strong>SDFT</strong> | <strong>89</strong> | <strong>100</strong> | <strong>98</strong> |

老师的 prompt 里放什么也很关键（附录 Figure 7）：只放答案 <strong>37%</strong>，只放原文 <strong>75%</strong>，原文 + 答案 <strong>89%</strong>。

### 4.4 规模和 pass@k（Figure 5）

![论文 Figure 5。左：Science 任务上 SDFT 减 SFT，3B 为 −3.3，7B 为 +4.0，14B 为 +6.9。右：pass@k（k 从 1 到 128），SDFT 一直在 SFT 上面，两者都远高于底座，但 SDFT 和 SFT 的阴影带有不少重叠](/images/paper-reading/2026-11-04-sdft/2026-11-04-d72-4.webp)

- <strong>模型越大越占优</strong>：因为老师的质量取决于模型「照着例子学」的能力，3B 不够用
- <strong>不是靠压熵刷分</strong>：pass@128 也比 SFT 高（约 0.89 vs 0.86），说明不只是把概率集中到少数答案上

### 4.5 关键消融：是老师好，还是 on-policy 好？（Figure 6）

同一个「看过示范的老师」，换三种用法（Tool Use）：① 让老师生成答案再 SFT ② 在老师生成的固定数据上做离线 KL 蒸馏 ③ SDFT（学生自己采样）。<strong>①② 都比普通 SFT 好，但都追不上 ③</strong>。结论：<strong>收益不只是老师好，学生在自己的轨迹上学才是关键</strong>。

### 4.6 推理模型用「只有答案」的数据（Table 2）

Olmo-3-7B-Think 在 Medical 上（数据没有思维链）：底座 <strong>31.2</strong>（平均 4612 token）→ SFT <strong>23.5</strong>（3273 token，推理被抄短了）→ SDFT <strong>43.7</strong>（4180 token）。<strong>老师是自己，所以会用自己的长推理风格去解释那个短答案</strong>，学生学到的是「答对 + 保留思考习惯」。

## 五、Limitations

### 论文自述的（有独立一节）

- <strong>算力</strong>：约 2.5 倍 FLOPs、4 倍墙钟时间（作者说如果算上 re-invoke 那类两阶段方法，总时间可能更少）
- <strong>学到老师的口头禅</strong>：「Based on the text...」这类话，靠跳过前几个 token 压住，是土办法
- <strong>依赖模型的 in-context 能力</strong>：小模型不行；而且<strong>很难做大幅度的行为改变</strong>，比如把不会写思维链的模型训成会写，作者试了，难
- 仍有少量遗忘；没试过有噪声的示范或真实用户对话

### 我读出的 7 条

1. <strong>⚠️ 理论和实际脱节（最要紧）</strong>：Eq.1、Eq.2、Figure 2 图注、3.1 节的逆强化学习等价，全部基于 reverse KL；实际所有结果是 forward KL。forward KL 下「隐式奖励 = log 老师 − log 学生」这条推导不成立。<strong>论文最漂亮的那段理论，解释的不是它自己跑出来的数字</strong>。v2 只在正文加了一句，Figure 2 图注仍写 reverse KL
2. <strong>⚠️ 缺 RL 对照</strong>：Science 是选择题、Tool Use 用正则判对错，<strong>都能直接跑 GRPO</strong>，而作者自己的前作就说 on-policy RL 忘得少。论文说 SDFT「和 RL 互补」，但没给同任务上的 GRPO 数字，读者没法判断「有示范时用 SDFT」比「有判分时用 RL」好还是差
3. <strong>⚠️ 也缺常见的防遗忘对照</strong>：LoRA、混入旧数据回放、加 KL-to-base 的 SFT、更小学习率，一个都没比。对照只有 SFT / DFT / re-invoke，「SDFT 忘得少」的参照系偏弱
4. <strong>「老师 100% 正确」的验证太便宜</strong>：Tool Use 上老师 prompt 里就放着正确的 API 调用，答对 100% 几乎是必然；所谓「推理过程正确」只人工看了 50 条
5. <strong>「没有退化」说重了</strong>：摘要说连续学习「without performance regression」，但 Figure 3 里 Tool Use 学完 Science 后从约 0.95 掉到约 0.8；单任务表里 Science 后旧榜平均也从 65.5 掉到 64.5、TruthfulQA 47.9 → 46.5
6. <strong>知识实验太小、判分自己人</strong>：只有 9 篇文章约 20 万 token；问答由 GPT-5 生成、GPT-5-mini 判分；间接提问（OOD 98%）是怎么出的、出了多少，正文和附录都没写清楚
7. <strong>算力账和训练轮数没对齐</strong>：SDFT 通常训 2 个 epoch，SFT 1 个；再加 4 倍墙钟。没有等算力下的 SFT 对照。规模实验只在 Science 一个任务上、每个规模一个点

<strong>仓库问题</strong>：没有 LICENSE（不能放心商用或改了再发）；没有权重；Medical 和知识数据承诺了没放；README 里的评测脚本名和仓库对不上；生成长度 1024 vs 论文 2048。<strong>Science 和 Tool Use 两条线能复现，其余要自己补</strong>。

| <strong>ZwZ</strong>（11/02） | 训练时在图上画框，推理时不画 | <strong>同一个模式</strong>：训练时能拿到、推理时拿不到的信息当特权信息。ZwZ 的特权信息是框，SDFT 是示范答案 |
| <strong>OPSD / Self-Distilled Reasoner</strong>（8/19） | 让模型看着答案教自己 | <strong>同期撞车</strong>：本篇相关工作里点名 Zhao 2026 和 Hübotter 2026 是并发工作。区别是 OPSD 主攻数学推理，SDFT 主打「防遗忘 / 持续学习」 |
| <strong>SDPO</strong>（9/30） | 把环境反馈塞给自己当老师 | <strong>同一伙人</strong>（Hübotter 是两篇共同作者）。SDPO 的特权信息是环境反馈，SDFT 是示范；骨架一样：同一模型、老师多看一点东西 |
| <strong>π-Distill</strong>（10/13） | 共享参数，老师看前沿模型的动作轨迹 | π-Distill 的脚注把 Shenfeld 2026 列为并发工作。π-Distill 让老师也训（联合目标），SDFT 让老师当学生的 EMA，<strong>两种防老师漂走的办法</strong> |
| <strong>TMS</strong>（9/14）/ <strong>Forget-Me-Not</strong>（9/29） | on-policy 或回放能防遗忘 | SDFT 把「on-policy 忘得少」这条经验从 RL 推广到「只有示范」的场景。但 Forget-Me-Not 说的「加一点回放」，本篇没拿来比 |
| <strong>CapCurriculum</strong>（10/22） | 只训推理会交「感知税」 | 同一类现象：<strong>后训练会悄悄把别的能力换掉</strong>。SDFT 的 Table 5 把这笔税量得很清楚（SFT 让 IFEval 掉 39 分） |

<strong>一句话串起来</strong>：本周三篇都在把「贵的东西」压进模型——ZwZ 压工具，Video-OPD 压 GRPO 的多次采样，SDFT 干脆<strong>连外部老师都省了，用 prompt 里的一份示范造出老师</strong>。从方法新意看，这是本周最实质的一篇。

## 七、启发与待跟进

1. <strong>💡 只有示范数据时，先试 SDFT 再试 SFT</strong>：改动就是把示范塞进老师 prompt + 学生自己采样，TRL 已有现成 Trainer，单卡能跑 7B
2. <strong>💡 把「后训练会忘」当回归测试</strong>：任何微调都挂上 IFEval / TruthfulQA，这两个在本篇里对 SFT 最敏感
3. <strong>💡 老师用 EMA</strong>：自蒸馏里老师既不能冻死也不能和学生同步，EMA 是便宜好用的折中
4. <strong>💡 有推理模型、但数据只有答案时</strong>：SFT 会把思考链抄短，SDFT 这种「自己解释答案」的方式能保住推理习惯
5. <strong>待跟进</strong>：① 同任务上补一个 GRPO 对照（Science / Tool Use 都有现成判分） ② 跑一遍 reverse KL 和 forward KL 的对比，看论文的理论到底对不对得上 ③ 补 LoRA / 回放 / KL-to-base SFT 这几个防遗忘基线 ④ 在等算力下比 SFT（SFT 也多训几轮或多扫几档）

## 八、结论

<strong>想法真有新意，而且简单</strong>：同一个模型，看过示范的自己当老师，没看的自己当学生，就把「只有示范」的数据变成了 on-policy 信号。三个技能任务上新任务更高、旧能力几乎不掉，Table 5 的数字很干净。

<strong>要打折的地方</strong>：论文的逆强化学习理论是按 reverse KL 推的，实际数字全是 forward KL 跑的；没和 RL、没和常见防遗忘方法比；小模型不行；贵 4 倍；仓库没 LICENSE、没权重、少两份数据。

<strong>今日一句</strong>：<strong>最好的老师，可能就是看过答案的你自己——前提是你本来就会照着例子学。</strong>

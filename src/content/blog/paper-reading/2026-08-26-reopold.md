## TL;DR

**一句话：OPD 本质上就是策略优化——师生 log 似然比就是逐 token 奖励；REOPOLD 用三个「轻拿轻放」的手段（混合奖励裁剪 + 熵感知 token 级动态采样 + 先探索后精修两阶段）稳定训练，数学/视觉/Agentic 三域通吃，6.7\~12× 样本效率，视觉上 7B 学生追平 32B 教师（\~3.32× 推理加速）。**

- **理论定性**：OPD 的反向 KL 目标 ≡ 以 log(π_te/π_θ) 为 token 奖励的策略梯度；stop-gradient 让奖励「固定」，期望梯度不变但方差大降（控制变量），梯度范数更低更稳
- **三大病灶**：① 重尾负奖励（学生采到教师概率≈0 的 token → 灾难性负梯度）；② 近零奖励稀释（多数 token 师生已对齐，信号≈0）；③ 熵塌缩（训练早期快速收敛，调高采样温度反而更糟）
- **REOPOLD**：λ=0.3 混合裁剪把负奖励钉在有限下界 logλ/(1−λ)；只在学生熵 top β 分位（β=0.2）的 token 上放梯度；前 1/3 步数只奖不罚（探索），之后只在高熵处引入负反馈（精修）
- **结果**：数学 1.5B 六榜平均 **57.1**（RKL 54.4）；视觉 3B **52.18**（RKL 48.99）、7B **57.76**；Agentic 平均 **65.75**；样本效率 vs ProRL **×6.7**、vs DeepScaleR/DeepMath **×12**

## 一、先看一个例子

> 学生被要求化简 √242，写到一半：`242 = 3 × 11²`（其实错了，242 = 2 × 11²）。教师在「3」「√3」这些 token 上的概率≈0——标准的反向 KL（RKL）在这里给学生一记重锤（深红 = 强负奖励），整条 rollout 的梯度被这几个 token 主导。更麻烦的是：多数 token（「First, factor」「Therefore, the」）师生早已对齐，奖励≈0，什么也学不到。真正有信息量的分歧只出现在少数「决策点」token 上。REOPOLD 的做法：把负奖励钉在有限下界（轻锤不砸死）、只在熵高的 token 上算梯度（上课只讲分歧点）、训练前半程只表扬不批评（先学会走路再纠姿势）。

> **直觉**：教师是园丁不是铁匠——把「学生已经会的」和「学生瞎编的」都筛掉，只在高信息量处轻推一把，训练自然稳。

## 二、动机：OPD 的病根在「信号分布」

### 2.1 理论：OPD 就是策略优化（Eq. 3）

`J_RKL(θ) = E[ 1/Σ|o| · ΣΣ ρ(θ)·R(θ) ]，R = log(π_te/π_θ)`

- 与标准 RL 唯一的区别：奖励 R 自身也含 θ——stop-gradient 后二者期望梯度等价（Remark 3.1），但有限样本下 stop-gradient 是**控制变量**：训练损失动力学几乎不变，梯度范数却显著更低更稳，验证集更好（Figure 3）
- 这一「等价性」是全文的钥匙：**RL 攒了十年的优化工具箱（重要性比裁剪、动态采样、分阶段训练）可以合法地搬进 OPD**

### 2.2 三个实证病灶

- **重尾负奖励**（Figure 4）：token 奖励的 log 尺度直方图上，负侧有一条长尾——少数「学生瞎编、教师零概率」的 token 产生灾难性负梯度，主导并破坏整个更新
- **近零奖励稀释**（Figure 5）：熵最低的 60% token 奖励几乎全堆在 0 附近——师生已对齐的确定性 token 不产生学习信号；真正的分歧集中在高熵的「决策点」token 上
- **熵塌缩**（Figure 6）：训练早期学生熵快速下降、过早收敛；调高采样温度只会让采样更偏离教师分布，越调越差

![图片展示了REOPOLD算法流程及两个token奖励直方图。左侧是REOPOLD算法步骤，输入学生策略、教师策略、查询集，设定超参数，输出训练后学生模型，初始化参数等。右侧是Math Reasoning和Visual Reasoning两个任务的token奖励直方图，横轴为熵，纵轴为对数似然比奖励，图中红虚线为熵的60百分位，数值分别为0.6563和0.6758。该图与上下文关系紧密，直观呈现了文中提到的“近零奖励稀释”问题，即熵最低的token奖励几乎堆在0附近。](/images/paper-reading/2026-08-26-reopold/2026-08-26-d24-1.png)

> **炸裂点**：把「奖励分布」而不是「loss 形式」当问题来治——之前的 OPD 工作都在换 KL 方向（前向/反向）、加正则（熵奖励），REOPOLD 直接对奖励信号本身开刀，还借来了 RL 的整套工具箱。

## 三、方法：三个「轻拿轻放」组件

统一目标（Eq. 4）：`J_REOPOLD = E[ 1/ΣΣM · ΣΣ ρ(θ)·R̂^λ(θ)·M ]`——一个裁剪后的奖励 R̂^λ + 一个可切换的 token 掩码 M，整个方法就是「奖励怎么裁、掩码怎么选」。

![这张图片展示了两种策略蒸馏方法处理学生回答问题的对比，主题是化简√242。左侧(a)部分为标准在线策略蒸馏（RKL），呈现了带有错误的学生化简过程，最终得出答案11√3，搭配的卡通角色形象带有负面标注属性。右侧(b)部分为放松在线策略蒸馏（REOPOLD），展示了正确的化简过程，标注提示保留了关键的正确推导内容，同时配有不同颜色的标注图例，绿色代表正向内容、0代表跳过项、红色代表负向内容，明确了两种方法对学生学习过程的不同处理方式，体现了REOPOLD方法的优化特点。](/images/paper-reading/2026-08-26-reopold/2026-08-26-d24-2.png)

### 3.1 混合奖励裁剪（Eq. 5, 7）——治「重尾负奖励」

- 用师生凸混合分布 (1−λ)·π_te + λ·π_θ 给 log 比找一个**有限上界**：R ≤ logλ/(1−λ)；当 π_te→0 时 R 发散到 −∞，而混合项收敛到有限常数，这个常数就是裁剪下限
- `R̂^λ = max(sg(R), logλ/(1−λ))`，默认 **λ=0.3**——只钉离群的负值 token，不碰 RKL 的 mode-seeking 主体
- 对照 Skew RKL：Skew RKL 全局改目标、对 λ 极敏感（λ=0.7 性能就崩，Figure 12）；REOPOLD 只处理尾部，天然鲁棒

### 3.2 熵感知 token 级动态采样（Eq. 8）——治「近零信号稀释」

- 用**学生策略熵** H_t 作信息密度代理，取 batch 内 top β 分位（默认 **β=0.2**）为阈值 τ_β，掩码 `M = 𝕀[H_t ≥ τ_β]`
- 只在「师生真分歧」的 token 上放梯度，归一化分母同步收缩——比 DAPO 的 prompt 级动态采样更细一个粒度（token 级），跨模型规模鲁棒
- 实证依据（Figure 5）：低熵 token 奖励≈0（噪声），高熵 token 才携带分歧信息

### 3.3 探索→精修两阶段（Eq. 9, 10）——治「熵塌缩」

- **阶段 I（前 T_switch ≈ 1/3 总步数）**：`M = 𝕀[R ≥ logλ/(1−λ)]`——负奖励 token 直接不参与梯度，只强化正向行为（≈ SFT 动力学），保住多个教师对齐的模式，防止熵塌缩；此时关闭动态采样（密集监督，严格对齐）
- **阶段 II**：`M = 𝕀[H_t ≥ τ_β]`——重新引入负反馈，但只在高熵分歧点上，精修收敛
- 效果（Figure 6）：Avg@32 与 Pass@32 **同时**上升——质量提升不靠牺牲多样性；两阶段全程采样温度 1.0，无需退火

## 四、实验

### 4.1 数学（Table 1，SkyWork-OR1-Math-7B → R1-Distill-Qwen-1.5B，45K prompts，300 steps）

| 方法 | AIME24 | AIME25 | AMC23 | MATH500 | Minerva | AVG |
|-|-|-|-|-|-|-|
| Base 1.5B | 28.6 | 22.7 | 62.6 | 82.9 | 26.4 | 44.4 |
| +GRPO | 31.8 | 23.7 | 62.0 | 85.4 | 33.8 | 47.8 |
| +SFT | 33.5 | 24.6 | 76.1 | 86.6 | 36.4 | 51.5 |
| +RKL | 37.1 | 30.6 | 80.2 | 88.0 | 34.6 | 54.4 |
| **+REOPOLD** | **41.6** | **32.6** | **83.0** | **89.2** | **38.6** | **57.1** |

- 7B 教师（SkyWork-OR1-7B）时 RKL 几乎没动（46.5 vs base 44.4，负迁移），REOPOLD 仍有 **51.5**（+10.75%）——RKL 对教师选择高度敏感，REOPOLD 鲁棒
- 7B 学生（Figure 7）：vanilla RKL 在 AIME-24 上先掉后爬、始终打不过 base；REOPOLD 单调上升——「教师更大更聪明」不再是负担

### 4.2 样本效率（Figure 1a）

- 600 步追平 ProRL 的 2000 步 → **×6.7**；300 步超过 DeepScaleR-1.5B-Preview / DeepMath-1.5B → **×12**；150 步就打平 RKL 的 300 步
- 同设置重实现的 GRPO 也被压过——增益来自算法本身，不是框架差异

> **三个观察**：① 数学榜 1.5B 六榜平均 57.1 vs RKL 54.4，AIME24 +4.5 分最猛；② 视觉 3B 的 MathVerse **46.40 vs 33.25（+26.44%）**——感知分歧类问题是大赢家；③ 全部设置共用 λ=0.3/β=0.2，几乎没有任务级调参。

### 4.3 视觉（Table 2，Qwen2.5-VL-32B(NoisyRollout) → 3B/7B，Geometry3K 训练）

- 3B：REOPOLD AVG **52.18** vs RKL 48.99（+4.27%）；7B：**57.76** vs 56.51（+2.21%）
- **测试时扩展**（Figure 1b）：Geometry3K / MathVerse 上 Pass@K 随思考时间增长，7B REOPOLD 逼近 32B 教师，平行思考（1→64）带来 \~**3.32× 推理加速**——「小模型 + 多采样」能顶大模型
- 教师鲁棒性（Table 3）：7B 教师下 +1.34、32B 教师下 +0.93（AVG vs RKL），两个规模都赢

### 4.4 Agentic 工具使用（Table 6，Pixel-Reasoner-7B → Qwen2.5-VL-3B，15K）

- REOPOLD AVG **65.75** vs GRPO 64.25 / RKL 63.27（Pixel/V-Star/InfoVQA/TallyQA 四榜三胜一平）
- Figure 10：仅 **50% 训练量**即超越全部基线——无需复杂奖励工程（zoom、关键帧选择等图像工具随 Pixel-Reasoner 协议）

### 4.5 定性：看见 vs 幻觉（Figure 14，HallusionBench）

- 案例：2001–2019 英国食品出口额曲线（整体上升，2010 是问询区间 2001–2010 内的峰值）
- RKL 学生把曲线「看」成一条平坦线（红色高亮：认为每年都 \~400,000 GBP）→ 感知退化、答 No；REOPOLD 准确抓住 2010 为区间峰值（绿色高亮）→ 答 Yes

### 4.6 消融（Table 9，3B 学生，Geo3K/MathVerse/MathVision AVG）

- RKL 35.37 → +stop-grad **39.33** → +奖励裁剪 39.73 → +动态采样 40.81 → 全量 **41.12**；7B 同序（42.75→44.74）
- stop-gradient 单步跳最大（尤其 MathVerse）；动态采样对 Geo3K 贡献最大——**每个组件都加，顺序无关但有累积**
- β=0.2 优于 β=0.5（Figure 9，低熵过滤越狠越好）；更长训练（300 steps + MMK12）差距拉大（3B 54.36 vs 53.44，7B 58.83 vs 56.71）

## 五、Limitations & 批判性思考

1. **论文没有独立 Limitations 章节**（诚实标注）——以下为我的阅读
2. **三个超参只调了两个**：λ、β 有敏感性分析（Figure 11/8），T_switch 未调（固定 1/3 步数）——「何时切阶段」仍是开问题
3. **高熵处假设教师是对的**：如果教师本身在高熵决策点也错（教师 error mode），精修阶段会强化错误——教师不确定性从未被显式建模
4. **视觉教师用 NoisyRollout 而非更强视觉 RL 模型**；训练域只有 Geometry3K，MathVerse/MathVision 只是测试域，跨域泛化证据有限
5. **没有和同期 OPD 方法直接对比**：EOPD / HPD / GNDPO / VGS 全部缺席——「REOPOLD vs 熵门控 vs 偏差符号」三方对照是社区空缺
6. **学生规模下探有限**：数学最小 1.5B，未测 0.5B；未覆盖代码域

## 六、与前文对照（OPD 谱系）

|  | 方法 | 核心创新 | 与 REOPOLD 的关系 |
| --- | --- | --- | --- |
| 18 | OPSD | 特权教师同策略自蒸馏（全词表前向 KL） | 同样在 student rollout 上蒸馏；OPSD 无裁剪无采样，REOPOLD 的裁剪/掩码可直接叠加 |
| 19 | GNDPO | batch 级 z-score 归一化治 token 梯度爆炸 | **同病不同药**：都治「token 级信号尺度失控」，GNDPO 归一化、REOPOLD 裁剪；可先裁剪再归一化双保险 |
| 20 | VGS | 梯度分解掰向视觉子空间 | 都是「按 token 条件路由监督」：VGS 按模态、REOPOLD 按熵/奖励 |
| 21 | HPD | K1 估计器符号混合前向/反向 KL（token 级重加权） | 同是「该不该让这个 token 教学生」的开关：HPD 按偏差符号、REOPOLD 按奖励绝对值 + 熵 |
| 22 | EOPD | 教师熵 H_te&gt;τ 门控切前向 KL | 都用熵当开关：EOPD 看**教师**熵决定 KL 方向，REOPOLD 看**学生**熵决定训哪些 token——互补可叠加 |
| **23** | **REOPOLD** | **OPD ≡ 策略优化：奖励裁剪 + 熵采样 + 两阶段（本作）** | **提供公共地基：log-ratio 即奖励，RL 工具箱可整体搬入 OPD** |

> **定位差异**：
> - **vs #19 GNDPO（最该合读）**：GNDPO 用 z-score 压「离群 token 梯度」，REOPOLD 用 logλ/(1−λ) 下限钉「重尾负奖励」——一个归一化、一个裁剪，都是「token 级信号尺度失控」的解药，理论上可同用（先裁剪再归一化）。
> - **vs #22 EOPD**：EOPD 的开关是教师熵（教师视角），REOPOLD 的是学生熵 + 奖励（学生视角）——两者叠加 = 「教师也不确定 × 学生也不确定」的联合门控，正是你 MCV-HPD 组件 B 的可选素材。
> - **vs #21 HPD**：HPD 的 K1 符号判断「强化/抑制」，REOPOLD 的裁剪判断「多狠地罚」——同一开关的两个旋钮。
> - **社区空缺**：论文引了 MiMo-V2-Flash「hard examples」与 DAPO 动态采样，但没有做 token 级 vs prompt 级采样粒度的消融——这是可直接补的对照实验。

## 七、启发与待跟进

> **核心启发**：
> 1. **「OPD = RL」是范式级洞察**：一旦接受 log-ratio 是 token 奖励，RL 的裁剪/采样/课程/advantage 归一化全部可迁移——OPD 从此有工具箱了，论文之间也有了共同语言。
> 2. **先查「奖励分布」再定「修复方案」**：画出 token 奖励直方图（长尾？近零堆？），再决定裁剪、归一化、采样还是门控——这是一个可脚本化的 OPD 体检流程。
> 3. **先探索后精修是通用配方**：前 1/3 只奖不罚保多样性、后 2/3 选择性纠错——与 O²-CritiCuRL 的课程思想同源，也和 SFT→RL 的工业界顺序一致。

### 待跟进 checklist

- [ ] **REOPOLD × GNDPO**：裁剪 + 全局归一化叠加，验证「不炸梯度 × 不飘奖励」双保险（MCV-HPD 组件 B 的候选方案之一）

## 八、今日阅读结论

REOPOLD 是「一次定性 + 三个轻修复」的高完成度工作：先用「OPD ≡ 策略优化」的等价性把 RL 工具箱合法引入蒸馏（stop-gradient = 控制变量），再对 token 奖励分布的三大病灶各开一剂药（重尾负奖励→混合裁剪、信号稀释→熵采样、熵塌缩→两阶段），最后用数学/视觉/Agentic 三域实验证明稳定与效率兼得——6.7\~12× 样本效率、7B 学生追平 32B 教师、\~3.32× 推理加速。它与 EOPD（教师熵门控）、HPD（偏差符号重加权）、GNDPO（梯度归一化）构成同一场「token 级监督精细化」的合流，而 REOPOLD 提供的理论视角（log-ratio 即奖励）正是其余三篇缺失的公共地基——把它和 EOPD 的学生熵门控叠加，就是你「监督信号精细化」主线上下一个值得跑的组合。

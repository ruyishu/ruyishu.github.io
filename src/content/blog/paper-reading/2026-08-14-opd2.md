## TL;DR

一句话：**把 OPD 的蒸馏信号从「师生概率差」换成「教师与其 base 模型的 delta」，就能剥离通用语言先验、只蒸馏后训练真正学到的推理能力——在英语、韩语、日语三种语言的数学推理上稳定超越原版 OPD，并且顺带缩小了英语-韩语性能差距；但只用英语数据做 OPD² 会让模型回答向英语漂移，多语言数据对保住目标语言输出至关重要。**

- **核心发现**：① OPD² 在多语言场景下全面优于 OPD，韩语提升 +3.1\~+3.3、日语 +3.1\~+4.0，英语提升反而较小（+0.7\~+2.1）；② 多语言 OPD² 缩小了英韩差距——在七个 benchmark 中有六个上差距减小；③ 英语-only 训练能让韩日 benchmark 分数和 multilingual 差不多，但目标语言回复率从 90%+ 暴跌到 30\~48%，说明推理能力和语言生成能力是可分离的两件事。
- **方法 OPD²**：核心改动只有一处——把 OPD token-level reward 中学生的 log 概率换成教师 base 模型的 log 概率差（详见 §2.1 公式）。简单但有效，配合 reward centering 和基于原 OPD 信号的 conditioning criterion 解决 delta 信号的收敛点问题。
- **炸裂结果**：Qwen3-1.7B 非思考模式，OPD² 把英语从 55.1→63.6、韩语从 40.9→51.9、日语从 37.2→52.0；思考模式下 1.7B 英语到 73.4、韩语到 68.2、日语到 71.2。

## 一、动机：OPD 在多语言场景下被忽略的盲区

### 1.1 OPD 作为 RL 后训练的替代方案

On-Policy Distillation（OPD）正在成为 LLM 后训练中 Reinforcement Learning 的有前景替代。RL 用单一整句评分做序列级监督，而 OPD 把学生的 rollout 喂给教师模型，获取 **token 级**的生成概率作为反馈，解决了 RL 后训练中序列级监督代表性不足的问题。给定问题 $x$，策略模型 $\pi_\theta$（学生）先从当前策略生成回复 $y$，然后送入教师模型 $\pi^*$ 获得 token 级概率。

**标准 OPD 目标函数：**

$$E_{y\sim\pi_\theta(\cdot|x)}[D_{KL}(\pi_\theta(y|x)\|\pi^*(y|x))]$$

等价地用 token-level reward 表达：

$$R_t = \log\pi^*(y_t|x,y_{<t}) - \log\pi_\theta(y_t|x,y_{<t})$$

策略更新：

$$E_{y\sim\pi_\theta(\cdot|x)}[\sum_{t=1}^T R_t \nabla_\theta\log\pi_\theta(y_t|x,y_{<t})]$$

OPD 给更被教师偏好的 token 赋正奖励、给教师概率更低的 token 赋负奖励，类似 on-policy RL 调整当前分布内的候选 token 相对概率。

### 1.2 三个未回答的问题

OPD 的现有研究几乎全部集中在英语推理 benchmark 上。三个核心问题被摆上台面：

1. **OPD² 在多语言场景下还能胜过原版 OPD 吗？** 尤其是非英语语言（韩语、日语），delta 信号是否仍然有效？
2. **OPD² 后训练能否缩小语言间的推理性能差距？** 还是只会让英语更强、其他语言更弱？
3. **只用英语数据做 OPD 对多语言推理和目标语言生成分别有什么影响？**

> 这篇和库里 #14 CAPS 有微妙的呼应：CAPS 问"历史接口从文本换成图像后丢了什么"，OPD² 问"蒸馏信号里到底蒸馏了什么"。两者都在逼问：你的蒸馏/对齐到底在迁移哪种能力？

## 二、OPD² 的核心改动：一个看似简单的换项

### 2.1 Delta Signal

OPD² 的核心创新只有一个替换：把 OPD reward 中**学生模型**的 log 概率，换成**教师 base 模型**的 log 概率：

`R_t^(OPD²) = log π*_teacher(y_t | x, y_<t) − log π*_base(y_t | x, y_<t)`

直觉上：LLM 先在大规模预训练数据上做 next-token prediction 得到 base 模型，再经 SFT + RL 后训练获得复杂推理能力。OPD² 把教师模型与其 base 之间的差异定义为 **delta signal**，旨在隔离后训练中真正学到的能力（尤其是推理），同时减少 base 模型中已存在的通用偏好和风格模式的影响。

对比两个 reward：

- **OPD**: 教师 vs 学生 → 告诉学生"你哪里和老师不一样"
- **OPD²**: 教师 vs 教师 base → 告诉学生"后训练真正学到了什么"

这个替换非常简洁，但效果显著。

### 2.2 收敛点问题与两个额外组件

Delta signal 存在一个收敛点（convergence-point）问题：如果只优化 delta，学生的分布最终会收敛到教师 base 模型的分布，而非教师模型本身的分布。OPD² 引入两个组件解决：

1. **Reward centering**：获得 advantage 形式的信号
2. **基于原始 OPD 信号的 conditioning criterion**：保证最终收敛到正确的教师分布

论文因篇幅限制省略了详细公式，指向 OPD² 原论文（arXiv:2607.15161）补充。

### 2.3 为什么 delta 信号有效？

论文给出的解释是：delta 信号剥离了 base 模型中已有的"通用语言先验"（包括语言风格、常见回答模式等），只留下后训练真正学到的推理能力。这使得蒸馏信号更纯净、更聚焦于推理能力的迁移，而非让模型简单地模仿教师的输出分布。

## 三、实验设置

**数据集**：构建包含 100K 问题的多语言数学训练集，英语/韩语/日语按 1:1:1 比例采样，无跨语言重叠。韩语和日语来自 Nemotron-SFT-Multilingual-v2，英语来自 Nemotron-Math-v2。额外构建一个 100K 英语-only 训练集做消融。OPD 不需要参考答案，只保留 question 字段。

**模型**：

- 学生模型：Qwen3-1.7B、Qwen3-8B
- 教师模型：Qwen3-30B-A3B-2507
- 训练：100 优化步，multilingual 和 English-only 使用相同超参和训练样本数

**评测**：PolyMath、Global-MGSM（英语/韩语/日语）；HRM8K（英语/韩语，含 GSM8K、MATH、Omni、KSM、M-MMLU 五个子集）；MAWPS（日语）。均报告 thinking 和 non-thinking 两种模式。

## 六、Limitations & 批判性思考

1. **论文非常短（9页），方法细节被压缩。** OPD² 的 reward centering 和 conditioning criterion 的具体公式被省略，指向原论文。这使得本工作的方法论贡献更像是一个"应用研究"而非"方法创新"——它验证了 delta 信号在多语言场景下的有效性，但没有引入新的技术机制。
2. **只在 Qwen3 系列上验证。** 1.7B、8B 学生 + 30B-A3B-2507 教师，没有在其他模型家族（LLaMA、Gemma、Mistral）上复现。delta 信号是否对所有架构通用？未知。
3. **只在数学推理上测试。** 虽然 OPD² 原论文在代码、科学推理上也验证了，但多语言版本只测了数学。多语言代码、多语言科学推理是否同样受益？
4. **语言漂移的度量粗糙。** "目标语言回复率"是一个二分类指标（是/否匹配问题语言），没有衡量回复中的语言混合程度。对于多语代码混用的场景（比如韩语提问但公式/变量名是英文），这个指标可能过于严格。
5. **没有探索混合比例。** 数据配比是 1:1:1 固定比例，没有尝试不同的语言配比。如果韩语/日语数据更稀缺，多少比例的多语言数据才能保住语言生成？
6. **思考模式的提升幅度远小于非思考模式。** 1.7B 英语思考模式仅 +3.0（70.4→73.4），而非思考模式 +18.1（47.6→65.7）。这说明 OPD² 主要帮助的是"不思考"模式下的直接推理能力，对于已经有强 CoT 能力的 thinking 模型，边际收益有限。

> **定位差异**这篇在 OPD 谱系中占据了一个独特位置：前 14 篇都在问"蒸馏信号从哪来"或"OPD 放在后训练流程哪一段"，而这篇问的是**蒸馏信号在多语言场景下是否仍然有效，以及多语言数据对语言生成保持的必要性**。它和几条已读线索的咬合点：
> - **Distilled RL (#9)**：都在精细化蒸馏信号——Distilled RL 按 token 置信度过滤，OPD² 按 delta 空间过滤。一个从学生侧裁剪（不信任低置信 token），一个从教师侧裁剪（减掉 base 已有部分）。两种过滤思路能否合并？
> - **PRISM (#13)**：PRISM 把 OPD 插在 SFT 和 RLVR 之间做预对齐；OPD² 的 delta 信号同样适合做 SFT 后的第一步——两者在 pipeline 位置上天然兼容。
> - **CAPS (#14)**：CAPS 的自蒸馏特权是"同一历史的文本接口"，OPD² 的 delta 特权是"同一教师的前后版本"。两者都是"同一模型、不同状态"的对比蒸馏，但 CAPS 跨模态、OPD² 跨训练阶段。

## 八、启发与待跟进

### 8.1 核心启发

> **启发 1：蒸馏信号的"减法"思路值得深挖。** OPD² 证明了一个反直觉的事实——不是让蒸馏信号更强，而是让它更"纯净"（去掉 base 已有的部分），效果更好。这和 Distilled RL 的选择性蒸馏（砍掉低置信 token）异曲同工：核心都是"少蒸一些，但蒸对的"。**启发 2：多语言数据的第一优先级是语言生成，不是推理能力。** 英语-only 就能迁移推理，但多语言数据是保住目标语言回复率的唯一手段。如果你只有有限的多语言预算，应该优先确保语言覆盖而非数据量。**启发 3：强模型上的原版 OPD 可能有害。** 8B 思考模式下 OPD 反而降分，但 OPD² 稳定。对于已经在思考模式上很强的模型，delta 信号比原始 OPD 更可靠——这可能是因为强模型的输出分布已经接近教师，原始 OPD 的"教师-学生"差值太小、信噪比差，而 delta 信号仍然有足够梯度。**启发 4：这篇的实验设计本身就是一个好模板。** 三个问题、三种语言、两种模式、两个模型规模、多语言 vs 英语-only 消融——用最小的实验矩阵覆盖了最大的信息量。对后续做多语言 OPD 研究有直接参考价值。

### 8.2 待跟进

- [ ] **Distilled RL × OPD²**：把 token 置信度过滤和 delta 信号合并，看能否进一步提升——先过滤掉 base 不确定的 token，再对剩余 token 用 delta reward。

- [ ] **OPD² 在非数学多语言任务上的验证**：代码生成（多语言编程）、科学推理（多语言问答）是否同样受益？

- [ ] **语言配比消融**：1:1:1 之外的比例（比如 5:1:1 英语主导）能否在推理和语言生成之间找到更好的 Pareto 前沿？

- [ ] **OPD² + PRISM pipeline**：把 OPD² 的 delta 蒸馏放在 SFT 后、RLVR 前，作为预对齐步骤，看是否和 PRISM 的黑盒预对齐互补。

- [ ] **思考模式提升有限的原因**：OPD² 在 thinking 模式上增益远小于 non-thinking，是因为思考模式的推理链已经很强，还是因为 thinking 模式的 CoT 主要用英语（不受多语言蒸馏影响）？

- [ ] **delta 信号在其他模型家族上的泛化**：LLaMA-3、Gemma-2、Mistral 上是否同样有效？尤其是 base 模型多语言能力差异大的情况下。

## 九、今日阅读结论

OPD² 的 multilingual 验证是一篇干净利落的"负空间"论文——它不发明新方法，而是在一个被忽略的维度（多语言）上验证了一个已有方法（delta 蒸馏），并意外地揭示了一个重要的经验事实：**推理能力的跨语言迁移和语言生成的保持是两个正交的目标，前者可以通过单语蒸馏实现，后者必须依赖多语言数据。**方法的简洁性（只换一个项）和效果的稳健性（在所有语言和模型规模上一致有效）形成对比。特别值得关注的是 8B 思考模式下原版 OPD 的降分——这暗示当学生模型足够强时，原始 OPD 的教师-学生差距信号可能引入噪声，而 delta 信号因为剥离了 base 先验，反而更稳定。放到 15 篇的脉络里，这篇补上了 OPD 研究线中缺失的多语言一环，同时为后续的数据配比实验（多少多语言数据才够？）和蒸馏信号精细化（delta + 选择性过滤能否叠加？）提供了明确的方向。

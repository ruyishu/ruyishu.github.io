## TL;DR

*一句话：MLLM 看不清小目标，很多时候不是"眼睛"坏了，而是它不知道往哪儿看——ACTIVE-o3 用 GRPO 纯强化学习训练模型"主动放大"，学会自己选区域 zoom-in，小目标检测/分割全面碾压基线，还能零样本迁移到 V 细粒度问答。*\*

- **核心问题**：主动感知（active perception）= 主动选择"往哪儿看"。GPT-o3 的 zoom-in 搜索是特例但低效（近似网格搜索、区域选不准）；现有 MLLM 完全没有学习如何选择观察区域
- **方法 ACTIVE-o3**：共享一个 Qwen2.5-VL-7B，双 prompt 拆成"感知模型（选 3 个 zoom 区域）+ 任务模型（在裁剪图上做任务）"；**双形式奖励** = 启发式（格式/不重叠/面积范围/覆盖率，无需标注）+ 任务感知（AP/AR 或 mIoU，需前向）；GRPO 训练（N=8，KL β=0.04）
- **结果**：SODA-A 航拍小目标 APs **9.2（基线 0.7，+8.5）**、SODA-D 驾驶场景 APs 15.1（+13.0）/ARs 22.0（+17.5）；交互式分割 3 步 zoom 后 mIoU **0.863**（基线越 zoom 越差掉到 0.561）；V\* 零样本：警车号码"102"、红绿灯"10"、背景里的红色面包车
- **主题轮换**：今天从 OPD 切到多模态 RL（昨日 REOPOLD 为 OPD 主题）

## 一、先看一个例子

> **问题**：一张莫斯科红场照片，前景有辆警车，问"警车上的号码是多少？"——原始分辨率下号码根本看不清。**Qwen2.5-VL**：直接放弃，"照片角度和距离导致车牌细节无法辨认"。**ACTIVE-o3**：先想"警车在图像中间偏前的位置，号码一般在车身侧面"，然后**主动放大警车区域**，放大图上车身侧面写着清晰的 **102** → 答对。整个过程中模型没有被教过"要放大"——它是纯 RL 学出来的：放大对 → 拿到高分；不放大 → 答错拿低分。

![](/images/paper-reading/2026-08-27-active-o3/2026-08-27-d25-1.png)

> **直觉**：人类看小目标也不是"眼睛分辨率高"，而是**知道该凑近看哪里**。ACTIVE-o3 就是给 MLLM 装了个"会自己决定往哪儿看的放大镜"。

## 二、动机：MLLM 的感知瓶颈在"看哪里"，不在"怎么看"

### 2.1 主动感知的系统化定义

- 智能体状态 s_t = (环境 s_env + 传感器位姿 s_cam)，动作 a_t = (环境动作 a_env + **感知动作 a_cam**)
- 目标：max E[Σ 任务奖励 − λ·感知成本]——感知不是免费的（放大要花计算/时间预算）
- 二维静态图特例（T=1）：感知动作 = 选一个 bbox 区域，观察 = ResizeCrop；在固定预算 K 下选 K 个区域最大化任务表现

### 2.2 两个观察

- **GPT-o3 的 zoom-in 是主动感知的特例**，但搜索低效：区域选不准（放大到无关区域）、近似网格穷举，还只能串行搜索
- **现有 MLLM 没有"选择看哪里"的能力**：给一张高分辨率图，模型直接全图推理——小目标（<100px 面积）在降采样后信息全丢

> **炸裂点**：不修内部注意力、不换更大模型——**在"行动层"给模型加一个感知动作**（放大哪里），用纯 RL 学出来，小目标检测能从近乎 0 提升 8\~17 个点。

## 三、方法：模块化 sensing-action + GRPO + 双形式奖励

统一目标（Eq. 2，标准 GRPO）：组内 advantage 归一化 + importance ratio 裁剪 + KL 正则（β=0.04）。

![](/images/paper-reading/2026-08-27-active-o3/2026-08-27-d25-2.png)

### 3.1 模块化设计：一个模型、两个角色

共享 MLLM π(y|o, ℐ)，通过两个 prompt 切换角色：

- **感知模型 ℳ_O**（sensing prompt）：输入低分辨率全局缩略图 → 输出最多 3 个候选区域 `{"bbox_2d": [x1,y1,x2,y2], "label": "coin-dense region"}`（JSON 格式，`<think>` 推理）
- **任务模型 ℳ_A**（task prompt）：输入每个裁剪图 → 输出任务答案（检测框/分割点/回答）

关键：**区域选择没有任何人工标注监督**——全靠奖励信号驱动模型自己学会"哪里信息密度高"。

### 3.2 双形式奖励

**启发式奖励**（任务无关、无需标注、全 λ=1）：

1. **R_format**：输出是合法 JSON + 含 bbox_2d 和 think/answer 标签
2. **R_no-overlap**：任意两区域 IoU ≤ 0.3（防重复放大同一处）
3. **R_area**：每块面积占图比 ∈ [0.01, 0.5]（既不能太小也不能整图）
4. **R_coverage**：三种模式——mask 覆盖率 / GT 框匹配率（IoU≥δ）/ mask 对齐

**任务感知奖励**（需额外前向 ℳ_A）：

- 检测：`R_detect = AP@IoU0.5 + AR@IoU0.5`
- 交互分割：`R_seg = mIoU(预测 mask, GT mask)`

> **三个观察**：① 消融证明**双形式 > 单形式**（LVIS APs：启发式 3.0 / 任务 3.6 / 组合 4.4）——启发式给探索先验、任务式给精确信号；② 训练数据混合 LVIS+SODA-A+D 最优，能学到**跨域统一感知策略**；③ 每实验 <24h、8 卡即可——纯 RL 在感知动作上的训练成本比想象的低。

### 3.3 训练设置

- Qwen2.5-VL-7B-Instruct 共享策略；GRPO 组 N=8、KL β=0.04、lr 1e-6、wd 0.01
- 感知输入短边 1024px（保宽高比）、任务输入固定 840×840
- 8×80-90GB GPU、DeepSpeed ZeRO-3、bf16，**每个实验 <24 小时**

## 四、实验

### 4.1 主结果

**LVIS 小目标/密集场景（Table 1）：**

| 方法 | small APs | small ARs | dense APs | dense ARs | APl | ARl |
|-|-|-|-|-|-|-|
| Qwen2.5-VL | 1.2 | 1.8 | 1.6 | 2.0 | 15.0 | 18.7 |
| Qwen2.5-VL-CoT | 1.2 | 2.2 | 2.5 | 3.5 | 20.3 | 25.8 |
| **ACTIVE-o3** | **2.2 (+1.0)** | **4.6 (+2.8)** | **4.3 (+2.7)** | **5.5 (+3.5)** | 20.9 | **33.3 (+14.6)** |

**SODA-A（航拍）/ SODA-D（驾驶）小目标检测（Table 2）：**

| 方法 | A-APs | A-ARs | D-APs | D-ARs |
|-|-|-|-|-|
| Qwen2.5-VL | 0.7 | 1.5 | 2.1 | 4.5 |
| Qwen2.5-VL-CoT | 3.2 | 5.2 | 7.8 | 15.2 |
| **ACTIVE-o3** | **9.2 (+8.5)** | **10.4 (+8.9)** | **15.1 (+13.0)** | **22.0 (+17.5)** |

- **交互式分割（ThinObjects）**：3 步 zoom 预算下 ACTIVE-o3 mIoU 从基线一路**单调升到 0.863**；Qwen2.5-VL-CoT 反而**越 zoom 越差**（0.561，放大错区域误差累积）
- **与 GDINO 组合即插即用**：ACTIVE-o3 的感知策略 + GDINO 检测器，dense APs 5.7→**7.0**——感知策略可以当"插件"喂给专用检测器

![](/images/paper-reading/2026-08-27-active-o3/2026-08-27-d25-3.png)

### 4.2 V\* 零样本迁移（未训练过的细粒度 VQA）

- 警车号码：基线"看不清"→ ACTIVE-o3 zoom 后读出 **102**
- 红绿灯数字：基线答非所问 → zoom 后答 **10**
- 背景小面包车颜色：基线"图中没有车"→ zoom 后答 **红色**
- 含义：感知策略是**任务无关的可迁移能力**，在纯检测数据上训练、直接泛化到细粒度问答

### 4.3 消融

- **数据组合**：SODA-A only 3.7 APs → +LVIS 6.4 → +SODA-D 全量 9.2/10.4——跨域混合让感知策略泛化
- **奖励消融**：启发式 only 3.0 / 任务 only 3.6 / **双形式 4.4**（LVIS APs）——先验与信号缺一不可
- **GPT-o3 对照**（Figure 6）：问"红牌子上画了什么动物"（答案 tiger），GPT-o3 放大到金属结构、背景纹理等无关区域，退化成网格穷举；ACTIVE-o3 靠空间布局推理一次选中关键区域，且支持并行多区域

![](/images/paper-reading/2026-08-27-active-o3/2026-08-27-d25-4.png)

## 五、Limitations & 批判性思考

1. **域间隙拖累任务奖励**：遥感等专业域里 MLLM 认不出类别（风车、储油罐），任务感知奖励被任务模型能力上限污染——奖励依赖的 ℳ_A 不够强时信号有噪声
2. **动作空间受限**：每步最多 3 个区域，且不支持旋转等变换（OCR 场景受限）
3. **无记忆机制**：感知模型只看当前观察，看不到自己之前的 zoom 轨迹——无法做轨迹级规划、长程搜索、回退操作（论文明确留白）
4. **失败模式**：密集 LVIS 物体分割不准、航拍小目标域间隙（框对但认错类）
5. **评估偏检测/分割域**：V\* 是零样本展示，没有在通用 VQA 榜上全面验证"主动感知是否总帮忙"（放大也可能有害——细看噪音区域）

## 七、启发与待跟进

> **核心启发**：
> 1. **"看哪里"是可学习的**：感知决策不需要人工标注——GRPO + 双形式奖励（启发式先验 + 任务信号）就能无监督学出 zoom 策略，这是"感知动作"作为 RL 动作空间的首批成功案例。
> 2. **启发式奖励是 RL 冷启动的加速器**：纯任务奖励（3.6）与纯启发式（3.0）都不如组合（4.4）——先给"像样"的先验再精修，是动作空间大时的通用配方。
> 3. **感知策略是插件**：训练好的 sensing 策略能接在 GDINO 上直接提点、能零样本迁移到 VQA——"感知能力"从任务中解耦出来了。

### 待跟进 checklist

- [ ] **ACTIVE-o3 × PAPO**：主动感知 + 内部感知正则化叠加——"会看 + 用得上"双保险（与你 MCV-HPD 视觉分支的感知修复联动）

- [ ] **主动感知蒸馏给学生（OPD 视角）**：教师（32B）的 sensing 策略通过 OPD 蒸馏给 3B/7B 学生，替代学生自己学 zoom——教师已经会看，学生直接学

- [ ] **记忆机制**：论文明确留白——多步 zoom 轨迹级规划、回退操作（把 sensing 做成序列决策而非单步）

- [ ] **动作空间扩展**：>3 区域、旋转、OCR 友好

- [ ] **通用 VQA 上测"主动感知是否总帮忙"**：放大也可能有害（噪音区域），需要成本-收益分析

- [ ] **奖励鲁棒性**：任务模型 ℳ_A 不够强时（遥感域间隙），任务奖励带噪——用奖励归一化/裁剪（GNDPO 那套）做组合

## 八、今日阅读结论

ACTIVE-o3 是"一个视角转换 + 一套干净工程"的多模态 RL 佳作：把 MLLM 的感知瓶颈从"内部注意力"重新定位到"主动选择看哪里"，用模块化 sensing-action 设计 + GRPO + 双形式奖励在**无区域标注**的情况下学出 zoom 策略——小目标检测从近乎 0 涨 8\~17 个点，交互式分割越 zoom 越好（0.863 vs 基线退化到 0.561），还能零样本泛化到细粒度 VQA。它和 PAPO（内部注意力修复）构成同一病症的"内外两解"，和你 OPD 主线的关系是：**"教师会看"这个能力本身也可以成为蒸馏的对象**——把 32B 教师的 sensing 策略 OPD 给 7B 学生，是直接把今天这篇接回你研究主线的最短路径。

> 2026-09-21 · 文献阅读 #41 · 方向：具身智能（VLA / 具身大脑） · 用"动作对齐视觉奖励"把推理训出来 · NeurIPS 2025

## TL;DR

<strong>一句话：VLA 模型的通病是"看到就动手"——图进去、动作出来，中间没有"想"这一步，所以长程任务一塌糊涂。已有的"先想后做"方案要么靠大量推理标注（ECoT/RAD 用现成 MLLM 生成中间步骤），要么拿仿真器的任务成功率当奖励（于是被绑死在那个仿真器上）。ThinkAct 的关键一招是：不给推理做标注，而是给推理造一个"动作对齐的视觉奖励"——让 MLLM 在图上画一条夹爪轨迹（一串 2D 关键点），然后用 ① 目标奖励（起/终点与检测器给的真值轨迹对齐）② 轨迹奖励（DTW 距离）来打分，再用 GRPO 优化。训完之后，把推理过程压成一个视觉计划 latent（Q-Former 32 个 query），冻结 MLLM，只训下游的 DiT 动作模型（432M）——慢思考 + 快控制的异步双系统。</strong>

- <strong>结果（操作）</strong>：SimplerEnv 三个 setup 上比自家的 DiT 基线 <strong>+15.5 / +16.9 / +11.4</strong>（71.5 / 65.1 / 43.8，<strong>全场最高</strong>）、LIBERO 平均 <strong>84.4</strong>（超 CoT-VLA 83.9）
- <strong>结果（具身推理）</strong>：EgoPlan-Bench2 <strong>48.2</strong>（vs 同骨干微调的 Qwen2.5-VL\* 45.7，<strong>+2.5</strong>）、RoboVQA <strong>59.8</strong> BLEU（<strong>+4.1</strong>）、OpenEQA <strong>56.2</strong>
- <strong>附带能力</strong>：<strong>10 样本适配</strong>（超 Magma <strong>+9.5</strong> Spatial / <strong>+7.3</strong> Goal）、<strong>自纠错</strong>（物体掉了会识别失败并重新规划重抓）
- <strong>最关键的消融</strong>：两个奖励都必要——单独去掉 r\_traj 或 r\_goal 都掉分，<strong>两个都去掉只剩 QA 奖励时几乎退回 SFT 水平</strong>（56.9 vs SFT 冷启动 56.4）→ <strong>"动作对齐的视觉反馈"才是有效成分</strong>
- <strong>算力</strong>：<strong>16×A100 80GB</strong>；<strong>全部定量操作实验都在仿真里</strong>（SimplerEnv + LIBERO），无真机对比
- <strong>主题轮换</strong>：今日<strong>具身智能</strong>（按序列从世界模型（9/18 MindJourney）切出；上次具身是 9/11 InstructVLA）

## 一、先看例子（大白话：从"看到就动手"改成"先画路线再动手"）

> 💡 <strong>铺垫</strong>：传统 VLA 是<strong>端到端</strong>的——图进来，Δx / Δθ / ΔGrip 出去，<strong>中间没有"想"这一步</strong>。
>
> 于是它只会<strong>短程技能</strong>（抓个杯子），一遇到"把书从左边搬到右边背部的隔层"这种<strong>长程任务</strong>就散架。
>
> <strong>ThinkAct 的改法：让模型先"想"，而且想的产物是一条能打分的"路线"。</strong>

> <strong>任务</strong>：「把草莓放进抽屉」
>
> <strong>传统 VLA</strong>：图 + 指令 → 直接输出动作序列
>
> <strong>ThinkAct</strong>：
>
> 1\. <strong>MLLM 先写推理</strong>：&lt;think&gt;先定位草莓 → 抓起来 → 移到抽屉 → 放进去&lt;/think&gt;
>
> 2\. <strong>同时在图上画一条黄色点串</strong>（夹爪轨迹）：起点在夹爪位置，终点指向抽屉口
>
> 3\. <strong>这条轨迹就是要打分的"计划"</strong>——起点/终点对不对给"目标奖励"，整条路线像不像真人的抓取轨迹给"轨迹奖励"
>
> 4\. 训完之后，这条推理被压成一个 <strong>latent</strong>，交给下游动作模型去真正动手 → <strong>慢思考（MLLM）+ 快控制（动作模型）异步运行</strong>

<strong>为什么"用轨迹当奖励"这一招聪明？</strong>

<strong>轨迹同时是"可视化的"和"可计算的"</strong>——它不需要任何推理标注，也不需要仿真器给分，只要一个现成的夹爪检测器，就能算出"你画的路线对不对"。

![▲ 论文 Figure 1：ThinkAct 的三种涌现能力——Few-Shot 适配（10 样本超 OpenVLA 25.1%）、长程规划（把任务拆成子目标）、自纠错（物体掉了，反射→重规划→再执行）](/images/paper-reading/2026-09-21-thinkact/2026-09-21-d42-1.webp)

## 二、动机：具身推理缺的不是算力，是"可跨环境的稠密奖励"

- <strong>端到端 VLA 的两个天花板</strong>：短程技能尚可，<strong>长程规划</strong>和<strong>动态环境适应</strong>不足
- <strong>已有的"显式 CoT"路线，两条都有硬伤</strong>： 
  - <strong>监督式</strong>（ECoT、RAD）：用现成 MLLM 生产中间步骤当标注 → <strong>需要大量推理标注</strong>，且<strong>被训练数据覆盖范围卡住</strong>
  - <strong>用目标环境的任务成功率当奖励</strong>：<strong>被绑死在特定仿真器上，而且没有视觉场景层面的引导</strong>（论文原话：restricted to specific simulators without proper guidance from visual scenes）
- <strong>所以缺的是</strong>：一种<strong>跨环境可计算、且带视觉/空间引导的稠密奖励</strong>，用来激励具身推理能力

> 🎁 <strong>这篇最值钱的一招（可迁移）</strong>：<strong>当某个能力没有标注、又拿不到环境奖励时——把它转成一个"几何上可计算的中间表示"，就能当奖励。</strong>
>
> ThinkAct 找的中间表示是<strong>图上的 2D 轨迹</strong>：既逼模型做视觉 grounding（必须看准物体在哪），又能用<strong>起点/终点距离 + DTW</strong> 算出分数。<strong>完全不需要人标注"推理步骤对不对"。</strong>

## 三、方法

### 3.1 三个组件

![▲ 论文 Figure 2：ThinkAct 总览。(a) 推理 MLLM 生成 <think> 推理与视觉计划 τ=［p0…pK］，并由动作对齐视觉奖励 + GRPO 优化；(b) 冻结 MLLM，视觉计划 latent c_t 经 Latent Projector 送入 DiT 动作模型，F_θ 每 N 步推理一次、π_φ 每步都出动作](/images/paper-reading/2026-09-21-thinkact/2026-09-21-d42-2.webp)

- <strong>(a) 推理 MLLM F\_θ</strong>（Qwen2.5-VL 7B）：给定观察 o\_t 与指令 l，自回归生成两类 latent—— 
  - <strong>推理嵌入 v\_t</strong> → 解码成文字推理步骤（&lt;think&gt;...&lt;/think&gt;）
  - <strong>视觉计划 c\_t</strong> → 解码成<strong>一串 2D 点</strong> τ = \[p\_k\]，p\_k∈\[0,1\]²，<strong>p\_1 和 p\_K 分别是夹爪的起点和终点</strong>
- <strong>(b) 动作对齐视觉奖励</strong>（核心）： 
  - <strong>目标奖励</strong>（鼓励预判目标完成）：r\_goal = ½·\[ f(p\_1, p̂\_1) + f(p\_K, p̂\_K) \]，其中 f(p,p') = max(0, 1 − ‖p−p'‖²₂)；p̂ 是<strong>现成检测器</strong>（LLARVA, Niu et al. 2024）从真值视频里抽出的夹爪轨迹
  - <strong>轨迹奖励</strong>（约束物理合理的夹爪运动）：r\_traj = max(0, 1 − d(τ, τ̂))，d = <strong>DTW（动态时间规整）距离</strong>
  - <strong>合成</strong>：r = 0.9·r\_visual + 0.1·r\_format，其中 r\_visual = 0.5·r\_goal + 0.5·r\_traj
  - <strong>可扩展</strong>：还能把公开 QA 数据（RoboVQA、失败检测 Reflect）格式化成<strong>问答式准确率奖励</strong>一起训
- <strong>(c) 动作模型 π\_φ</strong>：DiT（Diffusion Policy）<strong>432M</strong>，OXE 预训练；state encoder = DINOv2（图）+ CLIP（文）→ 1024 维；<strong>c\_t 经 Q-Former（32 queries）投影进动作模型的输入空间</strong> 
  - <strong>行为克隆目标</strong>：L\_IL(φ) = E\[ℓ(π\_φ(c\_t, o\_i, l), a\_i)\]
  - <strong>冻结 F\_θ</strong>，只更新 state encoder + latent projector + 动作模型
  - <strong>异步</strong>：一个 c\_t 覆盖 <strong>N 次环境交互</strong>（i ∈ \[t, t+N\]）→ <strong>慢思考 + 快控制</strong>

### 3.2 训练策略（三阶段）

| 阶段 | 做什么 | 关键配置 |
|-|-|-|
| <strong>0 · 冷启动 SFT</strong> | 教 MLLM 读视觉轨迹、按格式输出推理与答案 | 20K iters，bs 32，lr 1e-5，ZeRO-3 |
| <strong>1 · GRPO 强化</strong> | 用动作对齐视觉奖励优化 MLLM | <strong>6K iters，bs 64，lr 1e-6，rollout size 5</strong> |
| <strong>2 · 动作适配</strong> | 冻结 MLLM，把 c\_t 接到动作模型 | 100K OXE 样本，120K iters，bs 256，lr 2e-5；LIBERO 再 75K iters，bs 128 |

- GRPO 目标就是标准式：组内相对优势 A\_i = (r\_i − mean) / std + KL 约束（β）防跑偏
- 推理时：c\_t = F\_θ(o\_t, l) 一次生成，然后动作模型照着它连续出动作

<strong>论文解读</strong>：

- 去掉 r\_traj → <strong>掉得最明显</strong>，说明它对"学到连贯、有结构规划"是关键
- 去掉 r\_goal → 也掉，说明它对"激励长程推理"有作用
- <strong>两个都去掉（只剩 QA 式奖励）→ 几乎退回 SFT 水平</strong>（56.9 vs 56.4）
- <strong>SFT 冷启动最低</strong> → <strong>RL 微调确实是有效成分</strong>

> <strong>一句话</strong>：<strong>QA 式奖励不足以支撑具身规划，必须靠"动作对齐的视觉反馈"。</strong>

## 五、Limitations &amp; 批判性思考

<strong>论文自述（只有 1 条）</strong>：

1. <strong>继承 MLLM 的幻觉</strong>——尤其在<strong>视觉/空间推理</strong>上，会生成引用错误物体属性或空间关系的计划，影响下游执行。虽然 latent planning + 动作接地能缓解一部分，但作者把"grounding-aware 训练 / 幻觉抑制"列为未来工作

<strong>我的阅读（8 条）</strong>：

1. <strong>最重要的一条：没有真机定量实验。</strong> 所有操作结果都是 <strong>SimplerEnv + LIBERO 仿真</strong>。论文里出现的 "real-world" 全是在描述基准数据集（RoboVQA/OpenEQA）的来源，<strong>不是自己的真机实验</strong>。对比 lib #29 HiF-VLA（有真机 cover&amp;stack），这篇的"落地"证据更弱
2. <strong>动作模型必须在目标环境微调</strong>：LIBERO 要额外 <strong>75K iters</strong>。所以<strong>它不是零样本通用策略</strong>——"推理有用"这个结论是在目标环境适配<strong>之后</strong>测出来的
3. <strong>视觉奖励依赖外部检测器</strong>（<strong>LLARVA</strong> 抓夹爪、Something-Something 用 Shan 手部检测 + RDP 关键点简化）→ <strong>不是完全无标注</strong>，奖励上限被检测器质量卡住；论文未报告检测器误差对奖励的影响
4. <strong>奖励只测几何对齐</strong>（起点/终点欧氏距离 + DTW）→ 一条"看着合理"的轨迹完全可能不对应真实推理（<strong>reward hacking 无分析</strong>）。DTW 对速度/停顿不敏感，也可能被"平滑的万能轨迹"钻空子
5. <strong>单次运行，无方差/多种子</strong>（表格都是单点值）
6. <strong>对照的公平性</strong>：对 OpenVLA / TraceVLA / CoT-VLA / Magma 的对比<strong>跨骨干、跨训练数据</strong>，不干净；真正干净的只有 vs DiT-Policy（值得肯定）和 vs Qwen2.5-VL\*（推理侧）
7. <strong>算力门槛高</strong>：16×A100 80GB，且要三阶段串行（SFT→RL→动作适配），复现成本不低
8. <strong>RL 只有 6K 迭代、rollout size 5</strong> → RL 的探索程度很浅；"推理能力被 RL 激励出来"这个说法，靠的是相对 SFT 冷启动的小幅提升

## 七、启发与待跟进

> 💡 <strong>核心启发</strong>：
>
> 1\. <strong>"没有标注"不等于"不能训"——把能力转成"几何上可计算的中间表示"，它就能当奖励。</strong> ThinkAct 找的是 2D 轨迹（可画、可算 DTW）；这个思路可以类比到任何"计划类"能力上
>
> 2\. <strong>奖励的可迁移性 &gt; 奖励的精确性</strong>：用仿真器成功率当奖励更"准"，但<strong>换不了环境</strong>；用几何轨迹当奖励略粗，但<strong>跨环境、跨本体都能算</strong>——这是它能泛化到 LIBERO/SimplerEnv/Bridge 三个不同环境的原因
>
> 3\. <strong>"慢思考 + 快控制"的异步设计</strong>是双系统能实用的关键：一个 latent plan 覆盖 N 步，推理频率可以远低于控制频率
>
> 4\. <strong>消融给出了一个清晰的结论</strong>：<strong>QA 式奖励不足以支撑具身规划</strong>（去掉两个视觉奖励就退回 SFT）——这对所有"用 VQA 数据顺带训 VLA"的做法是个警告

<strong>待跟进 checklist</strong>

- [ ] <strong>最有价值的一组：把"轨迹奖励"换成 OPD</strong>（接 lib 主线）——ThinkAct 用 DTW 当稠密奖励；OPD 用教师分布当稠密监督。<strong>两者能不能叠加</strong>（教师给 token 级信号 + 轨迹给计划级信号）？

- [ ] <strong>奖励鲁棒性</strong>：检测器质量 → 奖励噪声 → 训练稳定性，这条链论文没量化；DTW 对速度/停顿不敏感是否会被"平滑轨迹"钻空子

## 八、今日阅读结论

ThinkAct（NeurIPS 2025，NVIDIA + 台湾大学）解决的是 VLA 一个很实在的问题：<strong>端到端"看到就动手"的模型没有"想"这一步，长程任务必然散架；而现有的"先想后做"方案要么靠大量推理标注，要么拿仿真器成功率当奖励（于是被绑死在那个仿真器上）</strong>。它的破题方式是<strong>不给推理做标注，而是给推理造一个可算的奖励</strong>——让 MLLM 在图上画一条 2D 夹爪轨迹（一串关键点），用 <strong>① 起点/终点与检测器真值的对齐（目标奖励）② 整条轨迹的 DTW 距离（轨迹奖励）</strong> 来打分，再用 <strong>GRPO</strong> 优化；训完后把推理压成<strong>视觉计划 latent</strong>（Q-Former 32 queries），<strong>冻结 MLLM</strong>，只训下游 <strong>DiT 动作模型（432M）</strong>，形成<strong>慢思考 + 快控制</strong>的异步双系统。结果：SimplerEnv 三个 setup <strong>比自家 DiT 基线 +15.5/+16.9/+11.4</strong>（71.5/65.1/43.8 全场最高）、<strong>LIBERO 84.4</strong> 最佳；具身推理 <strong>EgoPlan-Bench2 48.2（+2.5）、RoboVQA 59.8 BLEU（+4.1）</strong>；并涌现出 <strong>10 样本适配</strong>（超 Magma +9.5/+7.3）与<strong>自纠错</strong>（物体掉了会重新规划重抓）。<strong>最有价值的消融</strong>：两个视觉奖励都必要，<strong>都去掉只剩 QA 奖励就几乎退回 SFT</strong>（56.9 vs 56.4）——<strong>"动作对齐的视觉反馈"才是有效成分</strong>。<strong>要打的两个折扣</strong>：① <strong>全部操作结果都在仿真里，没有真机定量实验</strong> ② <strong>动作模型必须在目标环境微调（LIBERO 再 75K iters）</strong>，所以它不是零样本通用策略。<strong>对你 lib 的价值</strong>：它给"给没有标注的能力造监督"这条主线<strong>补上了第四条路线——造奖励</strong>（前三条：BSBT 造诊断 / MIRL·CFPO 造信号 / ViCrit 造任务），而且它的"把计划转成几何可算量再当奖励"是一个非常可迁移的招式。

> 🔗 <strong>今日一句</strong>：VLA 模型"看到就动手"，长程任务必然散架；想让它"先想后做"，可"想得对不对"根本没有标注、也没法用仿真器打分。<strong>ThinkAct 的招是把"想"画出来——让 MLLM 在图上画一条夹爪轨迹</strong>，起点/终点对不对算一个奖励、整条路线像不像真人算另一个（DTW），<strong>用 GRPO 训</strong>；训完把推理压成一个 latent 交给动作模型执行，<strong>慢思考 + 快控制</strong>。结果 SimplerEnv 三项全场最高（<strong>+15.5/+16.9/+11.4</strong>）、LIBERO <strong>84.4</strong>，还能 <strong>10 样本适配</strong>（超 Magma +9.5）和<strong>掉了东西自己重新规划</strong>。而消融说了实话：<strong>把两个视觉奖励拿掉、只剩问答奖励，就退回到 SFT 水平</strong>——<strong>"动作对齐的视觉反馈"才是真正在起作用的东西</strong>。论文：arXiv:2507.16815（<strong>NeurIPS 2025 Poster</strong>）· 项目页 jasper0314-huang.github.io/thinkact-vla · 笔记挂在 lib 中 · 2026-09-21

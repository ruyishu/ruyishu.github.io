## TL;DR

**一句话：RLVR（GRPO/PPO 那套）被普遍认为能让 LLM "自我进化"出新推理能力——这篇给 RLVR 做了一次"能力边界体检"，结论扎心：RLVR 只是把采样往正确路径上"挤"（pass@1 涨），却几乎没有产生任何根本性的新推理模式——大 k 采样时 base 模型的 pass@k 反超 RL 模型，训练越久推理能力边界反而越窄；而蒸馏（把教师长 CoT 蒸给学生）却能真正引入新模式、撑开能力边界。**

- **核心发现（五条）**：① 小 k（k=1）RL 赢、**大 k base 反超**（pass@k 曲线交叉）；② 训练推进时 pass@1 涨但 **coverage（pass@256）降**——能力边界收窄；③ coverage/perplexity 分析：RL 模型生成的推理路径**已包含在 base 的采样分布里**——能力源于 base、受 base 封顶；④ 6 种流行 RLVR 算法表现相似且**远未充分利用 base 潜力**（∆SE 都很大）；⑤ **蒸馏能引入教师的新推理模式，真正扩展能力边界**
- **实验矩阵**：Qwen2.5-7B/14B/32B + LLaMA3.1-8B；GRPO/PPO/Reinforce++/DAPO/RFT/Oat-Zero/SimpleRLZoo；数学（AIME24/MATH500/Minerva/Olympiad）+ 代码（LiveCodeBench/HumanEval+）+ 视觉推理（MathVista/MathVision）

## 一、先看例子（大白话：RLVR 到底"涨"了什么？）

> **背景铺垫**：DeepSeek-R1 之后，大家都相信"GRPO 这类 RLVR 能让模型在推理中自己探索、发现新解题策略"——就像 AlphaGo 自我对弈练出人类没见过的棋路。RLVR 模型在 MATH/AIME 上 pass@1 大涨，好像确实"进化"了。这篇问的是：**它真的变强了，还是只是"更容易蒙对"了？**

> **体检方法（极简版）**：别只看"答一次对不对"（pass@1），要让模型**同一个题反复答很多次**（pass@k，k 到 256、1024），看"答几百次能覆盖多少种解法、最多能答对多少"。

> **发现的"交叉"现象**：同一个题让 base 模型和它的 RLVR 版各答 256 次——

> **类比**：base 像一个大而全的图书馆（什么书都有，但没人翻）；RLVR 像给热门书做了个前台推荐位（借阅量涨了），代价是**把冷门但有用的书从书架上撤了下来**——图书馆的"知识总量"没涨，反而窄了。蒸馏则不同：它像**从别的图书馆（教师）真运来了新书**——总量真的涨了。

## 二、动机：RLVR 的"能力进化"叙事需要被检验

### 2.1 流行叙事

- o1/DeepSeek-R1 之后，RLVR（RL with Verifiable Rewards）成为推理后训练主流
- 默认假设：RLVR ≈ 传统 RL 的探索机制 → 模型能持续自我改进、**获得超出 base 的新推理能力**

### 2.2 为什么要质疑

- RLVR 的奖励只看"最终答案对不对"（稀疏标量），**没有过程反馈**——它凭什么发现"新策略"？
- 更可能的是：它只是在 base 已有的解题分布里"重加权"（把 base 会但概率低的正确路径调高）
- 检验方法：**pass@k 大 k + coverage**——如果 RLVR 真创造了新模式，大 k 时它应该 ≥ base；如果只是重排，大 k 时 base 会追平甚至反超（base 的分布更广）

### 2.3 核心问题

- *RLVR 是把能力边界往外推，还是在边界内部重排概率？蒸馏呢？*

> **炸裂点**：用 pass@256 当"能力边界"的探针——**采样效率（pass@1）和能力边界（pass@k 大 k）被彻底解耦**：RLVR 优化的是前者，牺牲的是后者。这个"能力边界收窄"的发现，直接动摇"RLVR = 自我进化"的叙事。

## 三、方法：不是新算法，是一套"能力边界体检协议"

### 3.1 体检指标

- **pass@k（大 k）**：同一问题采样 k 次，至少一次对的概率——k→∞ 逼近"模型分布里有多少正确解法"
- **coverage = pass@k**：可解问题的覆盖比例（Figure 1 右：pass@1 涨 vs pass@256 收敛/下降）
- **perplexity + coverage 联合分析**：判断 RLVR 生成的路径是否"落在 base 的采样分布里"

### 3.2 体检对象（横跨模型/算法/域）

- **模型族**：Qwen2.5-7B/14B/32B-Base、LLaMA3.1-8B、Qwen2.5-Math-7B
- **RLVR 算法**：GRPO、PPO、Reinforce++、DAPO、RFT、Oat-Zero、SimpleRLZoo（6+ 种）
- **任务域**：数学（GSM8K/MATH500/AIME24/AMC23/Minerva/Olympiad）、代码（LiveCodeBench/HumanEval+）、视觉推理（MathVista/MathVision）
- **对比臂**：base vs RLVR 版 vs 蒸馏版（DeepSeek-R1 → Qwen2.5-Math-7B 的官方 distill 模型）

### 3.3 核心分析手段

- pass@k 曲线交叉点分析（Figure 2：4 模型 × 4 榜的曲线矩阵）
- 搜索树可视化（Figure 1 左：Problem A 高效采样 / Problem B 能力范围缩小）
- ∆SE（采样效率差距）：衡量 RLVR 距"base 能力上限"还有多远

## 四、实验与发现

### 4.1 发现一：大 k 时 base 反超（Figure 2，4 模型 × AIME24/MATH500/Minerva/Olympiad）

- 所有模型族/榜单上：小 k（k=1-16）RL 赢 → **k 到几十到几百时 base 追上并反超**
- Minerva/Olympiad 上交叉最明显：base 后期显著高于 RL 版

![图片展示了不同模型在AIME24、MATH500、Minerva、Olympiad榜单上的coverage（pass@k）随样本数量k变化的情况。横轴为样本数量k，纵轴为coverage。图中分别呈现了Qwen-2.5-7B、Qwen-2.5-14B、Qwen-2.5-32B、LLaMA-3.1-8B等模型的Base和RL版本的曲线。Base版本曲线在RL版本之上，表明Base版本在样本数量较少时覆盖度更高。该图与上下文内容相关，用于说明在不同榜单上，Base版本在小k时覆盖度高于RL版本，且后期显著高于RL版。](/images/paper-reading/2026-09-04-rl-cap/2026-09-04-d31-2.png)

### 4.2 发现二：训练越久，边界越窄（Figure 1 右）

- Qwen2.5-7B + GRPO：step 150→300→450，pass@1 持续涨，**pass@256 持续降**（收敛但仍低于 base 起点）——能力边界随训练收窄

### 4.3 发现三：RLVR 的路径都在 base 分布里

- coverage/perplexity 分析：RLVR 模型的生成路径**几乎全部被 base 的采样分布包含**——没有产生 base 采样不到的新路径
- 结论：RLVR 的能力"源于 base、受 base 封顶"；pass@1 的提升 = 概率重排，不是新知识

### 4.4 发现四：6 种 RLVR 算法半斤八两，都远未榨干 base

- PPO/GRPO/Reinforce++/DAPO/RFT/Oat-Zero 的 ∆SE 差异小且都很大——**离"充分利用 base"差得远**，说明瓶颈不在具体算法，在 RLVR 范式本身（稀疏奖励、无探索）

### 4.5 发现五：蒸馏是真正的"扩界"选手（Figure 7）

- DeepSeek-R1-Distill-Qwen-7B（把 R1 的长 CoT 蒸进 Qwen2.5-Math-7B）vs base 及 RL 版：

  - 蒸馏模型的 pass@k 曲线**整体抬升**（不是交叉，是全区间领先）
  - 蒸馏从教师那里**引入 base 本来不会产生的推理模式**——这才是能力边界的真实扩展

![图片为Minerva模型的pass@k曲线图，展示了Base、RL、Instruct、Distill四种模型在不同样本数量k（1至128）时的覆盖率（pass@k）。Base模型曲线最低，Distill模型曲线最高，且在全区间领先，表明蒸馏模型引入了Base本来不会产生的推理模式，真正实现了能力边界扩展。该图与上下文紧密相关，直观呈现了蒸馏模型在能力边界扩展方面的优势。](/images/paper-reading/2026-09-04-rl-cap/2026-09-04-d31-3.png)

### 4.6 论文自己开的药方（如果要让 RLVR 真正扩界）

- 有效的探索机制（当前 RLVR 采样即探索，太弱）
- 更精细的数据策展（不是海量灌题）
- **细粒度过程信号**（← 这条直接接你 OPD 主线的"监督信号精细化"）
- 多轮 agent 交互（让模型在环境反馈中真正"试错"）

## 五、Limitations & 批判性思考

1. **论文有独立 Limitations（第 7 节）**——以下为论文自述 + 我的阅读
2. **pass@k 的语义边界**：论文自认 pass@k 衡量的是"分布覆盖"，不等于"单一 rollout 的实际可用性"——对必须一次答对的部署场景，采样效率（pass@1）依然是 RLVR 的实在价值
3. **"新推理模式"的判定是间接的**：靠 perplexity/coverage 推断"路径在 base 分布内"，没有直接证明"这些路径 base 采样不到"（计算上无法穷举）
4. **评测以数学/代码为主**：视觉推理只有两个榜；开放式/agentic 任务（无标准答案、需多轮）不在覆盖范围——RLVR 在那里的行为可能不同
5. **蒸馏对比是"别人的蒸馏"**：用的是 DeepSeek 官方 distill 模型（教师 R1 远强于 base），没有在同一起跑线比较"弱教师蒸馏 vs 强 RL"——"蒸馏必优于 RL"的结论在教师不强时是否成立未验证
6. **分析对象限于 2025 上半年的 RLVR**：GRPO 系；更新的带过程奖励/搜索的方法（如 TIR/多轮）不在体检范围

## 七、启发与待跟进

> **核心启发**：
> 1. **pass@1 与能力边界是两回事**：pass@1 涨可能只是概率重排；pass@k（大 k）才是"分布里有多少真解法"的探针——**评估协议决定你看到的故事**
> 2. **RLVR 的"进化叙事"要打折**：稀疏答案奖励 + 无探索 = 只能重排 base 已有分布；这是"监督信号精细化"（你的主线）最硬的存在理由——**奖励给不出新方向，只有新信号（教师/过程/反馈）能**
> 3. **蒸馏扩界的本质是"引种"**：把教师分布里 base 没有的模式搬进来——所以教师的选择（强不强、会不会新解法）决定扩界上限

### 待跟进 checklist

- [ ] **OPD 的 pass@k 体检**：把你 lib 的 OPD 方法（REOPOLD/EOPD/HPD）训出的模型也跑一遍大 k pass@k——验证"OPD 是否真的扩界"（本文只测了官方 distill，没测 on-policy 蒸馏）

- [ ] **教师质量 × 扩界幅度**：弱教师（同规模 RL 版）vs 强教师（R1）蒸馏的 pass@k 差异——补本文"蒸馏对比"的同起点缺环

- [ ] **细粒度过程信号药方落地**：本文点名"过程信号"是扩界方向——接 BSBT 的盲测验证/PCD 的分锅门控，做"过程级 RLVR"消融 pass@1 vs pass@256

- [ ] **agentic RLVR 的边界体检**：本文没测多轮/带工具——AutoTool 类方法在大 k 下是否扩界

- [ ] **覆盖率指标标准化**：把 pass@256 写进 lib 后续所有博客的评测栏，统一度量

## 八、今日阅读结论

这篇（NeurIPS 2025 Oral）是 OPD 谱系的"机制级注脚"：用 pass@k 大 k 给 RLVR 做体检，发现它**只提升采样效率、不扩展能力边界**（大 k base 反超、coverage 随训练收窄、路径都在 base 分布里），6 种 RLVR 算法半斤八两且都远未榨干 base；而蒸馏（把教师长 CoT 引进来）是真正扩界的手段。它不是"RLVR 无用论"——pass@1 的实在价值依然在——而是把**采样效率与能力边界解耦**，逼每个做后训练的人想清楚：我训的方法是在"挤概率"还是"引新模式"？对你 OPD 主线，这篇是理论底气：REOPOLD（能稳训）+ OPSD（token 省）+ 本文（蒸馏才扩界）拼成"OPD 系值得做"的完整论证；它点名的药方"细粒度过程信号"，正是你 lib 一个月来在填的坑——BSBT 的盲测、PCD 的分锅、REOPOLD 的熵采样，全都是在给 RLVR 补它最缺的东西。

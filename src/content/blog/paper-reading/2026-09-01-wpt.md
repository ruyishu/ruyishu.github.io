## TL;DR

**一句话：世界模型（World Model）能"预言"未来几秒的路况，但推理时跑它太慢（312ms）；WPT 让它只在训练期当"预言家"——先教出一个会选最优轨迹的教师策略，再用"策略蒸馏 + 奖励蒸馏"把这份未来感知传进一个 64ms 的轻量学生策略，训完把世界模型和教师一起扔掉——学生照样 0.11% 碰撞率、79.23 驾驶分，比世界模型系和纯模仿系都强。**

- **核心问题**：自动驾驶的世界模型方法要么推理时耦合世界模型（慢、贵），要么靠离线奖励（破坏端到端优化）——**世界模型的知识无法以实时代价被使用**
- **方法（四件套）**：① 教师策略（多模态：生成 N 条候选轨迹 + 世界模型互动选最优）/ 学生策略（单模态：一次前向直接出轨迹）；② 世界模型（预训练 Drive-OccWorld，**冻结**，预言未来世界状态）；③ **可训练奖励模型**（把候选轨迹和预言的世界状态一起打分：模仿头 + 仿真头 5 信号 NC/DAC/EP/TTC/Comfort）；④ **双蒸馏**——Policy Distillation（学生 plan query 对齐教师的 ||Q_S−Q_T||²）+ World Reward Distillation（学生轨迹的奖励分对齐教师最优轨迹的 ||r(τ_S)−r(τ\*\_T)||²），**只在训练期生效**
- **结果**：nuScenes 开环 Avg L2 0.61m / 碰撞 0.11%（教师），学生 0.66m/0.24%（基线 0.88/1.06）；Bench2Drive 闭环驾驶分 79.23 / 成功率 54.54%（压过 DriveTransformer 63.46/35.01、DiffAD 67.92/38.64）；学生 64ms ≈ 基线延迟，比教师 312ms **快 4.9×**
- **主题轮换**：今日**世界模型**（轮换序列新方向第一弹；8/31 为多模态推理/感知）

## 一、先看例子（世界模型大白话 + 驾驶场景）

> **世界模型是什么（大白话）**：就是给 AI 一个"如果……就会……"的**因果预言器**——你告诉它"我现在在这条路上、前面有车在变道、我打算加速"，它预测"3 秒后世界长什么样"（下一帧画面 / 未来占用栅格 / 其他车的位置）。人类开车的"预判感"就是这么来的：你不需要真的撞上去，脑子里就能模拟"如果我不刹车会怎样"。世界模型的全部价值 = **不试错就知道后果**。

> **场景**：高速上，前车突然亮刹车灯，右后方有车正在并入。**纯模仿学习（IL）**：只学"老司机踩过什么踏板"——没见过这种组合场景就抓瞎（复刻行为，不建模因果）。**世界模型直接当策略**：先预言"3 秒后右车会插到前面、前车要停"，再规划——准，但每帧要多跑一个世界模型（312ms/帧，实时根本扛不住）。**WPT（今天）**：让世界模型只在**训练期**当预言家——它给教师策略当"考官"（每条候选轨迹跟预言未来一对比，打一个分），教师学会"选那条最安全的路"；然后把教师的判断力**蒸馏**进一个 64ms 的学生策略。**推理时世界模型和教师都不在了**，学生自己带着"未来感"开车。

## 二、动机：世界模型很强，但上不了车

### 2.1 现象（三条路的死结）

- **(a) 模仿学习**：复刻专家行为，不建模"因果互动"——组合场景泛化差
- **(b) 世界模型当策略**：把 WM 耦合进策略提升特征演化，但推理时 WM 常驻 → **运行时耦合**（慢、贵、难部署）
- **(c) 仿真器 RL**：用模拟世界训策略，但奖励信号离线、和真实环境脱节，且破坏端到端优化

### 2.2 根因

- 世界模型的知识（"未来会怎么演化"）**以训练信号的形式存在才有价值**；推理时逐帧跑 WM 是把"预判力"当成"实时计算负荷"
- 核心问题：*能否把世界模型的预判力，以纯训练信号的形式蒸馏进一个轻量策略，让推理零开销？*

> **炸裂点**：WPT 的答案是"训完就扔"——世界模型只在训练期当预言家，教师策略只在训练期当"最优轨迹选择器"，两者在推理时全部移除。这直接回应了"世界模型不可行"的怀疑：**世界模型不需要部署，只要会预言就行**——预判力是知识，不是运行时依赖。

## 三、方法：预言家 + 考官 + 双蒸馏

### 3.1 双胞胎策略（教师/学生）

- 通用骨架：多视图相机 → BEV 世界表示 F_w → 规划解码器 PD（可学习 query Q 与 F_w 交叉注意力）→ MLP 规划头 → 未来轨迹
- **教师（多模态策略）**：解码器先生成 N 条候选轨迹 {τ_1…τ_N}，再与世界模型互动选出最优——**会选**
- **学生（单模态策略）**：一次前向直接出整条轨迹，推理时无多模态生成、无 WM 互动——**快**

### 3.2 世界模型当"预言家"（冻结）

- 预训练 Drive-OccWorld（4D 占用预测），**权重冻结**：观测编码 WE → 特征聚合 AM → 自回归解码 WD，输入动作条件 c（历史轨迹/导航命令/自车状态），输出未来世界状态 F^w\_{t+1}
- 教师把 F^w\_{t+1} 当规划解码器的输入：**在"预言的未来"里规划**（Fig. 2 上半部）

![这张图呈现了“World Model Enhanced Planning”的核心架构，包含教师与学生的孪生策略及对应知识蒸馏的流程。上方教师侧以AD Policy(T)为基础，经Plan解码器生成多模态候选轨迹，结合世界模型输出的未来世界状态，通过Reward Model计算轨迹对应的奖励；下方学生侧的AD Policy(S)经编码器生成精简的规划查询，输出单模态轨迹，完成策略蒸馏，将世界模型的规划知识迁移给学生，实现推理效率与性能的平衡。](/images/paper-reading/2026-09-01-wpt/2026-09-01-d28-2.webp)

### 3.3 可训练奖励模型当"考官"（核心创新）

- 每条候选轨迹 τ_i 与预言的未来状态 F^w\_{t+1} 拼成联合表示 → 打分，两个头：

  - **模仿奖励头**：轨迹与人类驾驶偏好的对齐度
  - **仿真奖励头**：5 个安全/舒适信号——NC 无碰撞、DAC 可行驶区域、EP 自车进度、**TTC 碰撞时间**、Comfort 舒适度（NAVISIM PDM 风格）
- 消融证明 TTC 是安全主力（去掉它碰撞率 0.11→0.25%）

### 3.4 双蒸馏：把预言家的功力传给学生（只训练期生效）

- **Policy Distillation**：学生对齐教师的"世界条件化规划意图"——`L_policy = ‖Q_S − Q_T‖²`（plan query 的 L2 对齐）
- **World Reward Distillation**：学生对齐教师的"世界认知评判标准"——`L_reward = ‖r_final(τ_S) − r_final(τ*_T)‖²`（学生轨迹分对齐教师最优轨迹分）
- 训练结束：教师 + 世界模型 + 奖励模型**全部移除**，只剩学生策略

> **三个观察**：① **"预言家-考官-学徒"三段式**——WM 负责预言（不参与决策）、Reward Model 负责评判（把预言变成打分）、学生负责学会"不用预言也能选对"；② **奖励蒸馏比 logit 蒸馏更本质**——学生学的不是"模仿教师说什么"，而是"什么才算好轨迹"；③ **query 蒸馏（隐空间）+ 奖励蒸馏（决策准则）双通道**，一个管"怎么想"，一个管"怎么判"。

## 五、Limitations & 批判性思考

1. **论文无独立 Limitations 章节**（诚实标注）——以下为我的阅读
2. **舒适度被牺牲**：WPT 的 Comfort 分数（16-18）显著低于基线（23.4）和 VAD-Tiny（66.9）——"安全/效率优先、舒适靠后"的奖励整形偏置，作者承认待解决
3. **世界模型是"借来的"**：直接冻结 Drive-OccWorld，世界模型质量决定教师上限——预言不准时蒸馏的是"错误未来感"；没测 WM 更弱/更差的场景
4. **手写奖励信号**：5 个仿真信号（NC/DAC/EP/TTC/Comfort）仍需人工设计权重，非端到端学习出来的
5. **学生仍有损耗**：Teacher 0.61/79.23 → Student 0.66/72.61，闭环驾驶分掉了约 8 分——蒸馏损失不可忽略
6. **域窄**：只有 nuScenes + Bench2Drive（都是驾驶）；天气/长尾/多城泛化未验证
7. **教师 312ms 的算力来源未披露**：训练期双模型 + WM 的 GPU 开销论文只给了"见附录"，工程成本存疑

| **27** | **WPT（本作）** | **世界模型当预言家 + 奖励蒸馏进轻量策略** | **CVPR 2026，华为基础模型部门：世界模型不部署、只当训练期预言家——"训完就扔"落地世界模型** |

> **定位差异**：
> - **vs OPD 主线（最该合读）**：OPD 的教师是"更强的策略"，蒸馏 token 分布；WPT 的教师是"世界模型加持的策略"，蒸馏 plan query（隐空间）+ 奖励分（决策准则）——**同一套"训练期双模型、推理期单模型"骨架，换了蒸馏对象**。对 OPD 研究者的价值：奖励蒸馏（L_reward = ‖r(τ_S)−r(τ\*\_T)‖²）是个可直接借鉴的"判据蒸馏"模板。
> - **vs PRISM（#13）**：PRISM 回答"OPD 放 pipeline 哪一段"，WPT 回答"世界模型知识怎么变成策略知识"——两者都证明"重模型当训练期导师"是通用范式。
> - **对"世界模型不可行"怀疑的直接回应**：用户此前怀疑世界模型——WPT 给出最务实的落地路径：**世界模型不用长在车上，只要在训练期"会预言"就行**；预判力蒸馏成策略后，推理时一个 64ms 的普通模型就够。

## 七、启发与待跟进

> **核心启发**：
> 1. **"预言家不参与决策"是世界模型落地的最短路径**：WM 只提供未来状态，Reward Model 把它变成打分，学生只学"什么才算好"——世界模型的部署成本被彻底拆掉
> 2. **奖励蒸馏 > 行为蒸馏**：让学生对齐"教师选出的最优轨迹的分数"，比对齐"教师的输出"更本质——教的是判断准则，不是表面行为
> 3. **在预言的世界里训练 > 在真值世界里训练**（WM-Occ 0.61 vs GT-Occ 0.65）：训练数据的"预测结构"本身就是正则化

### 待跟进 checklist

- [ ] **WPT × OPD**：奖励蒸馏模板（‖r(τ_S)−r(τ\*\_T)‖²）能否搬到 LLM 推理 OPD——用"教师对答案质量的打分"替换"教师概率"，做成判据蒸馏

- [ ] **蒸馏损耗分析**：Teacher 79.23 → Student 72.61 掉 8 分，Query 蒸馏 + Reward 蒸馏各贡献多少、能否用 GNDPO 式归一化补

- [ ] **舒适度-安全权衡**：5 信号权重能否端到端学习（替代手写），或加"舒适度"进蒸馏目标

- [ ] **世界模型更弱的鲁棒性**：换弱 WM / 换任务域（泊车、城市路口）时 WPT 是否仍有效——验证"预言家质量下限"

- [ ] **泛化到 VLA/具身**：WM 当预言家 + 奖励蒸馏进轻量策略的框架，能否套到机器人大脑（π0 类）——世界模型轮换主题的下一步延伸

- [ ] **训练成本**：论文只承诺"附录见"，双模型 + WM 训练期的真实 GPU 开销要盯

## 八、今日阅读结论

WPT 是"世界模型如何落地"最干净的回答（CVPR 2026）：不要求世界模型上实时系统，只让它当**训练期预言家**——预言未来世界状态 → 可训练奖励模型当考官给候选轨迹打分 → 教师学会选最优 → **双蒸馏**（plan query 对齐 + 奖励分对齐）把预判力传进 64ms 学生策略，然后预言家/考官/教师全部退役。结果 nuScenes 开环 0.61m/0.11%、Bench2Drive 闭环 79.23 分压过世界模型系与模仿系，学生推理快 4.9×。对 OPD 研究者：**奖励蒸馏（教"什么才算好"而非"怎么做"）和"训练期预言家"范式，是两个可直接迁移的模板**；它也是"世界模型不可行"怀疑的最务实回应——**世界模型不需要长在车上，只要在训练期会预言就够了**。

> **今日一句**：世界模型不用背上车——让它在训练期当预言家，把"3 秒后的世界"变成打分，再把"会打分"蒸馏进一个 64ms 的小策略，训完连预言家一起扔掉。论文：arXiv:2511.20095（CVPR 2026）· 笔记挂在 lib 中 · 2026-09-01
